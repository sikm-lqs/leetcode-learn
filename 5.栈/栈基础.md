下面是 **Python 栈基础知识 + 常用技巧 + 高频模板**。

栈可以先理解成：

> 栈是一种“后进先出”的数据结构。

英文是：

```text
LIFO：Last In, First Out
```

也就是：

```text
最后放进去的元素，最先被取出来。
```

---

# 一、什么是栈？

假设我们依次放入：

```text
1、2、3
```

栈中的状态可以想成：

```text
栈顶
 ↓
3
2
1
```

这时先取出的会是 `3`，然后是 `2`，最后是 `1`。

就像一摞盘子：

```text
最后放上去的盘子，最先拿下来。
```

# 二、Python 中怎么实现栈？

Python 中通常直接使用列表 `list` 实现栈。

```python
stack = []
```

入栈：

```python
stack.append(x)
```

出栈：

```python
x = stack.pop()
```

查看栈顶：

```python
top = stack[-1]
```

判断栈是否为空：

```python
if not stack:
    print("栈为空")
```

# 五、栈和队列的区别

栈是：

```text
后进先出
```

队列是：

```text
先进先出
```

例如依次加入：

```text
1、2、3
```

栈取出顺序：

```text
3、2、1
```

队列取出顺序：

```text
1、2、3
```

| 数据结构 | 规则   | 常见用途           |
| ---- | ---- | -------------- |
| 栈    | 后进先出 | 括号匹配、撤销、递归、表达式 |
| 队列   | 先进先出 | BFS、任务调度、层序遍历  |

# 六、栈为什么适合处理“最近的问题”？

栈最适合解决这种问题：

> 当前元素需要和最近一个还没有处理完的元素进行匹配。

例如：

```text
括号匹配
删除相邻重复字符
下一个更大元素
撤销操作
路径退回
```

因为栈顶永远表示：

```text
最近放入但还没有处理完的元素。
```

# 七、栈的核心技巧一：括号匹配

括号匹配是最经典的栈题。

例如：

```text
()[]{}
```

是有效括号。

而：

```text
([)]
```

不是有效括号。

---

## 1. 基本思路

遇到左括号：

```text
(
[
{
```

就入栈。

遇到右括号：

```text
)
]
}
```

就检查它和栈顶左括号是否匹配。

---

## 2. 标准代码

```python
def isValid(s):
    stack = []

    pairs = {
        ")": "(",
        "]": "[",
        "}": "{"
    }

    for ch in s:
        if ch in "([{":
            stack.append(ch)
        else:
            if not stack:
                return False

            if stack[-1] != pairs[ch]:
                return False

            stack.pop()

    return not stack
```

---

## 3. 为什么最后要 `return not stack`？

例如：

```text
(((
```

所有字符都是左括号。

遍历结束以后，栈中还有：

```text
( ( (
```

说明还有括号没有匹配。

所以最后必须保证：

```python
return not stack
```

只有栈为空才是有效括号。

# 八、栈的核心技巧二：删除相邻重复元素

例如：

```text

```

处理过程：

```text
a
ab
abb    b 和 b 相同，删除
a
ac
aca
```

最后结果：

```text
ca
```

代码：

```python
def removeDuplicates(s):
    stack = []

    for ch in s:
        if stack and stack[-1] == ch:
            stack.pop()
        else:
            stack.append(ch)

    return "".join(stack)
```

核心判断：

```python
if stack and stack[-1] == ch:
```

这里必须先判断：

```python
stack
```

否则空栈时访问：

```python
stack[-1]
```

会报错。

# 九、栈的核心技巧三：单调栈

单调栈是栈题中非常重要的一类。

单调栈不是一种新的数据结构，而是：

> 栈中的元素始终保持单调递增或单调递减。

单调栈常用于解决：

```text
下一个更大元素
下一个更小元素
每日温度
柱状图最大矩形
接雨水
```

# 十、什么是单调递增栈和单调递减栈？

---

## 1. 单调递增栈

从栈底到栈顶越来越大：

```text
1 3 5 8
```

---

## 2. 单调递减栈

从栈底到栈顶越来越小：

```text
9 7 4 2
```

实际做题时，更重要的不是背名字，而是理解：

> 当前元素来了以后，是否能帮助栈中旧元素找到答案。

# 十一、每日温度：单调栈经典题

题目大意：

> 给出每天的温度，求每一天还要等几天，才能遇到更高温度。

例如：

```python
temperatures = [73, 74, 75, 71, 69, 72, 76, 73]
```

答案：

```python
[1, 1, 4, 2, 1, 1, 0, 0]
```

---

## 1. 核心思路

栈中不保存温度值，而保存：

```text
下标
```

因为最后要计算天数差：

```python
i - stack[-1]
```

---

## 2. 标准代码

```python
def dailyTemperatures(temperatures):
    n = len(temperatures)
    ans = [0] * n
    stack = []

    for i, temp in enumerate(temperatures):
        while stack and temperatures[stack[-1]] < temp:
            prev_i = stack.pop()
            ans[prev_i] = i - prev_i

        stack.append(i)

    return ans
```

---

## 3. 为什么栈里保存下标？

因为我们既需要：

```text
比较温度
```

又需要：

```text
计算距离
```

通过下标可以同时得到：

```python
temperatures[stack[-1]]
```

以及：

```python
i - stack[-1]
```

这是单调栈题非常常见的技巧：

> 当题目要求位置差、距离、天数时，栈里通常保存下标。

# 十三、栈的核心技巧四：表达式计算

栈常用于处理：

```text
加减乘除
括号
逆波兰表达式
中缀表达式
```

---

## 1. 逆波兰表达式

例如：

```text
["2", "1", "+", "3", "*"]
```

表示：

```text
(2 + 1) * 3 = 9
```

做法：

```text
遇到数字入栈
遇到运算符，弹出两个数字进行运算
再把结果压回栈
```

代码：

```python
def evalRPN(tokens):
    stack = []

    for token in tokens:
        if token not in {"+", "-", "*", "/"}:
            stack.append(int(token))
        else:
            b = stack.pop()
            a = stack.pop()

            if token == "+":
                stack.append(a + b)
            elif token == "-":
                stack.append(a - b)
            elif token == "*":
                stack.append(a * b)
            else:
                stack.append(int(a / b))

    return stack[-1]
```

注意顺序：

```python
b = stack.pop()
a = stack.pop()
```

对于减法和除法：

```text
a - b
a / b
```

不能写反。

# 十四、栈的核心技巧五：字符串解码

例如：

```text
3[a2[c]]
```

解码后：

```text
accaccacc
```

这种带嵌套结构的问题，经常用栈。

---

## 基本思路

遇到：

```text
数字：累计倍数
左括号 [：保存当前状态
字母：拼接当前字符串
右括号 ]：弹出之前状态并展开
```

代码：

```python
def decodeString(s):
    stack = []
    current_num = 0
    current_str = ""

    for ch in s:
        if ch.isdigit():
            current_num = current_num * 10 + int(ch)

        elif ch == "[":
            stack.append((current_str, current_num))
            current_str = ""
            current_num = 0

        elif ch == "]":
            prev_str, repeat = stack.pop()
            current_str = prev_str + current_str * repeat

        else:
            current_str += ch

    return current_str
```

# 十五、栈的核心技巧六：路径简化

例如 Unix 路径：

```text
/home//foo/
```

简化后：

```text
/home/foo
```

规则：

```text
.  表示当前目录
.. 表示返回上一级
空字符串忽略
普通目录名入栈
```

代码：

```python
def simplifyPath(path):
    stack = []

    for part in path.split("/"):
        if part == "" or part == ".":
            continue
        elif part == "..":
            if stack:
                stack.pop()
        else:
            stack.append(part)

    return "/" + "/".join(stack)
```

# 十六、栈的核心技巧七：模拟递归

递归本质上也使用了系统调用栈。

例如二叉树 DFS：

```python
def dfs(root):
    if not root:
        return

    dfs(root.left)
    dfs(root.right)
```

可以用显式栈改成迭代：

```python
def dfs(root):
    if not root:
        return

    stack = [root]

    while stack:
        node = stack.pop()

        print(node.val)

        if node.right:
            stack.append(node.right)

        if node.left:
            stack.append(node.left)
```

为什么先放右节点？

因为栈是后进先出：

```text
先放右
再放左
最后左先出来
```

这样可以保证先访问左子树。

# 十八、最小栈

题目要求：

```text
支持 push
支持 pop
支持 top
还要能 O(1) 获取最小值
```

普通栈只能 O(n) 找最小值。

解决方法是再维护一个辅助栈。

---

## 代码

```python
class MinStack:

    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, val):
        self.stack.append(val)

        if not self.min_stack:
            self.min_stack.append(val)
        else:
            self.min_stack.append(min(val, self.min_stack[-1]))

    def pop(self):
        self.stack.pop()
        self.min_stack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.min_stack[-1]
```

核心思想：

```text
普通栈保存所有值
最小栈保存每个位置对应的当前最小值
```

例如依次压入：

```text
3、5、2、4
```

普通栈：

```text
3 5 2 4
```

最小栈：

```text
3 3 2 2
```

# 十九、用两个栈实现队列

队列是先进先出，栈是后进先出。

可以用两个栈实现：

```text
in_stack：负责入队
out_stack：负责出队
```

代码：

```python
class MyQueue:

    def __init__(self):
        self.in_stack = []
        self.out_stack = []

    def push(self, x):
        self.in_stack.append(x)

    def pop(self):
        self._move()
        return self.out_stack.pop()

    def peek(self):
        self._move()
        return self.out_stack[-1]

    def empty(self):
        return not self.in_stack and not self.out_stack

    def _move(self):
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())
```

核心：

```text
第一次倒序一次
第二个栈中的顺序就变成先进先出
```

# 二十、栈题常见边界情况

---

## 1. 空栈出栈

错误：

```python
stack = []
stack.pop()
```

会报错。

正确处理：

```python
if stack:
    stack.pop()
```

---

## 2. 空栈访问栈顶

错误：

```python
stack[-1]
```

如果栈为空会报错。

所以经常写：

```python
if stack and stack[-1] == x:
```

---

## 3. 最后栈中还有剩余元素

括号题中，遍历结束后不能直接返回 `True`。

要判断：

```python
return not stack
```

---

## 4. 运算顺序写反

逆波兰表达式中：

```python
b = stack.pop()
a = stack.pop()
```

计算：

```python
a - b
a / b
```

不能写成：

```python
b - a
```

---

## 5. 栈里存值还是存下标

例如每日温度，必须存下标。

如果只存温度，就无法计算相隔几天。

---

## 6. 单调栈的 while 写成 if

错误：

```python
if stack and nums[stack[-1]] < x:
    stack.pop()
```

一个新元素可能一次解决多个旧元素，所以通常应该写：

```python
while stack and nums[stack[-1]] < x:
    stack.pop()
```

# 二十七、栈题时间复杂度怎么分析？

---

## 1. 普通遍历加栈

例如有效括号：

```python
for ch in s:
```

每个字符入栈、出栈最多一次：

```text
时间复杂度：O(n)
空间复杂度：O(n)
```

---

## 2. 单调栈为什么不是 O(n²)？

单调栈中虽然有：

```python
for
```

里面套：

```python
while
```

但每个元素：

```text
最多入栈一次
最多出栈一次
```

所以总操作次数最多约为 `2n`。

因此：

```text
时间复杂度：O(n)
空间复杂度：O(n)
```

不是 `O(n²)`。

# 二十八、栈篇最重要总结

栈的核心规则：

```text
后进先出
```

Python 中栈的三个基本操作：

```python
stack.append(x)  # 入栈
stack.pop()      # 出栈
stack[-1]        # 查看栈顶
```

最常见的题型：

```text
括号匹配
相邻消除
表达式计算
嵌套结构
单调栈
```

最重要的安全判断：

```python
if stack and stack[-1] == x:
```

最重要的单调栈模板：

```python
stack = []

for i, x in enumerate(nums):
    while stack and nums[stack[-1]] < x:
        prev_i = stack.pop()
        # 当前元素 x 为 prev_i 找到了答案

    stack.append(i)
```

你现阶段最应该先掌握两道题：

```text
1. 有效的括号
2. 每日温度
```

第一题帮助你理解普通栈，第二题帮助你理解单调栈。
