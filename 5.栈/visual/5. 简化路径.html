5. 简化路径

将 Unix 风格路径转换为规范路径

1. 题目理解

给定一个 Unix 风格的绝对路径（以 '/' 开头），将其转化为规范路径（更简洁的表示）。

Unix 路径规则：
  • . → 当前目录，可忽略
  • .. → 上一级目录，需返回父目录
  • // 或 /// → 视为单个 '/'
  • ... 或 .... → 合法的文件/目录名，不能忽略

示例

输入：path = "/home/"
输出："/home"

输入：path = "/../"
输出："/"

输入：path = "/home//foo/"
输出："/home/foo"

输入：path = "/a/./b/../../c/"
输出："/c"
规范路径要求：以 '/' 开头，目录间只有一个斜杠，结尾不含斜杠，不含 '.' 或 '..'。

2. 核心思路：栈模拟

为什么用栈？

路径的层次结构天然符合栈的后进先出特性：

  • 遇到普通目录名 → 入栈（进入子目录）
  • 遇到 '..' → 出栈（返回父目录）
  • 遇到 '.' 或空串 → 忽略（停留在当前目录）

算法流程

  1. 按 '/' 分割路径，得到各个组成部分
  2. 遍历每个部分：
    • 空串或 '.' → 忽略
    • '..' → 栈非空则弹出
    • 其他 → 入栈
  3. 用 '/' 连接栈中所有元素
核心洞察：split('/') 自动处理连续斜杠（产生空串），栈处理目录层次，'..' 对应出栈，完美模拟目录切换。
边界情况：栈为空时说明在根目录，返回 '/'；连续 '..' 超出根目录时也返回 '/'。

3. 伪代码骨架

stack = []

for name in 按'/'分割路径:
    if 空串或'. ':               # name == "" or name == "."
        continue                   忽略，停留在当前目录
    elif name == "..":             返回上一级
        if stack:                    # 栈非空才能返回
            stack.pop()             弹出栈顶
    else:                          普通目录名
        stack.append(name)        入栈

if not stack:                     # 栈为空
    return "/"
return "/" + 用'/'连接栈      # '/'.join(stack)

5. 详细过程模拟

以 path = "/a/./b/../../c/" 为例：

分割路径

path.split('/') = ["", "a", ".", "b", "..", "..", "c", ""]

逐个处理

部分操作栈状态说明
""忽略[]空串，跳过
"a"入栈["a"]进入目录 a
"."忽略["a"]当前目录，跳过
"b"入栈["a", "b"]进入目录 b
".."出栈["a"]返回上一级（弹出 b）
".."出栈[]返回上一级（弹出 a）
"c"入栈["c"]进入目录 c
""忽略["c"]空串，跳过

拼接结果

'/' + '/'.join(["c"]) = "/c"
最终结果："/c" ✅

6. 代码逐段解释

完整代码

class Solution:
    def simplifyPath(self, path: str) -> str:
        stack = []
        for name in path.split("/"):
            if name == "" or name == ".":
                continue
            elif name == "..":
                if stack:
                    stack.pop()
            else:
                stack.append(name)
        if not stack:
            return '/'
        return '/' + '/'.join(stack)

逐段说明

第 1 步：初始化栈

stack = []

用栈存储路径中的目录名。

第 2 步：分割并遍历路径

for name in path.split("/"):

split('/') 自动处理连续斜杠，生成空串。

第 3 步：根据类型处理

if name == "" or name == ".":
    continue
elif name == "..":
    if stack:
        stack.pop()
else:
    stack.append(name)
  • 空串或 '.' → 忽略
  • '..' → 出栈（栈非空时）
  • 其他 → 入栈

第 4 步：拼接结果

if not stack:
    return '/'
return '/' + '/'.join(stack)

栈为空返回根目录，否则用 '/' 连接。

关键：栈为空时不能继续 pop()，否则会报错。

7. 复杂度分析

维度值说明
时间复杂度O(n) n 为路径长度，只需一次遍历
空间复杂度O(n) 栈最多存储 n 个字符（最坏情况全是目录名）
优化：split('/') 的时间复杂度为 O(n)，整体算法只需遍历一次，非常高效。

8. 常见易错点

错误一：栈为空时继续出栈

# 错误：不检查栈是否为空
elif name == "..":
    stack.pop()  # ❌ 栈为空时会报错

# 正确：先检查栈是否为空
elif name == "..":
    if stack:
        stack.pop()  # ✅

错误二：忽略特殊目录名

# 错误：把 ... 当作 ..
if len(name) >= 2 and name[:2] == "..":  # ❌

# 正确：只有 .. 才是特殊命令
if name == "..":  # ✅
注意：'...'、'....' 等是合法的文件名，不能当作特殊命令处理。

边界情况

输入输出说明
"/""/"根目录本身
"/../""/" 从根目录无法再向上
"/home//foo/""/home/foo" 连续斜杠视为单个
"/.../a/../b/c/.d""/.../b/c/.d" ... 和 .d 是合法文件名

9. 总结

简化路径 解法精髓：

  • 用栈模拟目录层次结构
  • '..' 对应出栈，目录名对应入栈
  • '.' 和空串直接忽略
  • split('/') 自动处理连续斜杠
  • 栈为空时返回根目录 '/'
class Solution:
    def simplifyPath(self, path: str) -> str:
        stack = []
        for name in path.split("/"):
            if name == "" or name == ".":
                continue
            elif name == "..":
                if stack: stack.pop()
            else:
                stack.append(name)
        return '/' + '/'.join(stack) if stack else '/'

💡 口诀：栈存目录名，点号原地留，双减出栈去，斜杠连接收。
