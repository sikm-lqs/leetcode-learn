1. 有效的括号

用栈判断括号是否有效匹配

1. 题目理解

给定一个只包含括号字符的字符串，判断它是否有效。

有效条件：
• 左括号必须用相同类型的右括号闭合
• 左括号必须以正确的顺序闭合
• 每个右括号都有对应的左括号

示例

输入：s = "()"
输出：true

输入：s = "()[]{}"
输出：true

输入：s = "(]"
输出：false

2. 核心思路：栈匹配

栈是处理「匹配」和「嵌套」问题的天然工具。

  • 遇到左括号 → 入栈（等待被匹配）
  • 遇到右括号 → 检查栈顶是否为对应左括号，不匹配或栈空则无效
  • 最后栈必须为空（所有左括号都被匹配）
核心洞察：左括号入栈，右括号触发出栈检查，利用 LIFO 保证顺序正确。

6. 代码逐段解释

class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        map = {')':'(', ']':'[', '}':'{'}

        for char in s:
            if char in '([{' :          # 左括号
                stack.append(char)
            elif char in ')]}':         # 右括号
                if not stack or map[char] != stack.pop():
                    return False
        return len(stack) == 0

7. 复杂度分析

  • 时间复杂度：O(n) —— 每个字符最多入栈/出栈一次
  • 空间复杂度：O(n) —— 最坏情况所有左括号入栈

8. 常见易错点

  • 右括号出现时栈为空（多余右括号）
  • 最后栈不为空（多余左括号）
  • 类型不匹配（如 (] ）
  • 顺序错误（如 ([)] ）

9. 总结

栈 + 哈希表是处理括号匹配的最优雅方案。左入右出，顺序天然保证。
