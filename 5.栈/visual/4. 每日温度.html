4. 每日温度

单调栈 · 下一个更高温度

1. 题目理解

给定每天的温度数组，返回对于每一天，下一个更高温度要等多少天。

如果之后都不会更高，则该位置填 0。

示例

输入：temperatures = [73,74,75,71,69,72,76,73]
输出：[1,1,4,2,1,1,0,0]

2. 核心思路：单调栈

维护一批“还没有被解决的问题”（即还没找到下一个更高温度的日子）。

  • 栈中保存的是下标，且温度从栈底到栈顶是递减的。
  • 当遇到一个更高的温度时，栈顶那些“未解决”的日子都可以被解决了。
  • 批量弹出栈顶，计算天数差。
核心洞察：单调栈把“找下一个更大”从 O(n²) 优化到 O(n)，因为每个元素只入栈出栈一次。

3. 伪代码骨架

ans = [0] * n
stack = []   # 存放还没找到答案的下标

for i, t in 遍历 temperatures:
    while stack and t > temperatures[stack[-1]]:
        prev = 弹出栈顶
        ans[prev] = i - prev     # 解决了一个“未解决的问题”
    stack.append(i)

6. 代码逐段解释

class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        # 单调栈
        # 维护一批“还没有被解决的问题”，当未来出现答案时批量解决。
        n = len(temperatures)
        ans = [0] * n
        stack = []  # 存下标

        for i, t in enumerate(temperatures):
            # 当前温度比栈顶温度高 → 解决一批“未解决”的问题
            while stack and t > temperatures[stack[-1]]:
                prev = stack.pop()
                ans[prev] = i - prev
            stack.append(i)
        return ans

7. 复杂度分析

时间 O(n)，空间 O(n)。每个元素最多被压栈、弹栈一次。

8. 常见易错点

  • 栈里存值而不是下标（会导致算不出天数差）
  • 忘记最后没被弹出的位置答案是 0（其实我们初始化就是 0）
  • 把 while 条件写反了

9. 总结

单调栈的精髓：用栈“记住”还没解决的问题，等到能解决的时候批量处理。
