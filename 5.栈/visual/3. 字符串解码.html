3. 字符串解码

给定经过编码的字符串 k[encoded_string]，返回解码后的字符串。

1. 题目理解

给定一个经过编码的字符串 s，返回解码后的字符串。编码规则为 k[encoded_string]，表示方括号内部的字符串正好重复 k 次。可以认为输入总是有效的：数字只会作为重复次数出现，且保证 k 为正整数。输入中可能包含嵌套的编码（如 3[a2[c]]）。

示例

输入：s = "3[a]2[bc]"
输出："aaabcbc"

输入：s = "3[a2[c]]"
输出："accaccacc"

输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"

2. 核心思路：栈模拟嵌套解码

用 栈 逐字符处理，遇到 ] 时触发一次「解码」：

  1. 非 ] 字符一律入栈（数字、字母、[ 都先放着）
  2. 遇到 ]：弹出字符直到 [，得到括号内的字符串（注意栈是倒序取出的，需要反转）
  3. 继续 弹出数字，得到重复次数 k（数字可能多位，也要反转）
  4. 把 k 倍的字符串重新压回栈，供外层继续解码

嵌套结构天然被栈化解：内层先解码、压回，外层遇到 ] 时再把它当作普通字符弹出拼接。最后拼接栈中所有字符即为答案。

关键洞察：解码结果「压回栈」而非直接输出——内层结果必须重新入栈，才能被外层的 k[...] 继续乘倍。这是栈解嵌套的核心。

6. 代码逐段解释

from typing import List

class Solution:
    def decodeString(self, s: str) -> str:
        stack = []
        for c in s:
            if c != "]":
                stack.append(c)              # 非 ']' 一律入栈
            else:
                now_str = ""
                while stack[-1] != "[":      # 1. 弹出括号内内容
                    now_str += stack[-1]
                    stack.pop()
                stack.pop()                   # 弹出 '['
                now_str = now_str[::-1]       # 倒序取出 → 反转

                num_str = ""
                while stack and stack[-1].isdigit():  # 2. 弹出数字（可多位）
                    num_str += stack[-1]
                    stack.pop()
                num_str = num_str[::-1]
                num = int(num_str)

                for _ in range(num):        # 3. 解码结果逐字符压回
                    for ch in now_str:
                        stack.append(ch)
        return "".join(stack)   # 拼接栈中全部字符

逐段说明

  • 入栈阶段：数字、[、字母统一当作普通字符压栈，[ 是解码的「分界标记」
  • 弹出内容：从栈顶往回取，先取到的是最内层字符，所以 now_str 是反的，必须 [::-1] 反转
  • 弹出数字：用 isdigit() 连续收集，12[a] 这类多位数字也能正确处理，同样需要反转后 int()
  • 压回：用嵌套循环逐字符入栈，保证外层解码时顺序正确

7. 复杂度分析

复杂度说明
时间O(n)每个字符最多入栈一次、出栈一次；s 的长度按解码后的总长度计
空间O(n)栈的深度即解码过程的嵌套深度，最坏为解码结果长度

8. 常见易错点

忘记反转：从栈顶取出的内容/数字是倒序的，now_str 和 num_str 都必须 [::-1]，否则 12[a] 会变成 21 倍。
解码结果没有压回：如果直接把 now_str * num 输出而不是逐字符重新入栈，嵌套场景 3[a2[c]] 的外层解码会缺失内层结果。
多位数字：只取一位数字（int(stack.pop())）会漏掉 12[a] 中的 1，必须用 while ... isdigit() 连续收集。
空栈访问：弹出内容时假设必有 [ 与它配对；题目保证输入有效，但若自己写测试用例（如裸 "]"）会越界。

9. 总结

  • 栈解嵌套：遇到 ] 解码一次，结果压回栈，天然处理任意层嵌套，无需递归
  • 三个动作：弹出内容（反转）、弹出数字（反转）、压回结果
  • 复杂度：时间 O(n)、空间 O(n)，一趟扫描完成
口诀：非右括全入栈，遇右括弹内容、弹数字、再压回。三处反转别忘记，最后拼接全栈。
