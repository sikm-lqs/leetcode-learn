2. 最小栈

设计一个支持常数时间 getMin 的栈

1. 题目理解

设计一个栈，支持 push、pop、top，并能在 O(1) 时间内检索到最小元素。

关键要求： getMin() 必须是 O(1) 时间复杂度。

示例

输入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]
输出：[null,null,null,null,-3,null,0,-2]

2. 核心思路：双栈设计

维护两个栈：

  • data_stack：正常存储所有元素
  • min_stack：存储当前的最小值

关键逻辑

  • push(value)：data_stack 正常压入。只有当 value <= min_stack 栈顶（或 min_stack 为空） 时，才把 value 压入 min_stack。
  • pop()：弹出 data_stack 栈顶。如果弹出的值等于 min_stack 栈顶，则 min_stack 也同步弹出。
  • getMin()：直接返回 min_stack 栈顶。
核心洞察：使用辅助栈记录“当前最小值”的历史状态，用空间换时间，保证每次 getMin 都是 O(1)。

3. 伪代码骨架

def push(value):
    data_stack.append(value)
    if not min_stack or value <= min_stack[-1]:
        min_stack.append(value)

def pop():
    top = data_stack.pop()
    if top == min_stack[-1]:
        min_stack.pop()

def getMin():
    return min_stack[-1]

6. 代码逐段解释

class MinStack:
    def __init__(self):
        self.data_stack = []
        self.min_stack = []

    def push(self, value: int) -> None:
        self.data_stack.append(value)
        # 只有当 value <= 当前最小值时才压入 min_stack
        if not self.min_stack or value <= self.min_stack[-1]:
            self.min_stack.append(value)

    def pop(self) -> None:
        top_element = self.data_stack.pop()
        # 只有当弹出的值是当前最小值时，才同步弹出 min_stack
        if top_element == self.min_stack[-1]:
            self.min_stack.pop()

    def top(self) -> int:
        return self.data_stack[-1]

    def getMin(self) -> int:
        return self.min_stack[-1]

7. 复杂度分析

  • 时间复杂度：O(1) —— push / pop / top / getMin 均为常数时间
  • 空间复杂度：O(n) —— 最坏情况下两个栈都存 n 个元素

8. 常见易错点

  • push 时忘记判断 value <= min_stack[-1]（必须包含等于）
  • pop 时没有判断弹出值是否等于 min_stack 栈顶就直接弹出
  • 只维护一个栈，导致 pop 后无法恢复之前的最小值

9. 总结

用辅助栈记录“历史最小值”，每次 push 都把当前最小值压进去，pop 时同步维护，完美实现 O(1) getMin。
