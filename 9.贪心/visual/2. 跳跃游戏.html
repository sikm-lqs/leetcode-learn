2. 跳跃游戏

贪心策略 · 维护最大覆盖范围

题目描述

给你一个非负整数数组 nums，你最初位于数组的 第一个下标。数组中的每个元素代表你在该位置可以 跳跃的最大长度。

判断你是否能够到达最后一个下标，如果可以，返回 true；否则，返回 false。

示例：nums = [2,3,1,1,4] → 输出: true
nums = [3,2,1,0,4] → 输出: false

算法思路

贪心策略：维护 max_reach（当前能够到达的最远距离），每一步贪心地扩大这个覆盖范围。

  • 遍历数组，维护 max_reach = max(max_reach, i + nums[i])
  • 如果当前索引 i > max_reach，说明无法到达该位置，返回 false
  • 如果能够遍历完整个数组，说明可以到达最后一个位置，返回 true
时间复杂度：O(n) —— 只需遍历一次
空间复杂度：O(1) —— 只用常数空间

核心亮点

  • ✓ 简化思维：将复杂问题转化为简单的边界判断
  • ✓ 贪心证明：只要能到达当前点，之前的所有点都能到达
  • ✓ 一次遍历：无需回溯或复杂的状态管理

代码实现

def canJump(nums):
    max_reach = 0

    for i in range(len(nums)):
        # 如果当前索引无法到达，返回 false
        if i > max_reach:
            return False

        # 更新能够到达的最远距离
        max_reach = max(max_reach, i + nums[i])

    return True

算法详解

以 nums = [2,3,1,1,4] 为例：

步骤当前位置 inums[i]更新后 max_reach判断
102max(0, 0+2) = 20 ≤ 2，可以继续
213max(2, 1+3) = 41 ≤ 2，可以继续
321max(4, 2+1) = 42 ≤ 4，可以继续
431max(4, 3+1) = 43 ≤ 4，可以继续
544max(4, 4+4) = 84 ≤ 4，到达终点！
关键观察：
- 在位置 1 时，max_reach 更新为 4，已经能到达终点
- 之后所有位置都在可达范围内，最终成功到达

失败案例：nums = [3,2,1,0,4]

步骤当前位置 inums[i]更新后 max_reach判断
103max(0, 0+3) = 30 ≤ 3，可以继续
212max(3, 1+2) = 31 ≤ 3，可以继续
321max(3, 2+1) = 32 ≤ 3，可以继续
430max(3, 3+0) = 33 ≤ 3，可以继续
54--4 > 3，无法到达！返回 false

关键要点

  • 贪心核心：维护能到达的最远位置，不断扩大覆盖范围
  • 边界判断：如果当前位置超出可达范围，立即返回 false
  • 最优证明：只要能到达当前点，之前的路径必定最优
  • 应用场景：路径规划、资源分配、可达性分析等
