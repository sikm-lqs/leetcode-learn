3. 买卖股票的最佳时机

贪心策略 · 维护历史最低价格

题目描述

给定一个数组 prices，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。

你只能选择 某一天 买入这只股票，并选择在 未来的某一个不同的日子 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 0。

示例：prices = [7,1,5,3,6,4] → 输出: 5（第2天买入，第5天卖出）
prices = [7,6,4,3,1] → 输出: 0（价格一直下跌，无法获利）

算法思路

贪心策略：遍历每一天卖出，利润最大的买入时机一定是在之前价格最低的那天。

  • 维护 min_price：遍历过程中的最低价格
  • 维护 max_profit：遍历过程中的最大利润
  • 对于每一天，计算 当前利润 = 当天价格 - 历史最低价格
  • 更新最大利润和最低价格
时间复杂度：O(n) —— 只需遍历一次
空间复杂度：O(1) —— 只用常数空间

核心亮点

  • ✓ 简化思维：将问题转化为"在遍历过程中维护历史最低值"
  • ✓ 一次遍历：无需嵌套循环或复杂的状态管理
  • ✓ 贪心证明：最优买入点一定是历史最低价格点

「历史最低价」同时兼顾了买入时机的最优性：最低点一定出现在某次卖出之前，一趟扫描即可求得全局最优。

代码实现

def maxProfit(prices):
    if not prices or len(prices) < 2:
        return 0

    min_price = prices[0]
    max_profit = 0

    for i in range(1, len(prices)):
        # 计算如果在第 i 天卖出的利润
        cur_profit = prices[i] - min_price

        # 更新最大利润
        max_profit = max(max_profit, cur_profit)

        # 更新最低价格
        min_price = min(min_price, prices[i])

    return max_profit if max_profit > 0 else 0

关键要点

  • 贪心核心：维护历史最低价格，以此为基准计算利润
  • 一次遍历：无需回溯，顺序处理即可得到最优解
  • 边界处理：当无法获利时返回 0，而不是负数
  • 应用场景：股票交易、价格优化、时机选择等
