1. 题目理解

这个学期必须选修 numCourses 门课程（编号 0 ~ numCourses-1）。prerequisites[i] = [ai, bi] 表示学习课程 ai 前必须先完成课程 bi。判断是否可能完成所有课程；可以返回 true，否则 false。

示例

输入：numCourses = 2, prerequisites = [[1, 0]]
输出：true
解释：先学 0 再学 1，可行。

输入：numCourses = 2, prerequisites = [[1, 0], [0, 1]]
输出：false
解释：0 依赖 1、1 又依赖 0，循环依赖，无解。
本质问题：课程依赖构成有向图，问的是「图中是否存在环」——有环则顺序无从谈起。

2. 核心思路：拓扑排序（Kahn / BFS）

  1. 建图：有向边 b → a（先修 b 才能修 a），同时统计每门课的入度（先修课数量）
  2. 初始入队：入度为 0 的课程没有未满足的先修要求，可以直接学习 → 全部入队
  3. BFS 学习：出队一门课即"学完"（learned +1）；它指向的每门后继课入度减 1——入度归零意味着先修要求全部满足，解锁入队
  4. 判环：结束后 learned == numCourses 则全部修完（DAG）；否则有课程永远无法入队——它们处在环上
learned == numCourses ⟺ 无环 ⟺ 可完成
环上课程的入度永远无法归零（每个都在等环里的其他人先完成），BFS 自然"绕开"了它们——learned 计数差就是环的规模，无需显式找环。

6. 代码逐段解释

from collections import deque
from typing import List

class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        graph = [[] for _ in range(numCourses)]
        indegree = [0] * numCourses

        for a, b in prerequisites:      # b → a：先学 b 才能学 a
            graph[b].append(a)
            indegree[a] += 1

        queue = deque(i for i in range(numCourses) if indegree[i] == 0)

        learned = 0
        while queue:
            course = queue.popleft()     # 学完一门
            learned += 1
            for next_course in graph[course]:
                indegree[next_course] -= 1   # 少一个先修要求
                if indegree[next_course] == 0:
                    queue.append(next_course)  # 全部满足 → 解锁
        return learned == numCourses

逐段说明

  • 建图方向：[a, b] 表示 a 依赖 b，所以连 b → a；方向反了整张图的入度全错
  • 初始队列：生成器直接筛出所有入度 0 的课——它们是"无门槛课"
  • 解锁条件：入度减到恰好为 0 才入队（减一次查一次，不会重复入队）

7. 复杂度分析

复杂度说明
时间O(V + E)建图扫一遍边，BFS 每个节点出队一次、每条边处理一次
空间O(V + E)邻接表 + 入度数组 + 队列

8. 常见易错点

建边方向写反：[a, b] 是"先 b 后 a"，应连 b → a 并给 a 的入度 +1；写成 a → b 时入度全反，判断恰好颠倒（本题因对称性可能侥幸，但课程表 II 必错）。
重复入队：入队条件必须是「减 1 后恰好等于 0」；若写成「小于等于 0 都入队」会重复计数。
用 visited 而非计数：拓扑排序不需要 visited——入度本身就是访问状态，learned 计数就是答案判据。
忽略重复边：prerequisites 若含重复对 [a,b]，入度会多加；一般题目保证无重边，但工程上可加防御。

9. 总结

  • 转化：课程依赖 → 有向图；能否修完 ⟺ 图无环
  • Kahn 算法：入度 0 入队 → 出队学习 → 后继减入度 → 归零解锁
  • 通用范式：编译依赖、任务编排、构建顺序都是本题换皮
口诀：依赖建图入度随，零度课程先入队；学完削减后继度，学满全部才算对。
