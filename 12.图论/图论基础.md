下面是 **图论基础知识 + BFS / DFS 遍历模板 + 高频技巧**。

图论可以先理解成：

> 图 = 节点 + 边。节点表示事物，边表示事物之间的关系。

图论大部分面试题的核心其实是：

```text
遍历：系统地访问图中所有（或部分）节点 —— BFS 或 DFS
```

也就是：

```text
从一个起点出发，借助边走到能到达的所有地方。
```

---

# 一、什么是图？

- **无向图**：边没有方向（朋友圈：A 和 B 是好友）
- **有向图**：边有方向（关注：A 关注 B，B 未必关注 A）
- **权重图**：边带长度/代价（城市间的距离）
- **连通分量**：无向图中「互相可达」的极大节点集合

网格（二维矩阵）也是图：每个格子是一个节点，上下左右四格是它的邻居。

---

# 二、图的存储方式

## 1. 邻接表（最常用）

```python
# n 个节点，edges = [(u, v), ...]
graph = [[] for _ in range(n)]
for u, v in edges:
    graph[u].append(v)
    graph[v].append(u)   # 无向图加这句；有向图删掉
```

## 2. 网格隐式图

```python
# (x, y) 的邻居 = 上下左右四格
for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
    nx, ny = x + dx, y + dy
    if 0 <= nx < m and 0 <= ny < n:   # 越界检查
        ...
```

# 三、BFS（广度优先搜索）

> 一圈一圈向外扩：先访问起点的所有邻居，再访问邻居的邻居。

数据结构：**队列（FIFO）**。

```python
from collections import deque

def bfs(start):
    queue = deque([start])
    visited = {start}          # 入队时立刻标记，防止重复入队
    while queue:
        node = queue.popleft()
        for nxt in graph[node]:
            if nxt not in visited:
                visited.add(nxt)
                queue.append(nxt)
```

**核心性质：无权图最短路**——BFS 按「距离从小到大」的顺序访问节点，第一次到达某点时的步数就是最短步数。

---

# 四、DFS（深度优先搜索）

> 一条路走到黑，走不动了再回头换路。

数据结构：**递归栈（或显式栈）**。

```python
def dfs(node):
    visited.add(node)
    for nxt in graph[node]:
        if nxt not in visited:
            dfs(nxt)
```

**核心性质：天然适合连通性判断、路径搜索、环检测**——配合回溯还能枚举所有路径。

---

# 五、BFS vs DFS 对照

| 维度 | BFS | DFS |
|------|-----|-----|
| 数据结构 | 队列（FIFO） | 栈 / 递归（LIFO） |
| 访问顺序 | 按距离分层，由近到远 | 一条链走到底再回溯 |
| 最短路 | ✅ 无权图一次遍历即得 | ❌ 首次到达未必最短 |
| 内存 | O(宽度)，最坏 O(n) | O(深度)，递归栈可能溢出 |
| 典型题 | 层序遍历、腐烂橘子、单词接龙 | 岛屿数量、路径枚举、课程表（环检测） |

**选择口诀**：问「最少步数 / 最短距离」用 BFS；问「是否可达 / 有几个连通块 / 所有路径」用 DFS。

# 六、高频技巧

## 1. 分层 BFS（记录当前层数）

```python
queue = deque([start])
visited = {start}
step = 0
while queue:
    for _ in range(len(queue)):      # 关键：一次处理完一整层
        node = queue.popleft()
        ...
    step += 1                        # 一层结束，步数 +1
```

## 2. 双向 BFS / 状态压缩（进阶）

单词接龙类问题可用双向 BFS 把搜索空间开根号；把「已访问集合」编码进状态（如钥匙 bitmask）可解决带上限的图搜索。

## 3. 拓扑排序（Kahn 算法，BFS 实现）

```python
# 课程表：入度减到 0 才能入队
indeg = [0] * n
for u in range(n):
    for v in graph[u]:
        indeg[v] += 1
queue = deque(u for u in range(n) if indeg[u] == 0)
order = []
while queue:
    u = queue.popleft()
    order.append(u)
    for v in graph[u]:
        indeg[v] -= 1
        if indeg[v] == 0:
            queue.append(v)
# len(order) == n → 无环；否则有环
```

## 4. 网格题的 visited 就地标记

网格题常把已访问格子直接改成 `'0'` / `'#'`，省掉 visited 数组。

# 七、易错点

1. **入队时标记 vs 出队时标记**：BFS 推荐「入队时标记」，否则同一节点可能重复入队导致超时
2. **无向图建边要加两次**：`graph[u].append(v)` 和 `graph[v].append(u)` 成对出现
3. **网格越界**：邻居生成后必须检查 `0 <= nx < m and 0 <= ny < n`
4. **递归深度**：Python 默认递归上限约 1000，长链图需 `sys.setrecursionlimit` 或改显式栈
5. **起点即终点**：BFS 求最短路时起点等于目标要返回 0，别漏判
