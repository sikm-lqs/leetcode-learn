2. 数组中的第K个最大元素

用小根堆维护最大的 k 个元素

📋 目录

1. 题目理解

给定整数数组 `nums` 和整数 `k`，返回数组中第 k 个最大的元素。

注意：找的是排序后的第 k 大，而非第 k 个不同的元素。例如数组 [3,3,3,3] 的第 2 大是 3，而不是不存在。

示例

输入：nums = [3,2,1,5,6,4], k = 2
输出：5
解释：升序为 [1,2,3,4,5,6]，第 2 大是 5

输入：nums = [3,2,3,1,2,4,5,5,6], k = 4
输出：4
朴素思路：将数组降序排序，取第 k-1 个元素。时间 O(n log n)。但我们可以用堆做得更好。

2. 核心思路：小根堆

为什么用堆？

我们只关心最大的 k 个元素，不需要完整排序。用大小为 k 的小根堆可以高效维护这 k 个元素：

  • 小根堆的堆顶是堆中最小的元素
  • 堆中始终保持当前最大的 k 个元素
  • 堆顶（这 k 个中的最小值）就是第 k 大

算法流程

  1. 创建空的小根堆
  2. 遍历数组中的每个元素：
    • 将元素加入堆
    • 若堆大小超过 k，弹出堆顶（最小值）
  3. 最终堆顶就是第 k 大的元素
核心洞察：小根堆自动维护"最大的 k 个"。当堆大小超过 k 时，弹出最小的元素，确保堆中只保留最大的 k 个。堆顶就是这 k 个中的最小值，即全局第 k 大。
时间复杂度优势：当 k << n 时（例如 k=2, n=1000000），堆解法远快于全排序。n 次入堆（O(log k)）+ 最多 n 次出堆（O(log k)）= O(n log k) << O(n log n)。

3. 伪代码骨架

import heapq

heap = []                     # 空的小根堆

for num in nums:
    heapq.heappush(heap, num)     入堆

    if 堆大小超过 k:          # len(heap) > k
        heapq.heappop(heap)      弹出堆顶（最小值）

return heap[0]                堆顶即第 k 大
关键字 变量 中文操作 注释公式
heapq 是 Python 的堆模块，默认实现小根堆。heappush 入堆，heappop 出堆（弹出并返回最小值）。

5. 详细过程模拟

以 nums = [3, 2, 1, 5, 6, 4], k = 3 为例，找第 3 大的元素。

初始状态

堆 = []（空）

第 1 步：处理 3

heappush(3) → 堆 = [3]
堆大小 = 1 ≤ 3，不弹出
堆顶 = 3

第 2 步：处理 2

heappush(2) → 堆 = [2, 3]
堆大小 = 2 ≤ 3，不弹出
堆顶 = 2

第 3 步：处理 1

heappush(1) → 堆 = [1, 3, 2]
堆大小 = 3 ≤ 3，不弹出
堆顶 = 1

第 4 步：处理 5

heappush(5) → 堆 = [1, 3, 2, 5]
堆大小 = 4 > 3，弹出堆顶 1 → 堆 = [2, 3, 5]
堆顶 = 2
弹出 1 是因为：我们要保留最大的 3 个元素。1 太小，不在前 3 名。

第 5 步：处理 6

heappush(6) → 堆 = [2, 3, 5, 6]
堆大小 = 4 > 3，弹出堆顶 2 → 堆 = [3, 5, 6]
堆顶 = 3

第 6 步：处理 4

heappush(4) → 堆 = [3, 4, 5, 6]
堆大小 = 4 > 3，弹出堆顶 3 → 堆 = [4, 5, 6]
堆顶 = 4
最终结果：堆 = [4, 5, 6]，堆顶 = 4，即第 3 大的元素 ✅

6. 代码逐段解释

完整代码

import heapq
from typing import List

class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        heap = []
        for num in nums:
            heapq.heappush(heap, num)
            if len(heap) > k:
                heapq.heappop(heap)
        return heap[0]

逐段说明

第 1 步：导入堆模块

import heapq

heapq 是 Python 标准库的堆模块，默认实现小根堆。

第 2 步：初始化空堆

heap = []

创建一个空列表，heapq 会将其视为堆。

第 3 步：遍历数组

for num in nums:
    heapq.heappush(heap, num)

将每个元素加入堆，heappush 的时间复杂度是 O(log k)。

第 4 步：维护堆大小

if len(heap) > k:
    heapq.heappop(heap)

如果堆大小超过 k，弹出堆顶（最小的元素）。heappop 的时间复杂度是 O(log k)。

第 5 步：返回结果

return heap[0]

堆顶（索引 0）就是第 k 大的元素。

关键：小根堆的 heap[0] 永远是最小元素。由于我们始终保留最大的 k 个，堆顶就是这 k 个中的最小值，即全局第 k 大。

7. 复杂度分析

维度值说明
时间复杂度O(n log k) n 次入堆，最多 n 次出堆，每次 O(log k)
空间复杂度O(k) 堆的大小最多为 k
优势：当 k << n 时（例如找第 2 大），堆解法明显快于全排序。当 k 接近 n 时，退化为 O(n log n)，与排序相当。

8. 解法对比

解法时间复杂度空间复杂度特点
全排序O(n log n)O(1) 或 O(n)简单直接，适合任意 k
小根堆O(n log k)O(k)k << n 时最优，本文解法
快速选择平均 O(n)，最坏 O(n²)O(1)期望线性，需要实现分区
选择建议：
  • 代码简洁、k 较小 → 用小根堆（本文解法）
  • 追求平均最优、能接受最坏情况 → 用快速选择
  • 只需要一次调用、不想引入额外依赖 → 用全排序

9. 总结

第 K 个最大元素 解法精髓：

  • 用小根堆维护当前最大的 k 个元素
  • 堆大小超过 k 时弹出堆顶（最小值）
  • 堆顶就是这 k 个中的最小值，即全局第 k 大
  • 时间 O(n log k)，空间 O(k)
  • 当 k << n 时，明显快于全排序
