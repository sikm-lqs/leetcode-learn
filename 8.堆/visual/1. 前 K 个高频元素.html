1. 前 K 个高频元素

哈希表统计频率 + 小根堆维护前k个高频元素

1. 题目理解

给定整数数组 `nums` 和整数 `k`，返回其中出现频率前 `k` 高的元素。可以按任意顺序返回答案。

注意：返回的是按频率排序的前 k 个元素，而非第 k 个高频元素。例如 [1,1,1,2,2,3] 的前 2 高频元素是 [1, 2]，频率分别是 3 和 2。

示例

输入：nums = [1,1,1,2,2,3], k = 2
输出：[1, 2]
解释：元素 1 出现 3 次，元素 2 出现 2 次，元素 3 出现 1 次

输入：nums = [1], k = 1
输出：[1]
朴素思路：统计所有元素的频率，按频率降序排序，取前 k 个。时间 O(n log n)。当 k 较小时，可以优化。

2. 核心思路：哈希表 + 堆

为什么用堆？

我们只关心频率最高的 k 个元素，不需要完整排序。分两步：

  1. 哈希表统计频率：O(n) 时间遍历数组，统计每个元素出现次数
  2. 小根堆维护前 k 个：将 [频率, 元素] 对入堆，保持堆大小为 k

算法流程

  1. 用哈希表统计每个元素的频率
  2. 遍历哈希表，将 [频率, 元素] 对加入小根堆
  3. 若堆大小超过 k，弹出堆顶（频率最低的元素）
  4. 最终堆中剩余的就是前 k 个高频元素
核心洞察：小根堆按频率排序，堆顶是频率最低的。当堆大小超过 k 时弹出堆顶，确保堆中只保留频率最高的 k 个元素。最后提取所有元素即可。
时间复杂度优势：统计频率 O(n)，堆操作 O(n log k)。当 k << n 时，明显优于全排序 O(n log n)。

5. 详细过程模拟

以 nums = [1,1,1,2,2,3], k = 2 为例。

第1步：统计频率

遍历数组，用哈希表统计频率：
freq = {
  1: 3,  # 元素1出现3次
  2: 2,  # 元素2出现2次
  3: 1   # 元素3出现1次
}

第2步：处理元素 1（频率3）

heappush([3, 1]) → 堆 = [[3, 1]]
堆大小 = 1 ≤ 2，不弹出

第3步：处理元素 2（频率2）

heappush([2, 2]) → 堆 = [[2, 2], [3, 1]]
堆大小 = 2 ≤ 2，不弹出

第4步：处理元素 3（频率1）

heappush([1, 3]) → 堆 = [[1, 3], [3, 1], [2, 2]]
堆大小 = 3 > 2，弹出堆顶 [1, 3]
堆 = [[2, 2], [3, 1]]
弹出元素 3（频率1）是因为我们只要频率最高的 2 个元素。元素 3 频率太低，不在前 2 名。

第5步：提取结果

堆中剩余：[[2, 2], [3, 1]]
提取元素：[2, 1]（顺序可能不同）
最终结果：[1, 2]（或 [2, 1]）✅

6. 代码逐段解释

完整代码

import heapq
from typing import List

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        # 第1步：统计频率
        freq = {}
        for num in nums:
            freq[num] = freq.get(num, 0) + 1

        # 第2步：用小根堆维护前 k 个高频元素
        heap = []
        for num, count in freq.items():
            heapq.heappush(heap, [count, num])
            if len(heap) > k:
                heapq.heappop(heap)

        # 第3步：提取堆中的元素
        return [item[1] for item in heap]

将 [频率, 元素] 对入堆。注意频率在前，作为排序键。

第 3 步：提取结果

7. 复杂度分析

维度值说明
时间复杂度O(n log k) 统计频率 O(n) + 堆操作 O(n log k)
空间复杂度O(n) 哈希表 O(n) + 堆 O(k)
优势：当 k << n 时（例如找前 10 个高频），明显快于全排序 O(n log n)。

8. 解法对比

解法时间复杂度空间复杂度特点
哈希表 + 排序O(n log n)O(n)简单直接，适合任意 k
哈希表 + 堆O(n log k)O(n)k << n 时最优，本文解法
桶排序O(n)O(n)需要知道频率范围，实现复杂
选择建议：
  • 代码简洁、k 较小 → 用堆（本文解法）
  • 追求线性时间、知道频率范围 → 用桶排序
  • 只需要一次调用 → 用哈希表 + 排序

9. 总结

前 K 个高频元素 解法精髓：

  • 哈希表统计频率：O(n) 时间遍历数组
  • 小根堆维护前 k 个：按频率排序，超限时弹出最低频
  • 将 [频率, 元素] 对入堆，频率作为排序键
  • 时间 O(n log k)，空间 O(n)
  • 当 k << n 时，明显快于全排序
import heapq
class Solution:
    def topKFrequent(self, nums, k):
        # 统计频率
        freq = {}
        for num in nums:
            freq[num] = freq.get(num, 0) + 1

        # 堆维护前k个
        heap = []
        for num, count in freq.items():
            heapq.heappush(heap, [count, num])
            if len(heap) > k:
                heapq.heappop(heap)

        return [item[1] for item in heap]

💡 口诀：哈希统计频率，堆顶最小频。超限即弹出，前k自然成。
