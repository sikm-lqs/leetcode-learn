# 三、字符串和数组的一个重要区别

字符串和列表很像，但有一个重要区别：

> Python 字符串不可修改。

例如：

```python
s = "hello"
s[0] = "H"
```

这会报错。

如果你想修改字符串，通常要先转成列表：

```python
s = "hello"

arr = list(s)
arr[0] = "H"

s = "".join(arr)
print(s)  # Hello
```

所以要记住：

```text
字符串不能原地修改
列表可以原地修改
```

# 九、字符串题核心技巧一：哈希表计数

字符串题中，最常见的是统计字符出现次数。

适合：

* 判断字母异位词
* 找第一个只出现一次的字符
* 字符频率统计
* 分组字母异位词
* 最小覆盖子串

---

## 1. 用字典统计字符

```python
s = "banana"

cnt = {}

for ch in s:
    cnt[ch] = cnt.get(ch, 0) + 1

print(cnt)
```

输出：

```python
{'b': 1, 'a': 3, 'n': 2}
```

核心写法：

```python
cnt[ch] = cnt.get(ch, 0) + 1
```

---

## 2. 用 `Counter`

```python
from collections import Counter

s = "banana"

cnt = Counter(s)

print(cnt)
```

输出：

```python
Counter({'a': 3, 'n': 2, 'b': 1})
```

判断两个字符串是否为字母异位词：

```python
from collections import Counter

def isAnagram(s, t):
    return Counter(s) == Counter(t)
```

---

## 3. 只包含小写字母时，用数组计数

如果题目说只包含 `'a'` 到 `'z'`，可以用长度为 26 的数组：

```python
cnt = [0] * 26

for ch in s:
    idx = ord(ch) - ord('a')
    cnt[idx] += 1
```

这里：

```python
ord('a')  # 97
ord('b')  # 98
```

所以：

```python
ord(ch) - ord('a')
```

可以把字母映射到 `0 ~ 25`。

# 十、字符串题核心技巧二：双指针

双指针适合：

* 回文串
* 反转字符串
* 删除字符
* 压缩字符串
* 字符串比较

---

## 1. 判断回文串

回文串就是正着读和反着读一样。

例如：

```text
aba
abba
上海自来水来自海上
```

模板：

```python
def isPalindrome(s):
    left = 0
    right = len(s) - 1

    while left < right:
        if s[left] != s[right]:
            return False
        left += 1
        right -= 1

    return True
```

---

## 2. 忽略大小写和非字母数字

例如 LeetCode 125：验证回文串。

```python
def isPalindrome(s):
    left = 0
    right = len(s) - 1

    while left < right:
        while left < right and not s[left].isalnum():
            left += 1
        while left < right and not s[right].isalnum():
            right -= 1

        if s[left].lower() != s[right].lower():
            return False

        left += 1
        right -= 1

    return True
```

核心：

```text
左指针跳过无效字符
右指针跳过无效字符
比较小写后的字符
```

# 十一、字符串题核心技巧三：滑动窗口

滑动窗口是字符串题最重要的技巧之一。

适合：

* 最长无重复子串
* 最小覆盖子串
* 找所有字母异位词
* 长度固定的子串统计
* 最长重复字符替换

---

## 1. 滑动窗口基础模板

```python
left = 0
window = {}

for right in range(len(s)):
    ch = s[right]

    # 加入右边字符
    window[ch] = window.get(ch, 0) + 1

    while 窗口不满足条件:
        left_ch = s[left]
        window[left_ch] -= 1
        left += 1

    # 更新答案
```

核心思想：

```text
right 扩大窗口
left 缩小窗口
window 记录窗口内的信息
```

---

## 2. 最长无重复子串

题目：

> 给一个字符串，找不含重复字符的最长子串长度。

```python
def lengthOfLongestSubstring(s):
    seen = set()
    left = 0
    ans = 0

    for right in range(len(s)):
        while s[right] in seen:
            seen.remove(s[left])
            left += 1

        seen.add(s[right])
        ans = max(ans, right - left + 1)

    return ans
```

核心思想：

```text
窗口中不能有重复字符
如果右边字符已经出现，就不断移动 left
```

---

## 3. 找到字符串中所有字母异位词

题目：

> 在 s 中找到所有 p 的异位词子串起始下标。

```python
from collections import Counter

def findAnagrams(s, p):
    ans = []
    need = Counter(p)
    window = Counter()
    left = 0

    for right in range(len(s)):
        window[s[right]] += 1

        if right - left + 1 > len(p):
            window[s[left]] -= 1
            if window[s[left]] == 0:
                del window[s[left]]
            left += 1

        if window == need:
            ans.append(left)

    return ans
```

核心：

```text
固定长度窗口
窗口长度等于 len(p)
比较窗口计数和目标计数
```

# 十二、字符串题核心技巧四：栈

字符串题中，栈经常用于：

* 括号匹配
* 删除相邻重复字符
* 解码字符串
* 简化路径
* 表达式处理

---

## 1. 有效括号

```python
def isValid(s):
    stack = []
    pairs = {
        ")": "(",
        "]": "[",
        "}": "{"
    }

    for ch in s:
        if ch in "([{":
            stack.append(ch)
        else:
            if not stack or stack[-1] != pairs[ch]:
                return False
            stack.pop()

    return not stack
```

核心：

```text
左括号入栈
右括号检查栈顶是否匹配
最后栈必须为空
```

---

## 2. 删除相邻重复字符

例如：

```text
abbaca -> ca
```

代码：

```python
def removeDuplicates(s):
    stack = []

    for ch in s:
        if stack and stack[-1] == ch:
            stack.pop()
        else:
            stack.append(ch)

    return "".join(stack)
```

# 十三、字符串题核心技巧五：排序

排序常用于：

* 判断字母异位词
* 字母异位词分组
* 重新排列字符串

---

## 1. 判断异位词

```python
def isAnagram(s, t):
    return sorted(s) == sorted(t)
```

例如：

```python
sorted("eat")  # ['a', 'e', 't']
sorted("tea")  # ['a', 'e', 't']
```

时间复杂度：

```text
O(n log n)
```

如果用计数，通常是：

```text
O(n)
```

---

## 2. 字母异位词分组

```python
from collections import defaultdict

def groupAnagrams(strs):
    groups = defaultdict(list)

    for word in strs:
        key = "".join(sorted(word))
        groups[key].append(word)

    return list(groups.values())
```

核心：

```text
异位词排序后结果相同
用排序后的字符串作为 key
```

# 十四、字符串题核心技巧六：前缀思想

字符串题中的前缀思想常见于：

* 最长公共前缀
* 前缀匹配
* Trie 字典树
* KMP 字符串匹配

入门阶段先掌握最长公共前缀。

---

## 最长公共前缀

```python
def longestCommonPrefix(strs):
    if not strs:
        return ""

    prefix = strs[0]

    for s in strs[1:]:
        while not s.startswith(prefix):
            prefix = prefix[:-1]
            if not prefix:
                return ""

    return prefix
```

核心思想：

```text
先假设第一个字符串是公共前缀
不断缩短 prefix
直到所有字符串都以它开头
```

# 十五、字符串题核心技巧七：模拟

很多字符串题没有特别高级算法，就是按照规则模拟。

常见题：

* 字符串相加
* 反转单词
* Z 字形变换
* 罗马数字转整数
* 整数转罗马数字
* 字符串压缩

---

## 例子：反转字符串中的单词

```python
def reverseWords(s):
    words = s.split()
    words.reverse()
    return " ".join(words)
```

例如：

```python
s = "  hello   world  "
print(reverseWords(s))  # world hello
```

这里：

```python
s.split()
```

会自动去掉多余空格，并按空白分割。

---

## 例子：字符串相加

不能直接转整数时：

```python
def addStrings(num1, num2):
    i = len(num1) - 1
    j = len(num2) - 1
    carry = 0
    ans = []

    while i >= 0 or j >= 0 or carry:
        x = int(num1[i]) if i >= 0 else 0
        y = int(num2[j]) if j >= 0 else 0

        total = x + y + carry
        ans.append(str(total % 10))
        carry = total // 10

        i -= 1
        j -= 1

    return "".join(ans[::-1])
```

核心：

```text
从个位开始加
用 carry 保存进位
最后反转答案
```

```python
        stack.append(ch)
    else:
        # 处理栈顶
        stack.pop()

return "".join(stack)
```

## 模板 9：从后往前模拟加法

```python
i = len(num1) - 1
j = len(num2) - 1
carry = 0
ans = []

while i >= 0 or j >= 0 or carry:
    x = int(num1[i]) if i >= 0 else 0
    y = int(num2[j]) if j >= 0 else 0

    total = x + y + carry
    ans.append(str(total % 10))
    carry = total // 10

    i -= 1
    j -= 1

return "".join(ans[::-1])
```

# 二十、字符串题最容易错的地方

---

## 1. 想直接修改字符串

错误：

```python
s[0] = "A"
```

正确：

```python
arr = list(s)
arr[0] = "A"
s = "".join(arr)
```

---

## 2. 大量循环中用 `+=` 拼接字符串

不推荐：

```python
ans = ""

for ch in s:
    ans += ch
```

推荐：

```python
ans = []

for ch in s:
    ans.append(ch)

return "".join(ans)
```

---

## 3. 忘记处理空字符串

错误：

```python
return s[0]
```

如果 `s = ""`，会报错。

应该：

```python
if not s:
    return ""
```

---

## 4. `split(" ")` 和 `split()` 混淆

```python
s = "  hello   world  "
```

使用：

```python
s.split()
```

结果：

```python
['hello', 'world']
```

使用：

```python
s.split(" ")
```

可能得到很多空字符串：

```python
['', '', 'hello', '', '', 'world', '', '']
```

刷题中反转单词时通常用：

```python
s.split()
```

---

## 5. 忘记删除 Counter 中为 0 的键

滑动窗口中，如果你要比较两个字典：

```python
window == need
```

那么当某个字符计数变成 0 时，最好删除：

```python
window[ch] -= 1
if window[ch] == 0:
    del window[ch]
```

否则可能导致比较失败。

---

## 6. 字符和数字混淆

```python
'1' + '2'  # '12'
1 + 2      # 3
```

如果要计算数字，要用：

```python
int(ch)
```

如果要转回字符：

```python
str(num)
```
