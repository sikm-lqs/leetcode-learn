4. 找到字符串中所有字母异位词

找到 s 中所有 p 的异位词子串的起始索引。

1. 题目理解

给定字符串 s 和 p，找出 s 中所有作为 p 的异位词的子串，返回它们的起始索引。异位词即字母频率完全相同、顺序不同的串。

示例

输入：s = "cbaebabacd", p = "abc"
输出：[0, 6]
解释："cba"（索引 0）和 "bac"（索引 6）都是 "abc" 的异位词
cbaebabacd "cba" → 起始索引 0
cbaebabacd "bac" → 起始索引 6
关键观察：异位词子串的长度必然等于 len(p)。所以只需在 s 上滑动一个固定大小为 len(p) 的窗口，逐个比较窗口内字符频率与 p 是否相同。

2. 核心思路：定长滑动窗口

与「最小覆盖子串」的变长窗口不同，本题窗口大小固定为 len(p)，逻辑大大简化：右进左出即可平移窗口。

两个频率数组（长度 26）

  • need[26]：p 中每个字母的出现次数
  • window[26]：当前窗口中每个字母的出现次数
右扩：window[s[right]]++
超长即左缩：若 right−left+1 > len(p)，window[s[left]]−−，left++
命中：window == need（两数组逐元素相等）→ 记录 left
核心洞察：用长度 26 的数组而非字典存频率，可直接 window == need 整体比较（Python 逐元素判等）。定长保证窗口元素总数始终 = len(p)，频率匹配即异位词，无需额外维护 valid 计数。

6. 代码逐段解释

class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        res = []

        # p 的字符频率（26 个小写字母）
        need = [0] * 26
        for c in p:
            need[ord(c) - ord('a')] += 1

        window = [0] * 26
        left = 0

        for right in range(len(s)):
            # 右端字符进入窗口
            window[ord(s[right]) - ord('a')] += 1

            # 窗口超过 p 的长度，左端移出，保持定长
            if right - left + 1 > len(p):
                window[ord(s[left]) - ord('a')] -= 1
                left += 1

            # 两数组逐元素相等 → 是异位词
            if window == need:
                res.append(left)
        return res

need = [0] * 26：用数组而非字典统计 p 的频率，便于直接整体 == 比较。

window[ord(s[right]) - ord('a')] += 1：右端字符入窗。ord(c) - ord('a') 把字母映射到 0–25 的索引。

if right - left + 1 > len(p)：定长窗口的关键。一旦窗口比 p 长，立刻移出左端、left++，把窗口大小锁死在 len(p)。注意是 if 不是 while——每轮最多超长 1 个，移出一个即可。

if window == need：Python 直接比较两个列表是否所有元素相等。定长保证了窗口元素总数 = len(p)，所以频率匹配即异位词，记录此时的 left。

前 len(p)-1 步窗口长度不足，window 元素总数 < need，== 必然为假，不会误记录。

7. 复杂度分析

维度值说明
时间复杂度O(m)right 遍历 s 一次（m 步），每步一次 O(26) 的数组比较，整体 O(26m) = O(m)
空间复杂度O(1)need 与 window 各固定 26 个元素
若把 window == need 换成维护一个 matched 计数（频率达标种类数），可把每次比较从 O(26) 降到 O(1)；但 26 是常数，直接比较已足够快，代码更简洁。

8. 常见易错点

错误：用 while 而非 if 收缩

定长窗口每轮最多超长 1 个字符，用 if 移出一个即可；写成 while 虽不出错但多余。区别于变长窗口（如最小覆盖子串）需要 while 持续收缩。

错误：忘记窗口定长，直接比较

若不先移出左端，窗口会越来越长，window == need 几乎永远为假（元素总数不等）。必须保持窗口 = len(p)。

错误：用字典却想直接 ==

字典的 == 不考虑值为 0 的键，可能误判。用长度 26 的数组（含 0）比较才严谨。

边界：len(s) < len(p)

窗口永远填不满，window == need 恒为假，返回空列表 []。

9. 总结

找到字符串中所有字母异位词 解法精髓：

  • 定长窗口：窗口大小恒为 len(p)，右进左出平移
  • 数组计数：用 [0]*26 存频率，可直接 == 比较
  • 命中即记：window == need 时记录 left
  • 时间 O(m)，空间 O(1)

💡 口诀：窗口定长等于 p，右进左出平移走；频率数组直接比，相等即记起始索引。
