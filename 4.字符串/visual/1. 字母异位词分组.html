1. 字母异位词分组

为每个字符串算一个「字母计数指纹」，指纹相同即为异位词，归入同一组。

1. 题目理解

给定字符串数组 strs，把字母异位词组合在一起。字母异位词指字母相同、排列不同的字符串（如 "eat" / "tea" / "ate"）。结果顺序任意。

示例

输入：strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出：[["bat"], ["nat", "tan"], ["ate", "eat", "tea"]]
解释：
  "eat" "tea" "ate" → 字母都是 {a, e, t}，归一组
  "tan" "nat"       → 字母都是 {a, n, t}，归一组
  "bat"             → 字母是 {a, b, t}，自成一组
关键观察：异位词与字母顺序无关，只与「每个字母出现几次」有关。所以只要能为每个字符串生成一个与顺序无关的指纹，指纹相同的串就是异位词。

2. 核心思路：计数指纹 + 哈希分组

用哈希表 groups 一次性分组：key 是指纹，value 是同组原始字符串列表。

指纹怎么造？—— 26 元计数数组

  • 开一个长度 26 的数组 count，count[i] 表示第 i 个字母（a–z）在该串中出现几次。
  • 遍历串的每个字符 c： count[ord(c) - ord('a')] += 1。
  • 异位词的 count 数组逐元素相同。
key = tuple(count)
groups[key].append(s)  # 指纹相同 → 同一组
核心洞察：把「是否为异位词」这个等价关系，编码成一个可哈希的指纹。哈希表天然把相同 key 的元素归到一起，于是分组只需一次遍历。
为什么是 tuple 而不是 list？Python 中 list 是可变的、不可哈希，不能作字典的 key；tuple(count) 把它转成不可变、可哈希的形式，才能拿去当 groups 的 key。

5. 详细过程模拟

以 strs = ["eat", "tea", "tan", "ate", "nat", "bat"] 为例。注意 "eat" / "tea" / "ate" 字符顺序不同，但累计出的指纹都是 a:1 e:1 t:1——这正是它们被归到同一组的原因。

字符串逐字符累计指纹 key动作该组累计
eate×1 → a×1 → t×1a:1 e:1 t:1🆕 新建组①{eat}
teat×1 → e×1 → a×1a:1 e:1 t:1➕ 加入组①（指纹已存在）{eat, tea}
tant×1 → a×1 → n×1a:1 n:1 t:1🆕 新建组②{tan}
atea×1 → t×1 → e×1a:1 e:1 t:1➕ 加入组①{eat, tea, ate}
natn×1 → a×1 → t×1a:1 n:1 t:1➕ 加入组②{tan, nat}
batb×1 → a×1 → t×1a:1 b:1 t:1🆕 新建组③{bat}

三种指纹 → 三组：a:1 e:1 t:1、a:1 n:1 t:1、a:1 b:1 t:1。

最终结果：[["eat","tea","ate"], ["tan","nat"], ["bat"]] ✅（组内顺序、组间顺序均可任意）

6. 代码逐段解释

from collections import defaultdict
from typing import List

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = defaultdict(list)

        for s in strs:
            count = [0] * 26

            for char in s:
                count[ord(char) - ord('a')] += 1

            key = tuple(count)
            groups[key].append(s)

        return list(groups.values())

groups = defaultdict(list)：用 defaultdict 而非普通 dict，访问不存在的 key 时自动初始化为空列表，省去 if key not in groups 的判空。

count = [0] * 26：每个字符串都新建一个干净的计数数组。下标 ord(char) - ord('a') 把 a–z 映射到 0–25。

key = tuple(count)：全题最关键的一行。list 不可哈希、不能当字典 key，tuple() 把它转成可哈希的等价形式。指纹相同 ⇔ 异位词。

groups[key].append(s)：指纹相同的字符串 key 相同，自然聚到同一组。

return list(groups.values())：dict.values() 返回的是视图，list() 转成题目要求的列表的列表。

把 key = tuple(count) 换成 key = ''.join(sorted(s)) 就是排序法，代码更短但单串 O(k log k)；计数法是 O(k)。

7. 复杂度分析

维度值说明
时间复杂度O(n·k)n 个字符串，每个整体遍历一次（最长为 k）；tuple(count) 复制 26 个元素为 O(1)。总计 O(n·k)。
空间复杂度O(n·k)分组中存了全部字符串 O(n·k)；n 个 key 各占 O(1)，共计 O(n)，被字符串部分主导。
字母表大小 26 是常数，所以「生成 key」与「比较 key」都是 O(1)。若字符集变大（Unicode），需改用字典统计或哈希指纹。

8. 常见易错点

错误：直接拿 list 当 key

写 groups[count] 会抛 TypeError: unhashable type: 'list'。list 可变、不可哈希，必须 key = tuple(count)。这是本题最常见的坑。

错误：以为必须排序

排序法 key = ''.join(sorted(s)) 也正确，但单串需 O(k·log k)；计数法是 O(k)，对长串更优。两者本质都是「生成等价类指纹」。

错误：用普通 dict 忘了判空

若 groups = {}，直接 groups[key].append(s) 会 KeyError。需 if key not in groups: groups[key] = []；用 defaultdict(list) 可省去这一步。

边界：字符集假设

ord(c) - ord('a') 仅适用 26 个小写字母。若输入含大写或其他字符，需改用字典统计（defaultdict(int)）并把字典转成可哈希的 frozenset 或排序 tuple。

9. 总结

字母异位词分组 解法精髓：

  • 等价类指纹：用 26 元计数数组刻画「字母构成」，与顺序无关
  • tuple 化：把不可哈希的 list 转成可哈希的 tuple 才能当 key
  • 哈希分组：defaultdict(list) 一次遍历，相同 key 自动聚拢
  • 时间 O(n·k)，空间 O(n·k)

💡 口诀：计数成指纹，tuple 作键存；同纹即异位，一遍分好群。
