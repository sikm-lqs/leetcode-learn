下面是 **二叉树基础知识 + 遍历模板 + 递归三步曲**。

二叉树可以先理解成：

> 每个节点最多有两个孩子的「分叉结构」，递归定义：树 = 根 + 左子树 + 右子树。

英文是：

```text
Binary Tree：每个节点至多有两个子节点
```

也就是：

```text
处理一棵树 = 处理根节点 + 处理两棵更小的树
```

# 一、基本术语

```text
        1          ← 根（root）
       / \
      2   3        ← 深度为 2 的一层
     / \   \
    4   5   6      ← 叶子（leaf：无孩子）
```

- **深度**：从根往下数，根的深度为 1
- **高度**：从叶子往上数，叶子高度为 1（「最大深度」=「高度」是一回事，只是视角不同）
- **叶子节点**：左右孩子都为空
- **满二叉树**：每层都填满；**完全二叉树**：只许最后一层从右往右缺

# 二、递归遍历四件套

访问根的时机决定遍历名称：

```python
def traverse(node):
    if node is None:          # 终止条件
        return
    # 前序：此处访问 node.val
    traverse(node.left)
    # 中序：此处访问 node.val
    traverse(node.right)
    # 后序：此处访问 node.val
```

| 遍历 | 顺序 | 记忆点 |
|------|------|--------|
| 前序 | 根 → 左 → 右 | 进入节点时做事 |
| 中序 | 左 → 根 → 右 | BST 中序 = 升序序列 |
| 后序 | 左 → 右 → 根 | 离开节点时做事（自底向上） |
| 层序 | 一层一层 | 用队列（BFS），不属于递归家族 |

# 三、递归三步曲（写树题的万能框架）

1. **确定函数含义**：`f(node)` 返回什么？（如「以 node 为根的树的最大深度」）
2. **确定终止条件**：`node is None` 时返回什么？（深度 0 / True / None……）
3. **确定单层逻辑**：假设左右子问题已有答案，如何组合出当前答案？

```python
# 例：最大深度
def maxDepth(node):
    if node is None:                      # 终止
        return 0
    return max(maxDepth(node.left),       # 左
               maxDepth(node.right)) + 1  # 右 + 根
```

# 四、两种递归思维

| 思维 | 形态 | 例子 |
|------|------|------|
| **自底向上**（分解问题） | 返回值逐层上传，利用子树答案 | 最大深度、直径、翻转 |
| **自顶向下**（传递信息） | 参数把上层信息带下去 | 路径总和、深度标注 |

判断技巧：**需要"左右子树答案汇合"的用返回值**（直径 = 左深 + 右深）；**只需要"从根传下去"的用参数**。

# 五、层序遍历（BFS）模板

```python
from collections import deque

def levelOrder(root):
    if root is None:
        return []
    queue = deque([root])
    res = []
    while queue:
        level = []
        for _ in range(len(queue)):    # 一次取完一整层
            node = queue.popleft()
            level.append(node.val)
            if node.left:  queue.append(node.left)
            if node.right: queue.append(node.right)
        res.append(level)
    return res
```

# 六、复杂度通式

- **时间**：O(n) —— 每个节点访问一次（n 为节点总数）
- **空间**：O(h) —— 递归栈深度 = 树高 h；平衡树 O(log n)，链状树 O(n)

# 七、易错点

1. **忘写终止条件**：`node is None` 不返回，无限递归
2. **None 陷阱**：`node.left` 在 node 为 None 时报 AttributeError——先判空再取孩子
3. **nonlocal**：递归内更新外层变量必须声明 `nonlocal ans`，否则是局部新变量
4. **深度 vs 直径**：深度数「节点」，直径数「边」——直径 = 左深 + 右深（两条边在根处拼接）
5. **修改树时返回根**：翻转/合并题要记得返回节点本身，父层才能接上
