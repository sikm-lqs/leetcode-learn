9. 二叉树的层序遍历

len(queue) 定格一层：BFS 分层模板的万能钥匙。

1. 题目理解

给你二叉树的根节点 root，返回其节点值的层序遍历（即逐层地，从左到右访问所有节点）。

示例

输入：root = [3, 9, 20, null, null, 15, 7]
        3
       / \
      9  20
         / \
        15  7
输出：[[3], [9, 20], [15, 7]]

输入：root = [1]
输出：[[1]]

输入：root = []
输出：[]
层序 ≠ 前中后序（它们沿一条链深入，属于 DFS）；层序按「离根的距离」一圈圈向外访问，天然需要队列。

2. 核心思路：一次取完一整层

  1. 根入队：队列初始化 deque([root])；空树提前返回 []
  2. 层定格：每轮 while 开始时，len(queue) 恰好是当前层的节点总数——先把这个数「拍下来」
  3. 整层出队：for _ in range(len(queue)) 只循环定格次数：出队 → 记入 level → 左右孩子（非空才）入队。本轮新入队的孩子属于下一层，不影响本轮循环次数
  4. 收集：level 完整后加入 res，进入下一轮 while
每轮开始：队列里 = 完整的一层 ⟹ len(queue) 就是层大小
为什么这样恰好分层？出队 n 个旧节点会带入至多 2n 个新节点，但 for 的次数在循环开始时就固定了——新节点安静地排在队尾等下一轮，层次边界自动形成。

这套「while + for range(len(queue))」骨架是所有分层 BFS 题的公共模板——求每层最右值、锯齿遍历、最小深度等只改 level 的用法，框架一字不动。

6. 代码逐段解释

from collections import deque

class Solution:
    def levelOrder(self, root) -> List[List[int]]:
        if not root:
            return []                      # 空树直接返回

        queue = deque([root])              # 1. root 放进队列
        res = []

        while queue:                       # 2. 队列非空
            level = []

            # 当前层有多少节点（循环开始时定格）
            for _ in range(len(queue)):    # 3. 取出整层
                node = queue.popleft()     # O(1) 出队
                level.append(node.val)

                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

            res.append(level)              # 4. level 加入 res

        return res

逐段说明

  • deque + popleft：双端队列头部出队 O(1)；用 list 的 pop(0) 是 O(n)，会整体超时
  • 入队前判空：if node.left 挡住 None，队列里永远只有真实节点，省去出队后的判空
  • len(queue) 的时机：写在 range() 里在 for 启动时求值一次——之后队列怎么变都不影响本轮次数

7. 复杂度分析

复杂度说明
时间O(n)每个节点入队一次、出队一次
空间O(w)队列最多同时容纳最宽一层的节点（w ≤ n，平衡树 w ≈ n/2）

8. 常见易错点

用 list.pop(0) 当队列：头部出队是 O(n)，总复杂度退化到 O(n²)；必须 deque.popleft()。
while 里逐个出队不分层：去掉内层 for 后得到的是一条「平铺序列」[3,9,20,15,7]，不是分层的嵌套列表。
把 len(queue) 写进 while 条件外反复求值：若用 while len(queue) > 0 逐个出队再手动判断层边界，逻辑复杂易错——定格 for 次数是最简写法。
空树崩溃：root 为 None 时不提前返回，deque([None]) 会在 node.val 处 AttributeError。

9. 总结

  • 模板：while 队列非空 → for range(len(queue)) 取整层 → 收集 level
  • 灵魂：循环开始时 len(queue) = 当前层大小，新入队的孩子属于下一层
  • 迁移：右视图（取 level[-1]）、锯齿（隔层反转 level）、最小深度（首叶子返回）全是这套骨架
口诀：队列先装根，循环看层深；定格一层数，取完再收层。
