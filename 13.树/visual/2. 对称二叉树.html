2. 对称二叉树

双参数递归：镜像成对比较，外侧对外侧、内侧对内侧。

1. 题目理解

给你一个二叉树的根节点 root，检查它是否轴对称。

示例

输入：root = [1, 2, 2, 3, 4, 4, 3]
输出：true
解释：沿根竖一条轴，左右子树互为镜像。

输入：root = [1, 2, 2, null, 3, null, 3]
输出：false
解释：左子树的右孩子是 3，右子树的左孩子才是 3——位置对不上。
对称的严格定义：左子树沿轴翻转后与右子树完全相同（结构与值都相同）。

2. 核心思路：镜像节点配对

  1. 配对：从根的左右孩子开始，每次比较一对镜像节点 check(left, right)
  2. 四情况判定：
    • 都为空 → True（两边都没东西，对称）
    • 只有一个为空 → False（一边有一边没有，不对称）
    • 值不等 → False
    • 值相等 → 递归：外侧对 check(l.left, r.right) 内侧对 check(l.right, r.left)，两者都成立才对称
  3. 合取：return check(外侧) and check(内侧)——短路求值，一假即假
关键视角转换：普通遍历比较的是「同一分支」的节点，这里比较的是「跨轴」的两条路径——左的最左对应右的最右（外侧），左的靠内对应右的靠内（内侧）。

def 检查(left, right):

5. 详细过程模拟

配对 (left, right)判定过程结论
(2, 2)都非空，值相等 → 继续检查外侧对与内侧对待递归
(3, 3) 外侧左子树的左孩子 vs 右子树的右孩子：都非空，值相等；两者的孩子都为空 → True✓
(4, 4) 内侧左子树的右孩子 vs 右子树的左孩子：值相等；孩子都空 → True✓
合取True and True → 整棵树对称True ✅
反例 [1,2,2,null,3,null,3]：内侧对是 (null, 3)——「只有一个为空」命中第二条判定直接 False，短路返回。

6. 代码逐段解释

class Solution:
    def isSymmetric(self, root) -> bool:
        # 对称 = 根节点值相等 + 外侧对外侧 + 内侧对内侧。递归的思想
        def check(left, right):
            # 1.都为空
            if left is None and right is None:
                return True
            # 2. 只有一个为空
            if left is None or right is None:
                return False
            # 3.两个节点的val不同
            if left.val != right.val:
                return False
            # 4. 镜像比较
            return check(left.left, right.right) and check(left.right, right.left)

        return check(root.left, root.right)

逐段说明

  • 入口：check(root.left, root.right)——根本身不参与比较（轴从根穿过）
  • 四条判定顺序固定：都空 → 一空 → 值不等 → 递归；前两条是结构检查，第三条是值检查
  • and 短路：外侧对失败时不再展开内侧对，直接向上传递 False

7. 复杂度分析

复杂度说明
时间O(n)每个节点最多进入一次配对
空间O(h)递归栈深度 = 树高

8. 常见易错点

两条 None 判定顺序颠倒：先判「一空」会把「都空」的对称情况判成 False。
配对方向搞错：正确是 l.left 对 r.right（外侧）、l.right 对 r.left（内侧）；写成 l.left 对 r.left 是比较「相同侧」而非镜像。
根节点参与比较：check(root, root) 也能工作但多一次无意义比较；标准入口是 check(root.left, root.right)。
只比较值不比较结构：两侧序列值相等但结构不同（一侧缺孩子）时，靠 None 判定兜底——漏掉会误判对称。

9. 总结

  • 模型：对称 = 每一对镜像节点（结构+值）都相等
  • 递归形态：双参数 check(l, r)，按四情况判定，外侧/内侧两路合取
  • 范式迁移：相同两树的「同构比较」「子树判断」都是这个骨架的变体
口诀：双参配对判四情，都空真来一空假；值等再查内外侧，两路合取即对称。
