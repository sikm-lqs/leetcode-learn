3. 二叉树的最大深度

分解问题式递归：max(左深, 右深) + 1，答案自底向上汇合。

1. 题目理解

给定一个二叉树 root，返回其最大深度：从根节点到最远叶子节点的最长路径上的节点数。

示例

输入：root = [3, 9, 20, null, null, 15, 7]
        3
       / \
      9  20
         / \
        15  7
输出：3
解释：最长路径 3 → 20 → 15（或 7），含 3 个节点。

输入：root = [1, null, 2]
输出：2
深度数的是「节点数」不是「边数」——空树深度为 0，单节点深度为 1。

2. 核心思路：子树答案的汇合

  1. 递归定义：整棵树的最大深度 = max(左子树深度, 右子树深度) + 1（+1 是根自己）
  2. 终止条件：root is None 返回 0——空树没有节点
  3. 信任子问题：不关心子树内部长什么样，只等左右两边的返回值，取大加一上交
depth(node) = max(depth(node.left), depth(node.right)) + 1
这是「分解问题」式递归（自底向上）：先递归到底，答案在回溯途中逐层组装——与前序「进入时做事」的「传递信息」式（自顶向下）相对。

3. 伪代码骨架

控制流与变量用代码表达，操作抽象为中文动宾短句，精确公式放在行尾注释：

def 最大深度(node):
    if node 为空:
        return 0                        # 空树深度 0（终止条件）

    left_depth = 最大深度(node.left)     # 递归左子树
    right_depth = 最大深度(node.right)   # 递归右子树

    return max(左右) + 1              # max(left_depth, right_depth) + 1
关键字 变量 中文操作 注释公式
三步曲范本：函数含义（返回该树深度）→ 终止（None → 0）→ 单层逻辑（max + 1）。几乎所有「树形 DP」题都从这个骨架生长出来。

6. 代码逐段解释

class Solution:
    def maxDepth(self, root) -> int:
        # max(左子树深度, 右子树深度) + 1，递归思想

        # 空树 depth = 0
        if root is None:
            return 0

        # 计算左/右子树的最大深度
        left_depth = self.maxDepth(root.left)
        right_depth = self.maxDepth(root.right)

        # 当前树的最大深度为左右更深的 +1
        return max(left_depth, right_depth) + 1

逐段说明

  • self.maxDepth 复用：方法自己调用自己，左右子树是规模更小的同构问题
  • 终止返回 0：空树贡献 0 个节点，+1 的基准点
  • 先递归后计算：两行递归在前、max 在后——计算发生在回溯途中（后序位置）

7. 复杂度分析

复杂度说明
时间O(n)每个节点访问一次
空间O(h)递归栈深度 = 树高；平衡 O(log n)，链状 O(n)

8. 常见易错点

终止条件返回 1：空树深度是 0 不是 1，返回 1 会给每条路径虚加一层。
忘 +1：max(左, 右) 不加 1 会漏掉当前节点自身，整棵树少算一层。
深度 vs 高度混用：本题「最大深度」从根往下数 =「高度」从下往上数，数值相同；但「最小深度」（111 题）两者就不同了。
与层序 BFS 混淆：迭代法需要队列逐层计数；递归法三行即止，两者答案一致但实现完全不同。

9. 总结

  • 骨架：判空返 0 → 递归左右 → max + 1
  • 思维：分解问题（自底向上），答案在回溯中汇合
  • 延伸：直径、平衡树、路径和……都是在这副骨架上加变量
口诀：空树归零是根基，左右深度递归取；取大再加根一个，自底向上层层传。
