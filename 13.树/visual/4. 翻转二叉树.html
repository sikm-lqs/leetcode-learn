4. 翻转二叉树

判空 → 交换左右孩子 → 递归：三行完成的经典"修改树"。

📋 目录

1. 题目理解 2. 核心思路：每个节点交换一次 3. 伪代码骨架 4. 交互可视化演示 5. 详细过程模拟 6. 代码逐段解释 7. 复杂度分析 8. 常见易错点 9. 总结

1. 题目理解

给你一棵二叉树的根节点 root，翻转这棵二叉树，并返回其根节点。

示例

输入：root = [4, 2, 7, 1, 3, 6, 9]
输出：[4, 7, 2, 9, 6, 3, 1]
解释：每个节点的左右孩子互换，整棵树镜像。
翻转 = 整棵树沿根轴做镜像：不只是根的孩子换，每个子树内部也要换。

2. 核心思路：每个节点交换一次

  1. 终止条件：节点为空，返回 None（空树无需翻转）
  2. 单层逻辑：交换当前节点的左右孩子（root.left, root.right = root.right, root.left）
  3. 递归：对新的左右子树分别调用翻转——子树内部继续两两交换
  4. 返回根：root 引用未变，孩子指针已换，直接返回
正确性直觉：镜像一棵树 = 根的孩子互换 + 两棵子树各自镜像。「先交换再递归」与「先递归再交换」（后序）都正确——交换的是孩子指针，与子树内部的翻转互不干扰。

3. 伪代码骨架

控制流与变量用代码表达，操作抽象为中文动宾短句，精确公式放在行尾注释：

def 翻转(root):
    if root 为空:
        return None                  # 空树不翻

    交换左右孩子                     # root.left, root.right = root.right, root.left
    递归翻转左子树                   # invertTree(root.left)
    递归翻转右子树                   # invertTree(root.right)
    return root
关键字 变量 中文操作 注释公式
「修改树」类题的通用返回结构：改的是指针、返回的是节点引用——父层靠返回值把新子树接回去。

6. 代码逐段解释

class Solution:
    def invertTree(self, root) -> Optional[TreeNode]:
        # 递归思想

        # 1.递归终止条件：当前节点为空
        if root is None:
            return None

        # 2. 交换
        root.left, root.right = root.right, root.left

        # 递归
        self.invertTree(root.left)
        self.invertTree(root.right)

        return root

逐段说明

  • 元组交换：Python 特有的一行交换，等价于三行 temp 写法
  • 交换在递归前：前序位置——先处理自己再处理子树；改成递归后交换（后序）同样正确
  • 返回值的作用：本题在原树上修改，返回 root 供外层（LeetCode 框架）拿到根

7. 复杂度分析

复杂度说明
时间O(n)每个节点访问并交换一次
空间O(h)递归栈 = 树高

8. 常见易错点

只交换根的孩子：忘记递归子树，只有第一层镜像、内部不变。
交换用了中间变量却顺序错乱：tmp = root.left; root.left = root.right; root.right = tmp——三步顺序错会丢失一侧子树（Python 元组交换无此风险）。
忘记返回 root：修改虽已完成，但外层拿不到根引用；用 root.left = invert(...) 的接回式写法时返回 None 会丢树。
空树崩溃：不判空直接 root.left 会 AttributeError。

9. 总结

  • 骨架：判空 → 交换 → 递归左右 → 返回根
  • 本质：镜像 = 每个节点局部交换的叠加
  • 延伸：「修改并返回」是构造/合并/剪枝类树题的通用签名
口诀：判空返回莫要忘，左右互换一行扛；递归两棵子树后，原树早已换新装。
