7. 不同的二叉搜索树

枚举根拆左右，乘积求和：卡特兰数的树形来历。

1. 题目理解

给你一个整数 n，求恰由 n 个节点组成且节点值从 1 到 n 互不相同的二叉搜索树（BST）有多少种。

示例

输入：n = 3
输出：5
解释：节点 {1, 2, 3} 共可组成 5 种结构的 BST。

输入：n = 1
输出：1
BST 性质：左子树所有值 < 根 < 右子树所有值——一旦选定根，哪些值归左、哪些归右就完全确定。

2. 核心思路：枚举根 + 乘法原理

  1. 枚举根：值 root 做根时，左子树只能由 1..root−1（共 root−1 个节点）组成，右子树由 root+1..nodes（共 nodes−root 个节点）组成
  2. 关键洞察：BST 的结构种数只与节点个数有关，与具体是哪些值无关（1..k 与任意 k 个有序数的结构数相同）
  3. 乘法原理：root 做根的方案数 = 左子树种数 × 右子树种数 = dp[root−1] × dp[nodes−root]
  4. 加法原理：对所有可能的根求和：
    dp[nodes] = Σ dp[root−1] × dp[nodes−root]，root = 1..nodes
  5. 边界：dp[0] = 1（空树算一种方案）
这正是卡特兰数递推：1, 1, 2, 5, 14, 42…（dp[0]=1, dp[1]=1, dp[2]=2, dp[3]=5, dp[4]=14）。

6. 代码逐段解释

from functools import cache

class Solution:                      # DP 版
    def numTrees(self, n: int) -> int:
        dp = [0] * (n + 1)
        dp[0] = 1                      # 空树一种
        for nodes in range(1, n + 1):
            for root in range(1, nodes + 1):
                left = root - 1          # 左子树节点数
                right = nodes - root      # 右子树节点数
                dp[nodes] += dp[left] * dp[right]
        return dp[n]

class Solution2:                     # 递归 + 记忆化版
    def numTrees(self, n: int) -> int:
        @cache
        def dfs(n):
            if n <= 1:               # 0 或 1 个节点都只有一种
                return 1
            ans = 0
            for root in range(1, n + 1):
                ans += dfs(root - 1) * dfs(n - root)
            return ans
        return dfs(n)

逐段说明

  • dp[0] = 1 的含义：空树是一种合法方案——它是「根在最左/最右时另一侧子树为空」的乘法单位元
  • left/root 的来源：值 root 做根，比它小的 root−1 个值全在左，比它大的 nodes−root 个全在右
  • 两版等价：@cache 记忆化递归 = 自顶向下做同一张 dp 表；边界 n ≤ 1 合并了 dp[0]、dp[1] 两个锚点

7. 复杂度分析

复杂度说明
时间O(n²)外层 n 种规模 × 内层最多 n 个根
空间O(n)dp 数组（递归版另有 O(n) 栈 + cache）

8. 常见易错点

dp[0] 初始化为 0：所有乘积全为 0，整个表算崩——空树必须算一种（乘法单位元）。
枚举根的范围写错：root 从 1 到 nodes（含端点），漏掉 root=nodes 会丢「根为最大值」的方案。
递归不记忆化：dfs 指数爆炸（同一规模反复展开）；@cache 或手写 memo 是必需品。
混淆「结构」与「值」：误以为要枚举值的具体分配——BST 性质已保证分配唯一，状态只需节点个数。

9. 总结

  • 转化：n 个节点的 BST 种数 = 卡特兰数 C(n) = Σ C(i)·C(n−1−i)
  • 两个洞察：枚举根拆左右（加法原理）× 左右独立（乘法原理）；种数只依赖节点个数
  • 延伸：括号方案数、出栈序列数、凸多边形三角剖分——都是这个递推的化身
口诀：定根拆出左右树，乘积原理各自数；种数只看节点数，求和便是卡特兰。
