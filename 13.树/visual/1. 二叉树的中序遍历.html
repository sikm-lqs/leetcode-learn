1. 二叉树的中序遍历

左 → 中 → 右：递归栈里最朴素的三行骨架。

📋 目录

1. 题目理解

给定一个二叉树的根节点 root，返回它的中序遍历。

示例

输入：root = [1, null, 2, 3]
        1
         \
          2
         /
        3
输出：[1, 3, 2]

输入：root = []
输出：[]
层序列表 [1, null, 2, 3] 的含义：按层从左到右排列，null 是空占位——1 的左孩子空、右孩子是 2，2 的左孩子是 3。

2. 核心思路：访问时机决定遍历名

  1. 中序 = 左 → 中 → 右：先一路向左深入，走不动了（node 为 None）回溯时访问节点，再转向右子树
  2. 递归三行骨架：递归左 → 访问根 → 递归右；node is None 是唯一终止条件
  3. 结果收集：用外层列表 result，访问动作就是 append(node.val)
为什么叫"中"序？——访问动作发生在「递归左之后、递归右之前」，即处于两次递归中间。把 append 挪到最前/最后就是前序/后序，其余代码一行不改。

5. 详细过程模拟

步骤动作递归栈result
1进入节点 1，压栈[1][]
2访问 1 的左子树 → None，返回[1][]
3回溯到 1：访问节点 1[1][1]
4访问 1 的右子树 → 进入节点 2，压栈[1, 2][1]
5访问 2 的左子树 → 进入节点 3，压栈[1, 2, 3][1]
63 的左子树 None；回溯到 3：访问节点 3[1, 2, 3][1, 3]
73 的右子树 None，3 完成弹栈；回溯到 2：访问节点 2[1, 2][1, 3, 2]
82 的右子树 None，全部弹栈完成[][1, 3, 2] ✅
关键观察：节点 1 虽然是根，却是第一个被访问的——因为它没有左子树；节点 2 在其左孩子 3 之后才访问——这就是「左 → 中 → 右」。

6. 代码逐段解释

class Solution:
    def inorderTraversal(self, root) -> List[int]:
        # 中序遍历：左 中间 右
        result = []

        def inorder(node):
            # 递归终止条件
            if node is None:
                return
            inorder(node.left)       # 遍历左子树
            result.append(node.val)   # 访问当前节点
            inorder(node.right)      # 遍历右子树

        inorder(root)
        return result

逐段说明

  • 闭包收集：result 定义在外层函数，递归内部直接 append——无需传参、无需返回值拼接
  • 终止条件：node is None 直接 return，None 不进入任何处理
  • 三行顺序：左递归 → 访问 → 右递归；调换三行顺序即得前序/后序

7. 复杂度分析

复杂度说明
时间O(n)每个节点进入递归一次、访问一次
空间O(h)递归栈深度 = 树高；平衡树 O(log n)，链状树 O(n)（输出数组不计入）

8. 常见易错点

忘了终止条件：node 为 None 时不返回，取 node.left 直接 AttributeError。
访问顺序放错位置：append 放在两次递归之前是前序、之后是后序——只有夹在中间才是中序。
result 放进递归函数里：每次递归都新建列表，最后收集不到完整结果——应放外层闭包共享。
递归栈溢出：树退化成 10⁵ 长链时递归深度过大，Python 需调 setrecursionlimit 或改显式栈迭代。

9. 总结

  • 骨架：判空 → 左递归 → 访问 → 右递归，树题递归的最小模板
  • 中序特性：BST 的中序序列是升序（验证 BST / 第 K 小题的基础）
  • 迁移：改动「访问时机」一行即可得到前序/后序版本
口诀：左尽回溯访自身，再向右去探一程；递归三行定顺序，中序夹在两递归。
