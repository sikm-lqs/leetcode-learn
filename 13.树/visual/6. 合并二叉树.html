6. 合并二叉树

双树同走：都有则相加，缺位整棵挂接。

1. 题目理解

给你两棵二叉树 root1 和 root2。将一棵覆盖到另一棵之上时一些节点会重叠。合并规则：重叠节点值相加；不为 null 的节点直接作为新树的节点。返回合并后的二叉树（必须从两棵树的根节点开始合并）。

示例

输入：root1 = [1, 3, 2, 5]，root2 = [2, 1, 3, null, 4, null, 7]
输出：[3, 4, 5, 5, 4, null, 7]

输入：root1 = [1]，root2 = [1, 2]
输出：[2, 2]
「覆盖」的直觉：两棵树逐位置对齐，同一位置都有节点就叠成一个（值相加），只有一边有就原样保留。

2. 核心思路：同步递归两棵树

  1. 双参数递归：mergeTrees(root1, root2) 同时走在两棵树的同一位置
  2. 缺位剪枝：
    • root1 为空 → 整棵返回 root2（root2 的子树原样挂上，不再递归）
    • root2 为空 → 整棵返回 root1
  3. 都有节点：值相加（本题在 root1 上原地合并：root1.val += root2.val）
  4. 接回：递归合并左右孩子并赋值给 root1.left / root1.right——保证父层结构正确
缺位返回是「天然剪枝」：一侧子树为空时，另一侧整棵子树无需再走——时间复杂度由较浅的树决定 O(min(m, n))。

3. 伪代码骨架

控制流与变量用代码表达，操作抽象为中文动宾短句，精确公式放在行尾注释：

def 合并(t1, t2):
    if t1 为空: return t2          # 缺位整棵挂接
    if t2 为空: return t1

    t1.val += t2.val                # 重叠：值相加（原地合并）

    t1.left = 合并(t1.left, t2.left)    # 递归左孩子
    t1.right = 合并(t1.right, t2.right)  # 递归右孩子
    return t1

6. 代码逐段解释

class Solution:
    def mergeTrees(self, root1, root2):
        # 递归思想：同时看两棵树当前位置的节点：
        # 都有就相加，只有一个就用那个，然后继续处理左右孩子

        # 1. 只有一棵树存在，直接返回另一棵
        if root1 is None:
            return root2

        if root2 is None:
            return root1

        # 2. 两个节点都存在，值相加
        root1.val += root2.val

        # 3. 继续合并左子树和右子树
        root1.left = self.mergeTrees(root1.left, root2.left)
        root1.right = self.mergeTrees(root1.right, root2.right)

        return root1

逐段说明

  • 两条缺位判断：任一为空就返回另一个（都空时返回 None）——不需要单独写「都空」分支
  • 原地合并：复用 root1 的节点，省内存；若要求不破坏输入可 new TreeNode(root1.val + root2.val)
  • 接回赋值：root1.left = merge(...)——返回值必须接住，否则缺位子树挂不上

7. 复杂度分析

复杂度说明
时间O(min(m, n))较短树先被走完，此后整棵挂接不再递归
空间O(min(m, n))递归栈深度 = 较浅树的高度

8. 常见易错点

缺位时新建节点：一空就 TreeNode(另一边.val) 只复制了当前节点，孩子丢失——必须返回整棵子树引用。
忘接返回值：只调用 merge(root1.left, ...) 不赋值，缺位子树没有被挂上，结果树残缺。
边界：两树皆空：root1 为空返回 root2（也是 None），无需第三个判断。
原地修改副作用：root1 被改写（含缺位处直接挂 root2 的节点）——本地测试勿复用旧树对象。

9. 总结

  • 模型：两树按相同位置同步递归，重叠相加、缺位挂接
  • 剪枝：一侧为空立即返回另一侧整棵子树
  • 范式：双树同走 + 修改并返回，与对称二叉树同属「多参数树递归」
口诀：两树同走看空位，谁空就把谁的对家回；都有节点值相加，接好孩子再返回。
