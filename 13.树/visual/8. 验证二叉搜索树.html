8. 验证二叉搜索树

双解法：上下界随路径收紧 × 中序遍历严格递增。

1. 题目理解

给你一个二叉树的根节点 root，判断其是否是一个有效的二叉搜索树。有效 BST 定义：

  • 节点的左子树只包含严格小于当前节点的数
  • 节点的右子树只包含严格大于当前节点的数
  • 所有左子树和右子树自身必须也是二叉搜索树

示例

输入：root = [2, 1, 3]
输出：true

输入：root = [5, 1, 4, null, null, 3, 6]
输出：false
解释：节点 4 在根 5 的右子树中，但 4 < 5。
注意「左子树全部小于根」「右子树全部大于根」——是整棵子树的所有节点，不只是直接孩子。

2. 核心思路：两种等价视角

解法一：区间沿路径收紧（上下界法）

  1. 陷阱：只比较「父与子」不够。反例 [5,4,6,null,null,3,7]：4<5 ✓、6>5 ✓、3<6 ✓、7>6 ✓，但节点 3 在根 5 的右子树里且 3 < 5——违反的是祖先约束
  2. 解法：递归函数 dfs(node, lower, upper) 携带开区间下降——当前节点必须严格落在 (lower, upper) 内
  3. 收紧规则：进左子树 upper = node.val；进右子树 lower = node.val；初始 (-∞, +∞)
dfs(node, lower, upper)：lower < node.val < upper

解法二：中序遍历严格递增

  1. BST 性质：中序遍历（左 → 中 → 右）得到的序列恰好严格升序
  2. 做法：中序收集所有值到数组 nums，再检查相邻关系 nums[i] > nums[i-1]——一旦出现 ≤ 即违规
两解法本质同源：区间法验证「每个节点面对所有祖先的约束」，中序法验证「所有约束的宏观结果（升序性）」——合法 BST ⟺ 两种检查都通过。

6. 代码逐段解释

解法一：上下界递归

class Solution:
    def isValidBST(self, root) -> bool:
        # 不能只考虑父亲节点，还要考虑祖先节点
        def dfs(root, lower, upper):
            if root is None:
                return True
            # 当前节点必须要在 lower-upper 之间
            if root.val <= lower or root.val >= upper:
                return False
            # 左子树（上界收紧为 root.val）
            left = dfs(root.left, lower, root.val)
            right = dfs(root.right, root.val, upper)
            return left and right

        return dfs(root, float("-inf"), float("inf"))

解法二：中序遍历 → 数组 → 检查递增

class Solution2:
    def isValidBST(self, root) -> bool:
        # 中序遍历：左子树 -> root -> 右子树
        # 将中序遍历保存到数组，然后检查
        nums = []

        def inorder(node):
            if not node:
                return
            inorder(node.left)      # 1.遍历左子树
            nums.append(node.val)    # 2. 当前值
            inorder(node.right)     # 3. 右子树

        inorder(root)

        for i in range(1, len(nums)):
            if nums[i] <= nums[i-1]:     # 相等也算违规
                return False
        return True

逐段说明

  • 解法一关键：val <= lower or val >= upper 开区间判断——等于边界也算违规；±∞ 初始化让根不受约束
  • 解法二关键：nums[i] <= nums[i-1]——严格递增要求把相等也判死（[1,1] 不是 BST）
  • 可省略数组：遍历中只记前驱值 prev，遇到 val <= prev 立即 False——空间降到 O(h)

8. 常见易错点

只比较父与子：最经典的错误。反例 [5,4,6,null,null,3,7] 每对父子都合法，但 3 违反祖先 5 的下界——区间法或中序法都能抓住它。
允许等于：区间法写成 val < lower、中序法写成 nums[i] < nums[i-1] 都会把「相等」放过去；BST 要求严格。
用 int 边界初始化：如 lower=INT_MIN——节点值恰为 INT_MIN 时误判；用 float ±inf 或 None 哨兵更稳。
中序后忘记检查 / 只查了一遍：收集完必须完整扫一遍相邻对；空数组与单元素直接 True。

9. 总结

  • 本质：BST 合法性是「路径约束」问题——每个节点受全部祖先制约
  • 双解法对照：
    上下界法中序法
    视角微观：逐节点验证祖先约束宏观：验证整体升序性
    短路违规即返回先收完再查（prev 版可边走边查）
    空间O(h)O(n) / O(h)（prev 版）
  • 延伸：中序升序性是 BST 一切题目的钥匙（第 K 小、验证、恢复 BST……）
口诀：父子比较不够看，祖先约束区间传；或者中序收一遍，严格递增才算 BST。
