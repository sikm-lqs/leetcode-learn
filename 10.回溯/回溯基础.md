下面是 **Python 回溯算法基础知识 + 常用技巧 + 高频模板**。

回溯可以理解成：

> 回溯 = 递归 + 撤销。尝试所有可能，走不通就回退。

英文是：

```text
Backtracking: 深度优先搜索 + 状态回退
```

也就是：

```text
做选择 → 递归 → 撤销选择（恢复现场）
```

---

# 一、什么是回溯？

假设我们要生成所有合法括号组合，每一步都要决定「放左括号还是右括号」：

```text
每一步 = 一个选择
所有选择 = 一棵决策树
回溯 = 遍历整棵树，记录所有合法叶子
```

---

# 二、回溯模板（三步法）

```python
def backtrack(路径, 选择列表):
    if 满足结束条件:
        记录答案
        return

    for 选择 in 选择列表:
        做选择                    # 修改状态
        backtrack(路径, 选择列表)  # 递归
        撤销选择                  # 恢复状态 ← 最关键的一步
```

**核心：递归前后状态必须一致**（否则分支间互相污染）。

# 三、回溯题目的常见套路

| 题型 | 典型题目 | 关键技巧 |
|------|---------|---------|
| 组合/子集 | 子集、组合总和 | 用 `start` 下标避免重复组合 |
| 排列 | 全排列 | 用 `used` 数组标记已选 |
| 括号/分割 | 括号生成、分割回文串 | 用「约束条件」剪枝 |
| 棋盘类 | N 皇后、数独 | 用行/列/对角线集合判冲突 |
| 图搜索 | 岛屿、单词搜索 | visited 标记 + 回溯清除 |

---

# 四、剪枝（Pruning）

回溯的优化核心是**提前砍掉不可能的分支**：

```text
不满足约束条件 → 直接跳过，不进入递归
```

例如括号生成：`cnt == 0` 时不能再放右括号（会非法），直接剪掉。

---

# 五、复杂度

- **时间**：O(方案数 × 方案生成代价)，常见卡特兰数、组合数等
- **空间**：O(递归深度 + 路径长度)，递归深度一般 O(n)

---

# 六、易错点

1. **忘记撤销选择**：递归返回后状态残留，结果互相污染
2. **复制 vs 引用**：记录答案时要拷贝路径（`list(path)`），不能直接存引用
3. **剪枝条件不全**：漏掉非法分支导致超时或答案错误
4. **结束条件位置**：先判断结束，再做选择；或先做选择、到叶子再判断（两种写法都要保证正确）
