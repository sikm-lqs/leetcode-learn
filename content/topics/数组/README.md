# 数组系列专题规划

数组系列建议先保留原始学习目录不动，只在这里整理输出顺序。

## 系列定位

数组是 LeetCode 中很多题型的入口。它既有基础操作题，也会承载哈希表、双指针、前缀和、排序、区间、原地修改等模式。

对于初学阶段，数组系列不追求一题多解，而是追求：

- 先知道数组的基本操作和遍历方式
- 再知道不同题目为什么会触发不同模式
- 每个模式用 2 到 4 道题讲透
- 每道题主讲 1 种最适合入门的做法

## 视频系列建议

第一期不要直接讲某一道题，建议先讲“数组题到底在考什么”：

- 数组的下标、长度、连续性
- 常见遍历方式：正向、反向、双指针、枚举起点
- 常见操作：append、pop、索引访问、切片、交换
- 常见复杂度：遍历 O(n)、排序 O(n log n)、嵌套枚举 O(n^2)
- 遇到数组题时先问：要找值、找位置、找连续区间、原地修改，还是统计次数

后续每一期进入一个核心模式。每期用 2 到 4 道题组成一个小专题。
