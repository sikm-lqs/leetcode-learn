# Content 输出资料

这个目录用于把已有 LeetCode 学习资料整理成可发布内容，不改变原始学习目录。

## 目录约定

- `topics/`：按题型和核心模式整理的选题、讲解主线和题目分组
- `blog/`：个人博客草稿
- `WeChat/`：公众号草稿
- `video-scripts/`：B站视频脚本

## 当前原则

1. 原始学习资料继续放在各题型目录中，例如 `1. 数组/leetcode.ipynb` 与 `1. 数组/visual/`。
2. 输出资料按“题型 -> 核心模式 -> 代表题”组织。
3. 初学阶段每题主讲 1 种解法，最多补充 1 种对理解有帮助的解法。
4. 每个题型系列先讲基础概念，再进入核心模式专题。
