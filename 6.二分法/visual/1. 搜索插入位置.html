1. 搜索插入位置

标准二分查找 · 找到第一个大于等于目标值的位置

题目描述

给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

示例：nums = [1, 3, 5, 6], target = 5 → 返回 2（找到目标）
nums = [1, 3, 5, 6], target = 2 → 返回 1（应插入位置）

算法思路

标准二分查找，目标是找到第一个大于等于 target 的位置：

  • 使用左闭右闭区间 [left, right]
  • 如果 nums[mid] < target：目标在右半边，left = mid + 1
  • 否则：目标在左半边（含 mid），right = mid - 1

当循环结束时，left 就是第一个 ≥ target 的位置（即插入位置）。

时间复杂度：O(log n) —— 每次将搜索范围减半
空间复杂度：O(1) —— 只用常数空间

核心亮点

  • ✓ 左闭右闭：使用 [left, right] 区间，经典直观的二分写法
  • ✓ 标准模板：通过 right = mid - 1 收缩，是最常用的二分查找模式
  • ✓ 清晰：循环结束时 left 自然指向插入位置

代码实现

def searchInsert(nums, target):
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = (left + right) // 2

        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return left

算法详解

以 nums = [1, 3, 5, 6], target = 2 为例：

步骤leftrightmidnums[mid]操作
103133 ≥ 2，right = 0
200011 < 2，left = 1
310--left > right，退出，返回 left = 1
结果：插入位置是 1，即 2 应该插入到索引 1 的位置，数组变为 [1, 2, 3, 5, 6]

关键要点

  • 循环条件：left ≤ right —— 保证所有元素都被检查
  • 循环结束：left 就是答案 —— 第一个 ≥ target 的位置
  • 边界处理：自动处理 target 小于所有元素（left = 0）和大于所有元素（left = len(nums)）的情况
  • 应用场景：这是"查找左边界"的通用模式，可用于查找、插入、统计等问题
