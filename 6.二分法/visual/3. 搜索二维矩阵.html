3. 搜索二维矩阵

二维矩阵转一维数组 · 坐标映射

题目描述

给你一个满足下述两条属性的 m x n 整数矩阵：

  • 每行中的整数从左到右按非严格递增顺序排列
  • 每行的第一个整数大于前一行的最后一个整数

给定一个整数 target，如果 target 在矩阵中，返回 true；否则，返回 false。

示例：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3 → 返回 true
matrix = 同上, target = 13 → 返回 false

算法思路

核心思想：将二维矩阵看作一个排好序的一维数组，对索引进行二分查找。

坐标转换：将一维数组的 mid 索引转换为二维坐标：

  • 行索引 i = mid / n（整数除法）
  • 列索引 j = mid % n（取模运算）

其中 n 是每行的列数。这样就能直接通过 mid 值访问矩阵元素 matrix[i][j]。

时间复杂度：O(log(m * n)) —— 二分范围是 m*n
空间复杂度：O(1) —— 只用常数空间

核心亮点

  • ✓ 巧妙转换：将二维问题转化为一维问题，降低思维难度
  • ✓ 坐标映射：利用整除和取模实现一维到二维的转换
  • ✓ 一次二分：只需一次二分查找即可定位目标值

mid 除以列数 n 得行、对列数 n 取余得列——只要每行长度相同，一维下标即可无缝映射到矩阵。

代码实现

def searchMatrix(matrix, target):
    if not matrix or not matrix[0]:
        return False

    m, n = len(matrix), len(matrix[0])
    left, right = 0, m * n - 1

    while left <= right:
        mid = (left + right) // 2

        # 一维坐标转化为二维坐标
        i = mid // n  # 行索引
        j = mid % n   # 列索引
        value = matrix[i][j]

        if value == target:
            return True
        elif value < target:
            left = mid + 1
        else:
            right = mid - 1

    return False

关键要点

  • 坐标映射：核心是整除（/）和取模（%）运算，实现一维到二维的转换
  • 搜索范围：left = 0，right = m*n - 1，覆盖所有元素
  • 边界处理：先检查矩阵是否为空，避免访问越界
  • 应用场景：适用于满足行列单调性的矩阵搜索问题
