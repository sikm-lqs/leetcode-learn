4. 搜索旋转排序数组

旋转数组二分查找 · 利用"一半有序"特性

题目描述

整数数组 nums 按升序排列，数组中的值 互不相同。在传递给函数之前，nums 在预先未知的某个下标 k（0 ≤ k < nums.length）上进行了向左旋转。

给定旋转后的数组 nums 和一个整数 target，如果 nums 中存在这个目标值 target，则返回它的下标，否则返回 -1。

示例：nums = [4,5,6,7,0,1,2], target = 0 → 返回 4
nums = [4,5,6,7,0,1,2], target = 3 → 返回 -1

算法思路

关键特性：旋转数组有一个重要特性 —— 至少有一半是有序的。

二分时先判断哪一半是有序的，然后判断 target 是否在有序的那一半内：

情况1：左半边有序（nums[left] ≤ nums[mid]）

  • 如果 nums[left] ≤ target ≤ nums[mid]：target 在左半边，right = mid - 1
  • 否则：target 在右半边，left = mid + 1

情况2：右半边有序（nums[left] > nums[mid]）

  • 如果 nums[mid] ≤ target ≤ nums[right]：target 在右半边，left = mid + 1
  • 否则：target 在左半边，right = mid - 1
时间复杂度：O(log n) —— 每次将搜索范围减半
空间复杂度：O(1) —— 只用常数空间

核心亮点

  • ✓ 利用有序性：旋转数组的一半一定是有序的，利用这个特性排除一半
  • ✓ 关键判断：通过边界判断哪一半是有序的（nums[left] 与 nums[mid] 的关系）
  • ✓ 模板通用：这是二分查找的变体，适用于旋转数组场景

代码实现

def search(nums, target):
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = (left + right) // 2

        # 找到目标值
        if nums[mid] == target:
            return mid

        # 判断哪一半是有序的
        if nums[left] <= nums[mid]:
            # 左半边有序
            if nums[left] <= target <= nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:
            # 右半边有序
            if nums[mid] <= target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1

    return -1

以 nums = [4,5,6,7,0,1,2], target = 0 为例：

旋转点：索引 4（值为 0）是旋转点，左半边 [4,5,6,7] 有序，右半边 [0,1,2] 有序。

详解：
步骤1：mid = 3，nums[0]=4 ≤ nums[3]=7，左半边 [4,5,6,7] 有序。target=0 不在这个范围内，所以去右半边找，left = 4。
步骤2：mid = 5，nums[4]=0 ≤ nums[5]=1，左半边 [0,1] 有序。target=0 在这个范围内，所以去左半边找，right = 4。
步骤3：mid = 4，nums[4]=0 == target，找到！返回 4。

关键要点

  • 判断有序性：通过 nums[left] ≤ nums[mid] 判断左半边是否有序
  • 范围判断：target 在有序的那一半内，就去哪一半找
  • 边界处理：注意 ≤ 和 < 的使用，确保边界元素被正确处理
  • 应用场景：适用于旋转排序数组的查找，如循环数组、轮转数组等
