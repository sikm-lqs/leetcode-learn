2. 在排序数组中查找元素的第一个和最后一个位置

两次二分查找 · 分别找左边界和右边界

题目描述

给你一个按照非递减顺序排列的整数数组 nums，和一个目标值 target。找出给定目标值在数组中的开始位置和结束位置。如果数组中不存在目标值，返回 [-1, -1]。

示例：nums = [5,7,7,8,8,10], target = 8 → 返回 [3, 4]
nums = [5,7,7,8,8,10], target = 6 → 返回 [-1, -1]

算法思路

两次二分，分别找到 target 的左边界和右边界：

找左边界（find_left）

  • 标准的二分查找
  • 当 nums[mid] == target 时，继续向左查找：right = mid - 1
  • 记录每次找到的位置，最终得到最左边的位置

找右边界（find_right）

  • 类似的二分查找
  • 当 nums[mid] == target 时，继续向右查找：left = mid + 1
  • 记录每次找到的位置，最终得到最右边的位置
时间复杂度：O(log n) —— 两次二分查找
空间复杂度：O(1) —— 只用常数空间

核心亮点

  • ✓ 问题分解：将一个问题分解为两个独立的二分查找
  • ✓ 关键技巧：通过修改二分方向（mid + 1 或 mid - 1）来决定继续向左或向右搜索
  • ✓ 通用模式：这是"查找边界"的标准写法

两次二分的关键差异只有命中后收缩方向相反：左边界往左收（right = mid-1），右边界往右收（left = mid+1）。

代码实现

def searchRange(nums, target):
    def find_left():
        left, right = 0, len(nums) - 1
        ans = -1

        while left <= right:
            mid = (left + right) // 2

            if nums[mid] == target:
                ans = mid
                right = mid - 1  # 继续往左找
            elif nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1

        return ans

    def find_right():
        left, right = 0, len(nums) - 1
        ans = -1

        while left <= right:
            mid = (left + right) // 2

            if nums[mid] == target:
                ans = mid
                left = mid + 1  # 继续往右找
            elif nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1

        return ans

    return [find_left(), find_right()]

关键要点

  • 找到目标不停止：关键是当 nums[mid] == target 时不立即返回，而是继续查找
  • 方向决定：找左边界时向左（right = mid - 1），找右边界时向右（left = mid + 1）
  • 记录答案：每次找到目标都记录位置，最终得到边界
  • 应用场景：适用于查找重复元素的边界范围，统计元素出现次数等
