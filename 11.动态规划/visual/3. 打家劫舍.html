3. 打家劫舍

「偷 or 不偷」的 0-1 决策：dp[i] = max(dp[i-1], dp[i-2] + nums[i])。

1. 题目理解

沿街房屋排成一排，每间房内藏有现金 nums[i]。相邻两间房屋装有防盗系统，同一晚偷相邻两间会报警。计算不触动警报的情况下，一夜之内能偷到的最高金额。

示例

输入：nums = [1, 2, 3, 1]
输出：4
解释：偷 1 号（1）和 3 号（3），共 4。

输入：nums = [2, 7, 9, 3, 1]
输出：12
解释：偷 1 号（2）、3 号（9）、5 号（1），共 12。
约束只有一个：不能偷相邻的两间。贪心（每次取更大的那间）会出错——因为取大可能堵死后面更大的。

2. 核心思路：最后一间偷还是不偷

  1. 状态定义：dp[i] = 考虑前 i 间房屋（0..i）能偷到的最高金额
  2. 状态转移：对最后一间房 i，只有两种决策——
    • 不偷：等于前 i-1 间的最优值 → dp[i-1]
    • 偷：第 i-1 间不能偷，等于前 i-2 间最优 + 本间 → dp[i-2] + nums[i]
    取较大值：dp[i] = max(dp[i-1], dp[i-2] + nums[i])
  3. 边界：dp[0] = nums[0]；dp[1] = max(nums[0], nums[1])
dp[i] = max(dp[i−1], dp[i−2] + nums[i])
「偷 or 不偷」是 0-1 决策类 DP 的核心：决策是互斥的，分别算出两种选择的收益再取 max，就是最优子结构的体现。

6. 代码逐段解释

from typing import List

class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0                      # 没有房屋
        if n == 1:
            return nums[0]               # 只有一间
        dp = [0] * n
        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1])   # 前两间只能偷一间
        for i in range(2, n):
            dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])  # 不偷 vs 偷
        return dp[n - 1]

逐段说明

  • n == 0/1 边界：空数组和单元素数组直接返回，避免 dp 数组索引越界
  • dp[1]：前两间相邻不能都偷，只能取金额较大的一间
  • 转移：偷第 i 间时必须跳开第 i-1 间，所以依赖 dp[i-2]；不偷则沿用 dp[i-1]

7. 复杂度分析

复杂度说明
时间O(n)一趟循环，每间房常数时间决策
空间O(n)dp 数组；只依赖前两个状态，可滚动到 O(1)

8. 常见易错点

贪心思路错误：每次偷更大的一间会堵死相邻的更大的房子，必须用 DP 全局决策。
dp[1] 初始化：dp[1] = max(nums[0], nums[1])，不能写 dp[1] = nums[1]（可能漏掉 nums[0] 更大的情况）。
偷的依赖：「偷第 i 间」依赖 dp[i-2] 而非 dp[i-1]——因为第 i-1 间必须跳过，这是转移方程最容易写错的地方。
空数组边界：n = 0 时直接访问 nums[0] 会越界，必须提前返回 0。

9. 总结

  • 决策建模：最后一间「偷 or 不偷」，两种互斥选择分别求值再取 max
  • 转移：dp[i] = max(dp[i-1], dp[i-2] + nums[i])
  • 范式：0-1 决策类线性 DP，可滚动到 O(1) 空间
口诀：最后一间两选择，偷则跳一加现金；不偷沿用前一间，max 决策全局优。
