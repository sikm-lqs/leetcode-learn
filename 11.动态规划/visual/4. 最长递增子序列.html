4. 最长递增子序列

「以 i 结尾」+ 枚举前驱：O(n²) 经典 DP。

1. 题目理解

给你一个整数数组 nums，找到其中最长严格递增子序列的长度。子序列是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。

示例

输入：nums = [10, 9, 2, 5, 3, 7, 101, 18]
输出：4
解释：最长递增子序列是 [2, 3, 7, 101]，长度为 4。

输入：nums = [0, 1, 0, 3, 2, 3]
输出：4
输入：nums = [7, 7, 7, 7, 7, 7, 7]
输出：1
子序列 ≠ 子数组：元素不需要连续，只需保持相对顺序。「严格递增」意味着相等元素不能相连。

2. 核心思路：谁可以当倒数第二个

  1. 状态定义：dp[i] = 以 nums[i] 作为结尾的最长递增子序列长度（初始为 1，即只有自己）
  2. 状态转移：枚举 i 前面的每个位置 j，若 nums[j] < nums[i]，说明 nums[i] 可以接在以 nums[j] 结尾的子序列后面：
    dp[i] = max(dp[i], dp[j] + 1)
  3. 答案：最优子序列的结尾可以是任意位置，所以 ans = max(ans, dp[i]) 全程维护
关键认知：dp[i] 是「必须包含 nums[i] 作为结尾」的局部最优；与最大子数组和一样，全局答案需要另外取 max——因为最优子序列不一定以最后一个元素结尾。

转移是「找前驱」：i 的状态由所有满足递增关系的 j 更新而来，所以每个 i 都要扫一遍前面的 j——这是 O(n²) 的来源。

6. 代码逐段解释

from typing import List

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [1] * n          # 以 i 结尾的 LIS 长度，至少 1（只有自己）
        ans = 1
        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:          # 只有更小的值才能接在后面
                    dp[i] = max(dp[i], dp[j] + 1)
            ans = max(ans, dp[i])          # 全局答案取所有 dp[i] 的最大值
        return ans

逐段说明

  • dp 初始化全 1：每个元素单独构成长度为 1 的递增子序列
  • 双循环：外层定结尾 i，内层枚举所有可能的前驱 j，用 max 合并多个候选
  • 严格递增：用 < 而非 <=，相等元素不能接
  • ans 维护：与 dp 分开，因为最优子序列结尾不一定在数组末尾

7. 复杂度分析

复杂度说明
时间O(n²)每个 i 扫描前面所有 j；可用贪心+二分优化到 O(n log n)
空间O(n)dp 数组

8. 常见易错点

dp 初始化为 0：每个位置至少是自己（长度为 1），初始化 0 会漏掉「无法接任何前驱」的情况。
ans 忘记维护：只返回 dp[n-1] 会出错——最优子序列不一定以最后一个元素结尾（如示例 1 中 18 结尾只有 4，但最长也在 4）。
用了 <= 判断：严格递增要求 nums[j] < nums[i]，用 <= 会把相等元素错误地接上。
与「最长连续递增子序列」混淆：本题子序列可跳元素（如 [2,5,7,101]），需要枚举前驱；连续版只需要比较相邻元素。

9. 总结

  • 状态定义：dp[i] = 以 nums[i] 结尾的 LIS 长度——「结尾」定位是子序列类 DP 的标准姿势
  • 转移：枚举前驱 j，nums[j] < nums[i] 时 dp[i] = max(dp[i], dp[j] + 1)
  • 答案：全局 max 单独维护；O(n²) 可优化到 O(n log n)
口诀：以 i 结尾定状态，前面逐个找前驱；递增才接长度加一，全局答案别忘取。
