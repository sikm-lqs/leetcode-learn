9. 乘积最大子数组

最大/最小双状态：负数会翻转乾坤（负负得正）。

1. 题目理解

给你一个整数数组 nums，找出数组中乘积最大的非空连续子数组，并返回该子数组所对应的乘积。只包含一个元素的子数组，其乘积就是该元素值。

示例

输入：nums = [2, 3, -2, 4]
输出：6
解释：子数组 [2, 3] 有最大乘积 6。

输入：nums = [-2, 0, -1]
输出：0
解释：[-2, -1] 不是连续子数组，结果为 0（取子数组 [0]）。

输入：nums = [-2, 3, -4]
输出：24
解释：整个数组 [-2, 3, -4] 的乘积 24 最大。
与「最大子数组和」的关键区别：乘积中负数会把大变小、小变大——只维护最大值会在「负负得正」时错过答案。

2. 核心思路：为什么需要两条状态

  1. 双状态定义：
    • max_dp[i] = 以 nums[i] 结尾的连续子数组的最大乘积
    • min_dp[i] = 以 nums[i] 结尾的连续子数组的最小乘积
  2. 三选一转移（两个状态同时算）：
    max_dp[i] = max(nums[i], max_dp[i−1]·nums[i], min_dp[i−1]·nums[i])
    min_dp[i] = min(nums[i], max_dp[i−1]·nums[i], min_dp[i−1]·nums[i])
  3. 答案：ans = max(ans, max_dp[i])，全程维护
直觉：当前的「最小乘积」（很可能是大负数）遇到负数元素就翻转为「最大乘积」的候选——最小值是最大值的后备弹药，所以两条状态必须一起滚动。

6. 代码逐段解释

from typing import List

class Solution:                        # 数组版
    def maxProduct(self, nums: List[int]) -> int:
        n = len(nums)
        max_dp = [0] * n
        min_dp = [0] * n
        max_dp[0] = min_dp[0] = nums[0]
        ans = nums[0]
        for i in range(1, n):
            max_dp[i] = max(nums[i], max_dp[i-1] * nums[i], min_dp[i-1] * nums[i])
            min_dp[i] = min(nums[i], max_dp[i-1] * nums[i], min_dp[i-1] * nums[i])
            ans = max(ans, max_dp[i])
        return ans

class Solution2:                       # 滚动变量版（O(1) 空间）
    def maxProduct(self, nums: List[int]) -> int:
        max_product = min_product = ans = nums[0]
        for i in range(1, len(nums)):
            prev_max, prev_min = max_product, min_product   # 先保存旧值！
            max_product = max(nums[i], prev_max * nums[i], prev_min * nums[i])
            min_product = min(nums[i], prev_max * nums[i], prev_min * nums[i])
            ans = max(ans, max_product)
        return ans

逐段说明

  • 双状态初始化：max_dp[0] = min_dp[0] = nums[0]（单元素既是最大也是最小）
  • 三候选：自己开头、接前最大、接前最小——正数元素接最大，负数元素接最小
  • 滚动版易错点：必须先把 prev_max/prev_min 存下来，否则算 min 时 max 已被覆盖

7. 复杂度分析

复杂度说明
时间O(n)一趟扫描，每步常数次乘法与比较
空间O(n) / O(1)数组版 O(n)；滚动变量版 O(1)

8. 常见易错点

只维护最大值：[−2, 3, −4] 会在最后一步错过 24——负负得正的翻转必须靠 min 状态接住。
滚动覆盖：先更新 max_product 再用「新的」max_product 算 min_product，会读到被覆盖的值；务必先存 prev。
ans 初始化为 0：全负数组（如 [−2]）答案应为 −2，初始化必须用 nums[0]。
与「最大子数组和」套同一模板：和问题负数只会拖累（max 二选一即可）；乘积问题负数可能翻盘，必须升维到双状态。

9. 总结

  • 升维：一维状态不够（负数翻转）→ 同时维护 max/min 两条状态
  • 转移：三选一——自己、接前最大、接前最小
  • 范式：「状态不够就加维度」是 DP 的通用加强手段
口诀：乘积最大双状态，最大最小一起滚；负数翻转乾坤变，最小值是后备军。
