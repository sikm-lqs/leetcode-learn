5. 完全平方数

完全背包求最少件数：枚举「最后一个平方数」。

📋 目录

1. 题目理解

给你一个整数 n，返回和为 n 的完全平方数的最少数量。完全平方数是其值等于另一个整数平方的数，如 1、4、9、16（3 和 11 不是）。

示例

输入：n = 12
输出：3
解释：12 = 4 + 4 + 4

输入：n = 13
输出：2
解释：13 = 4 + 9
平方数可以重复使用（12 用了三个 4），这正是「完全背包」的标志。

2. 核心思路：枚举最后一个平方数

  1. 状态定义：dp[i] = 组成整数 i 所需的最少完全平方数数量
  2. 初始化：全部设为 n+1（当作无穷大哨兵），dp[0] = 0（组成 0 不需要任何数）
  3. 状态转移：对每个 i，枚举「最后选的一个平方数 j²」（j² ≤ i）：若最后选 j²，前面还需组成 i - j²，共 dp[i-j²] + 1 个：
    dp[i] = min(dp[i], dp[i − j²] + 1)
  4. 答案：dp[n]
视角转换是关键：不枚举「选哪些平方数」，而是问「最后一个选的是几」——最优解的最后一个平方数必属 {1, 4, 9, …}，逐一尝试取最小即可。

3. 伪代码骨架

控制流与变量用代码表达，操作抽象为中文动宾短句，精确公式放在行尾注释：

dp = [n+1] * (n+1)   # 无穷大哨兵
dp[0] = 0

for i in range(1, n+1):
    j = 1
    while j * j <= i:
        尝试最后选 j²          # dp[i] = min(dp[i], dp[i-j*j] + 1)
        j += 1
return dp[n]
关键字 变量 中文操作 注释公式
哨兵值 n+1 的妙处：n 最多由 n 个 1 组成，真实答案 ≤ n，所以 n+1 天然代表「不可达」，比 float('inf') 更轻量。

6. 代码逐段解释

class Solution:
    def numSquares(self, n: int) -> int:
        dp = [n + 1] * (n + 1)   # 哨兵值：n+1 视为无穷大
        dp[0] = 0                      # 组成 0 不需要任何平方数
        for i in range(1, n + 1):
            j = 1
            while j * j <= i:               # 枚举最后一个平方数 j²
                dp[i] = min(dp[i], dp[i - j * j] + 1)
                j += 1
        return dp[n]

逐段说明

  • 哨兵初始化：dp 全填 n+1，真实答案最多 n（全用 1），不会与哨兵混淆
  • while j*j <= i：平方数不能超过当前目标 i，天然控制枚举范围
  • min 转移：每个候选 j² 给出一个方案数，取最小

7. 复杂度分析

复杂度说明
时间O(n·√n)每个 i 枚举 ≤ √i 个平方数
空间O(n)dp 数组

8. 常见易错点

dp[0] 忘记置 0：dp[0] 是所有「i 本身是平方数」情况（如 dp[4]、dp[9]）的转移来源，错了会全盘皆错。
哨兵值太小：初始化用 0 或 1 会让 min 取到错误值；n+1 是安全上界。
枚举边界：条件是 j*j <= i（等号可取，平方数本身可以当候选），写 < 会漏掉「i 恰好是平方数」。
贪心（每次取最大平方数）错误：如 n=12 贪心得 9+1+1+1=4 个，而最优是 4+4+4=3 个。

9. 总结

  • 模型：完全背包求最少件数——物品是 1, 4, 9, 16…，无限供应
  • 转移：枚举最后一件，dp[i] = min(dp[i], dp[i−j²] + 1)
  • 技巧：n+1 哨兵 + dp[0]=0 锚点
口诀：最后一枚是平方，枚举平方取最小；dp 零处锚点设，哨兵上界 n 加一。
