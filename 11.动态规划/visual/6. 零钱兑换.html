6. 零钱兑换

完全背包原型：枚举最后一枚硬币，min 转移 + 哨兵判不可达。

1. 题目理解

给你一个整数数组 coins 表示不同面额的硬币，以及一个整数 amount 表示总金额。计算凑成总金额所需的最少硬币个数；如果没有任何硬币组合能组成总金额，返回 -1。每种硬币的数量是无限的。

示例

输入：coins = [1, 2, 5], amount = 11
输出：3
解释：11 = 5 + 5 + 1

输入：coins = [2], amount = 3
输出：-1

输入：coins = [1], amount = 0
输出：0
「每种硬币无限」是完全背包的标志；若每种只能用一次，就是 0-1 背包（转移时需倒序枚举金额）。

2. 核心思路：枚举最后一枚硬币

  1. 状态定义：dp[i] = 组成金额 i 的最少硬币个数
  2. 初始化：全部设为 amount+1（哨兵无穷大），dp[0] = 0（金额 0 用 0 枚）
  3. 状态转移：对每个金额 i，枚举最后使用的一枚硬币 coin（coin ≤ i）：
    dp[i] = min(dp[i], dp[i − coin] + 1)
  4. 不可达判断：结束时若 dp[amount] 仍等于哨兵值，说明凑不出，返回 -1
与「完全平方数」完全同构：把硬币面额换成 1, 4, 9, 16… 就是上一题。两题共用一个模板，只是「物品集合」不同。

6. 代码逐段解释

from typing import List

class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        dp = [amount + 1] * (amount + 1)  # 哨兵：amount+1 视为无穷大
        dp[0] = 0                     # 金额 0 用 0 枚硬币
        for i in range(1, amount + 1):
            for coin in coins:
                if coin <= i:                 # 硬币面额不能超过当前金额
                    dp[i] = min(dp[i], dp[i - coin] + 1)
        return dp[amount] if dp[amount] != amount + 1 else -1

逐段说明

  • 双重循环：外层金额、内层硬币——顺序对完全背包无影响（也可交换）
  • coin <= i 过滤：面额超过当前金额的硬币不可能作为「最后一枚」
  • 结尾判 -1：dp[amount] 保持哨兵值说明无解（如 coins=[2], amount=3）

7. 复杂度分析

复杂度说明
时间O(amount × len(coins))每个金额枚举所有硬币
空间O(amount)dp 数组

8. 常见易错点

贪心（每次取最大面额）错误：coins = [1, 3, 4], amount = 6，贪心得 4+1+1（3 枚），最优是 3+3（2 枚）。
忘记处理不可达：直接返回 dp[amount] 会把哨兵值当答案；必须检查是否仍为 amount+1。
BFS 也可解：金额是节点、硬币是边，最少硬币数 = 最短路；但 DP 更通用（可扩展到方案计数）。
与「零钱兑换 II（组合数）」混淆：本题求最少件数用 min；求组合数用加法 dp[i] += dp[i-coin]，且循环顺序有讲究。

9. 总结

  • 模型：完全背包最少件数——「最后一枚是谁」驱动 min 转移
  • 不可达：哨兵值 amount+1 兼做 -1 判断
  • 同构题：完全平方数 = 零钱兑换（coins = 平方数集合）
口诀：金额外层硬币内，最后一枚取最小；哨兵上界判无解，dp 零处是锚点。
