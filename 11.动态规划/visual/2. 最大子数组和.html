1. 题目理解

给你一个整数数组 nums，找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

示例

输入：nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
输出：6
解释：连续子数组 [4, -1, 2, 1] 的和最大，为 6。

输入：nums = [1]
输出：1
暴力做法是枚举所有起点和终点，O(n²) 个候选；DP 通过「以 i 结尾」的状态定义把问题压缩到一趟扫描。

2. 核心思路：接上 or 重新开始

  1. 状态定义：dp[i] = 以 nums[i] 为右端点的最大子数组和
  2. 状态转移：每个位置二选一——
    • 接上：把 nums[i] 接到 dp[i-1] 的最优段后面 → dp[i-1] + nums[i]
    • 重新开始：从 nums[i] 单独开始 → nums[i]
    取较大值：dp[i] = max(dp[i-1] + nums[i], nums[i])
  3. 答案：遍历时维护 ans = max(ans, dp[i])，因为最优子数组的右端点可以是任意位置
dp[i] = max(dp[i−1] + nums[i], nums[i])
为什么能这么做？最优子数组的任意前缀也必然是最优的——如果「以 i 结尾」的最优段前缀不是最优，换成更优的前缀只会更大（最优子结构）。

6. 代码逐段解释

from typing import List

class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [0] * n
        dp[0] = nums[0]          # 以 0 结尾的最大和就是它自己
        ans = nums[0]            # 记录所有 dp[i] 的最大值
        for i in range(1, n):
            dp[i] = max(dp[i - 1] + nums[i], nums[i])  # 接上 or 重新开始
            ans = max(ans, dp[i])
        return ans

逐段说明

  • 初始化：dp[0] = nums[0]（只有一个元素时它就是答案），ans 同步初始化
  • 转移：max 二选一——「接上」可能越接越小（遇到负数），「重新开始」兜底
  • 答案维护：dp[i] 只保证「以 i 结尾」，最优段右端点未知，所以全程取 max

7. 复杂度分析

复杂度说明
时间O(n)一趟扫描，每个位置常数时间
空间O(n)dp 数组；可滚动为 O(1)（只依赖 dp[i-1]）

8. 常见易错点

ans 初始化为 0：全负数数组（如 [-1, -2]）会错误返回 0，必须初始化为 nums[0] 或负无穷。
dp 含义混淆：dp[i] 是「以 i 结尾」的最大和，不是「前 i 个元素」的最大和——后者无法直接转移（子数组必须连续）。
「接上」不是无脑加：dp[i-1] 为负数时接上更差，max 会自动选择重新开始，不要手动加判断。
与「和为 K 的子数组」混淆：本题求最大和（无固定 K），用 DP；固定 K 的计数题用前缀和+哈希表。

9. 总结

  • 状态定义：「以 i 结尾」——子数组类 DP 的标准姿势
  • 转移：接上 or 重新开始，max 二选一
  • 答案：全局 max 与局部 dp[i] 分开维护
口诀：以 i 结尾定状态，接上重开二选一；局部最优全局比，一趟扫完得答案。
