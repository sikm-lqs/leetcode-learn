7. 单词拆分

前缀可达性接力：dp[j] 且 s[j:i] 在字典中 → dp[i]。

1. 题目理解

给你一个字符串 s 和一个字符串列表 wordDict 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 s 则返回 true。不要求字典中的单词全部使用，且单词可以重复使用。

示例

输入：s = "leetcode", wordDict = ["leet", "code"]
输出：true
解释："leetcode" 可由 "leet" 和 "code" 拼接成。

输入：s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
输出：false
拆分必须恰好覆盖整个字符串，不能多也不能少；单词可重复使用（如 "applepenapple"）。

2. 核心思路：枚举最后一个单词

  1. 状态定义：dp[i] = s 的前 i 个字符（s[0:i]）能否由字典单词组成；dp[0] = True（空串天然可拼）
  2. 状态转移：枚举「最后一个单词」的起点 j（0 ≤ j < i）：
    dp[i] = dp[j] 且 s[j:i] ∈ wordDict（任一 j 成立即可）
  3. 剪枝：找到一个成立的 j 立即 break；字典转 set 加速查询
  4. 答案：dp[n]
与「最长递增子序列」同构——都在问「最后一个部件是谁」：LIS 枚举倒数第二个元素，本题枚举最后一个单词的起点，dp[j] 是前缀合法性的接力棒。

3. 伪代码骨架

控制流与变量用代码表达，操作抽象为中文动宾短句，精确公式放在行尾注释：

words = 字典转集合            # words = set(wordDict)
dp = [False] * (n+1)
dp[0] = True                # 空串可拼

for i in range(1, n+1):
    for j in range(i):
        if dp[j] and s[j:i] in words:
            dp[i] = True; break   # 找到一个即可
return dp[n]
关键字 变量 中文操作 注释公式
dp[j] 是「接力棒」：只有前 j 个字符本身可拼，最后一个单词才是有效的增量——两条件缺一不可。

6. 代码逐段解释

class Solution:
    def wordBreak(self, s: str, wordDict: list[str]) -> bool:
        words = set(wordDict)      # 集合查询 O(1)
        n = len(s)
        dp = [False] * (n + 1)
        dp[0] = True               # 空字符串视为已成功拆分
        for i in range(1, n + 1):
            for j in range(i):      # 枚举最后一个单词的起点
                if dp[j] and s[j:i] in words:
                    dp[i] = True
                    break            # 找到即可，剪枝
        return dp[n]

逐段说明

  • dp 尺寸 n+1：下标 i 表示「前 i 个字符」，dp[0] 对应空串
  • 两条件短路求值：先查 dp[j]（O(1)）再切片查字典，避免无谓的字符串构造
  • break 剪枝：布尔问题找到一个证明即可停止

7. 复杂度分析

复杂度说明
时间O(n²)双重循环；切片与集合查询另计 O(词长)
空间O(n + Σ词长)dp 数组 + 字典集合

8. 常见易错点

忘记 dp[0] = True：整条接力链的起点，漏掉则所有 dp 恒为 False。
只用字典匹配不考虑前缀：只判断 s[j:i] ∈ words 而不管 dp[j]，会把「后半能拼、前半拼不出」的错误情况判真。
忘记 break：不影响正确性，但最坏情况下多做无用的切片与查询。
与「单词拆分 II（返回所有句子）」混淆：本题只问可行性；返回方案需回溯枚举，复杂度更高。

9. 总结

  • 状态：dp[i] = 前缀 s[0:i] 是否可拼，dp[0] 是接力起点
  • 转移：枚举最后一个单词起点 j，dp[j] ∧ s[j:i]∈字典
  • 技巧：set 查询 + break 剪枝
口诀：前缀可拼是接力，最后单词找起点；两条件同真才点亮，空串起点别忘记。
