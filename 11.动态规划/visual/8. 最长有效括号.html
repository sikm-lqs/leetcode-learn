8. 最长有效括号

以 ')' 结尾的两种形态转移：() 与 ))，跳跃回溯找配对。

1. 题目理解

给你一个只包含 '(' 和 ')' 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

示例

输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"

输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"

输入：s = ""
输出：0
「有效」= 每个左括号都有对应右括号闭合；「连续子串」必须是相邻的一段，不能跳跃拼接。

2. 核心思路：以 ')' 结尾分类讨论

有效括号串一定以 ')' 结尾，所以定义 dp[i] = 以 s[i] 结尾的最长有效括号子串长度（s[i] 为 '(' 时恒为 0）。对每个 s[i] == ')'：

  1. 情况 1："…()"：s[i-1] == '('，当前一对贡献 2，再接上更前面连续的有效段：
    dp[i] = 2 + dp[i-2]
  2. 情况 2："…))"：s[i-1] == ')'。跳过以 i-1 结尾的整段有效括号，回溯到位置 j = i - dp[i-1] - 1 找待配对的 '('。若 s[j] == '('：
    dp[i] = dp[i-1] + 2 + dp[j-1]
    （配对的一对 + 中间段 + j 前面相连的有效段）

答案 = max(dp)，因为最长有效括号不一定以最后一个字符结尾。

情况 2 的 j 是灵魂：dp[i-1] 告诉我们「以 i-1 结尾的有效段有多长」，直接跳过它直达可能配对的位置——一次转移 O(1)，不需要栈。

3. 伪代码骨架

控制流与变量用代码表达，操作抽象为中文动宾短句，精确公式放在行尾注释：

dp = [0] * n

for i in range(1, n):
    if s[i] == ')':
        if 前一个是 '('（情况1）:
            dp[i] = 2 + dp[i-2]       # …() 的接龙
        else （情况2 …))）:
            j = i - dp[i-1] - 1        # 跳过整段，找待配对的 '('
            if j >= 0 and s[j] == '(':
                dp[i] = dp[i-1] + 2 + dp[j-1]   # 一对 + 中间段 + 前缀段

return max(dp)
关键字 变量 中文操作 注释公式
三种「接龙」：() 接前段、)) 吞中间段再接 j 前段——dp 值本身记录了「连续有效段的长度」，是跳跃的尺子。

6. 代码逐段解释

class Solution:
    def longestValidParentheses(self, s: str) -> int:
        n = len(s)
        dp = [0] * n
        for i in range(1, n):
            if s[i] == ')':                  # 只有 ')' 能当结尾
                if s[i - 1] == '(':          # 情况 1：…()
                    dp[i] = 2
                    if i >= 2:
                        dp[i] += dp[i - 2]   # 接上前面连续的有效段
                else:                           # 情况 2：…))
                    j = i - dp[i - 1] - 1       # 跳过整段，找待配对的 '('
                    if j >= 0 and s[j] == '(':
                        dp[i] = dp[i - 1] + 2     # 配对一对 + 中间段
                        if j >= 1:
                            dp[i] += dp[j - 1] # j 前面还有连续段也接上
        return max(dp, default=0)  # 空串返回 0

逐段说明

  • 情况 1 的 dp[i-2]：如 "(())"，最内层 "()" 后面又包一层，2 要接上 i-2 处的段
  • 情况 2 的三段拼装：dp[i-1]（中间整段）+ 2（新配对的一对）+ dp[j-1]（j 左边相连段）
  • 边界防御：i ≥ 2、j ≥ 0、j ≥ 1 三处下标检查缺一不可

7. 复杂度分析

复杂度说明
时间O(n)一趟扫描，每个位置 O(1) 转移
空间O(n)dp 数组（栈解法可做到 O(1) 额外空间的两次扫描法也存在）

8. 常见易错点

返回 dp[n-1]：最长段不一定以最后一个字符结尾（示例 ")()())" 的 dp[5]=0 但答案是 4），必须取 max。
情况 2 忘加 dp[j-1]：如 "()(()"处理最后 ')' 时，j 前面还有 "()" 段要拼接，漏掉会得到 2 而非 4。
情况 1 忘加 dp[i-2]：如 "(())"，最外层 ')' 的 dp 应是 4 而非 2。
空串崩溃：n = 0 时 dp 为空，max() 抛异常，需 default=0。

9. 总结

  • 状态：dp[i] = 以 s[i] 结尾的最长有效括号长度（只有 ')' 非零）
  • 两形态："…()" 加 2 接前段；"…))" 跳跃回溯 j = i−dp[i−1]−1 配对
  • 答案：全局 max，不是 dp 末项
口诀：右括号才结尾，紧邻左括加二接前段；双右括跳段找配对，三段拼接取全局。
