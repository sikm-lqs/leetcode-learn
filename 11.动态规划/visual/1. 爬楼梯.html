1. 爬楼梯

经典线性 DP：dp[i] = dp[i-1] + dp[i-2]（斐波那契）。

1. 题目理解

假设你正在爬楼梯。需要 n 阶你才能到达楼顶。每次你可以爬 1 或 2 个台阶，问有多少种不同的方法可以爬到楼顶。

示例

输入：n = 2
输出：2
解释：1 阶 + 1 阶；2 阶

输入：n = 3
输出：3
解释：1+1+1、1+2、2+1
答案与斐波那契数列一致：1, 1, 2, 3, 5, 8, 13…（本题从 1, 1 起步）。

2. 核心思路：最后一步怎么走

  1. 状态定义：dp[i] = 爬到第 i 阶的方法数
  2. 状态转移：到达第 i 阶的最后一步只有两种情况——从 i-1 爬 1 阶（dp[i-1] 种），或从 i-2 爬 2 阶（dp[i-2] 种），故 dp[i] = dp[i-1] + dp[i-2]
  3. 边界：dp[0] = 1（什么都不做）、dp[1] = 1（爬 1 阶）
  4. 优化：只依赖前两个状态 → 滚动变量 prev1/prev2，空间降到 O(1)
dp[i] = dp[i−1] + dp[i−2]
核心思想：把「爬到楼顶有多少种方法」拆成「最后一步从哪来」——不关心中间过程，只关心子问题答案，这就是 DP 的无后效性。

3. 伪代码骨架

控制流与变量用代码表达，操作抽象为中文动宾短句，精确公式放在行尾注释：

if n == 1:
    return 1

prev2 = 1      # dp[0]
prev1 = 1      # dp[1]

for i in range(2, n+1):
    current = prev1 + prev2   # dp[i] = dp[i-1] + dp[i-2]
    滚动: prev2 = prev1; prev1 = current

return prev1      # 即 dp[n]
关键字 变量 中文操作 注释公式
滚动数组的本质：dp[i] 只用一次就不再需要，所以用两个变量「接力」，把 O(n) 空间压成 O(1)。

6. 代码逐段解释

class Solution:
    def climbStairs(self, n: int) -> int:
        if n == 1:
            return 1
        prev2 = 1          # dp[0]
        prev1 = 1          # dp[1]
        for i in range(2, n + 1):
            current = prev1 + prev2    # dp[i] = dp[i-1] + dp[i-2]
            prev2 = prev1              # 滚动：prev1 → prev2
            prev1 = current            # current → prev1
        return prev1

逐段说明

  • 边界 n == 1：直接返回，避免 n 过小时循环/索引问题
  • 滚动变量：只保留最近两个 dp 值，与 dp 数组版本完全等价
  • 循环次数：从 2 到 n 共 n-1 次迭代，每次算出新的 dp[i]

7. 复杂度分析

复杂度说明
时间O(n)从 2 到 n 一趟循环
空间O(1)滚动数组只用了两个变量（dp 数组版本为 O(n)）

8. 常见易错点

忘记 n == 1 边界：若不处理，循环 range(2, 2) 为空，但 prev1 初始化正确时其实也可行——关键是保证 dp[0]/dp[1] 语义清晰。
滚动顺序写反：必须先 prev2 = prev1 再 prev1 = current，顺序反了会丢失旧值。
dp[0] 的约定：dp[0] = 1 是「方便转移」的人为定义，不是真实爬法数。
数值溢出：n 较大时（如 45）答案达 18 亿级，Python 无此问题，但其它语言注意用长整型。

9. 总结

  • 状态转移：从「最后一步」出发，dp[i] = dp[i-1] + dp[i-2]
  • 滚动优化：只依赖前两个状态 → O(1) 空间
  • 范式：与斐波那契同构，是线性 DP 的入门题
口诀：最后一步定转移，边界先行两状态；只要前两不要全，滚动数组省空间。
