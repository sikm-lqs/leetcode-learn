4. 环形链表

给定链表头节点 head，判断链表中是否有环。

📋 目录

1. 题目理解 2. 核心思路：快慢指针 3. 伪代码骨架 4. 交互可视化演示 5. 详细过程模拟 6. 代码逐段解释 7. 复杂度分析 8. 常见易错点 9. 总结

1. 题目理解

给定单链表的头节点 head，判断链表中是否存在环。如果有环返回 true，否则返回 false。

关键：「环」是指链表中某个节点的 next 指针再次指向链表中靠前的节点，从而形成循环。判断条件不是「值相等」，而是「指针再次回到之前走过的节点」。

示例 1（有环）

输入：head = [3, 2, 0, -4]，pos = 1
输出：true

下标 0:3, 1:2, 2:0, 3:-4。尾节点 -4 的 next 指回下标 1（节点 2），形成环。

3 → 2 → 0 → -4

弧线表示 -4 的 next 指回节点 2（成环）

示例 2（无环）

输入：head = [1, 2, 3]，pos = -1
输出：false
1 → 2 → 3 → null

2. 核心思路：快慢指针

🐢 slow 慢指针

每次走 1 步：slow = slow.next

🐇 fast 快指针

每次走 2 步：fast = fast.next.next

算法流程

  1. 初始化 slow = fast = head，两指针同时从头出发
  2. 当 fast 和 fast.next 都不为空时，循环：
  3.   slow = slow.next     // 慢指针走 1 步
  4.   fast = fast.next.next // 快指针走 2 步
  5.   if slow is fast: return True // 相遇 → 有环
  6. 循环正常结束（fast 先到 null）→ 返回 False
核心洞察（龟兔赛跑）：fast 比 slow 每轮多走 1 步，即相对速度为 1。若有环，两指针都进入环后，距离每轮缩小 1，迟早追上；若无环，fast 一定先到达 null。空间只用两个指针，O(1)。

5. 详细过程模拟

以 head = [3, 2, 0, -4]，pos = 1 为例。next 关系：0→1→2→3→1→…（成环）。

初始：slow = fast = 头节点 3

slow/fast3 → 2 → 0 → -4

两指针同在起点；弧线表示环回（-4 → 2）

第 1 轮：slow 走 1 步，fast 走 2 步

slow = 2（节点下标 1），fast = 0（节点下标 2，已超前）

3 → slow2 → fast0 → -4

第 2 轮：slow 到 0，fast 跳到 2（绕环）

slow = 0（下标 2），fast = 2（下标 1，fast 从下标 2 走两步：3→1，已在环里绕了一圈）

3 → fast2 → slow0 → -4

第 3 轮：两指针在 -4 相遇！✅

slow = -4（下标 3），fast = -4（下标 3，从下标 1 走两步：2→3）→ slow is fast → 返回 true

3 → 2 → 0 → slow/fast-4
✅ 相遇即有环，返回 true。

对比：无环示例 [1, 2, 3]（pos = -1）

fast 先到达 null：slow=1→2→3，fast=1→3→null。循环条件 fast and fast.next 不满足，跳出循环，返回 false。

slow1 → 2 → fast3 → null
fast.next 为 null → 退出循环 → 返回 false。

6. 代码逐段解释

完整代码

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def hasCycle(self, head: ListNode) -> bool:
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:
                return True
        return False

逐段说明

第 1 步：初始化快慢指针

slow = fast = head

两个指针同时指向头节点，准备同时出发。

第 2 步：循环条件

while fast and fast.next:

fast 每次走 2 步，所以要同时检查 fast 和 fast.next 都不为空，否则会越界（None.next 报错）。一旦任一为空，说明 fast 先到链表末尾，无环。

第 3 步：两指针前进

slow = slow.next
fast = fast.next.next

slow 走 1 步，fast 走 2 步。每轮两者距离变化 1 步。

第 4 步：判断相遇

if slow is fast:
    return True

若两指针指向同一个节点对象（用 is 判同一引用，而非值相等），说明 fast 追上了 slow，有环。

第 5 步：循环退出

return False

fast 到达 null（无环），返回 False。

用 is 不用 ==：环的判定标准是「指针指向同一节点」，而非「节点值相等」。链表中可能有多个值相同的节点，用 == 会误判。

7. 复杂度分析

维度值说明
时间复杂度O(n)无环时 fast 走 n/2 步到末尾；有环时 slow 进环最多 n 步，fast 最多再绕一圈追上。总体 O(n)。
空间复杂度O(1)只用 slow、fast 两个指针变量，常数空间。
追上步数的直观理解：两指针都进入环后，fast 与 slow 的距离每轮缩小 1（fast 多走 1 步），环长最多 n，所以最多再走 n 步必然相遇。

8. 常见易错点

错误一：循环条件写错

while fast.next:        # ❌ fast 为 None 时会报错
while fast:              # ❌ fast.next 为 None 时仍进循环，fast.next.next 越界
while fast and fast.next:  # ✅ 同时检查，安全

因为 fast 一次走两步，必须保证 fast 和 fast.next 都存在。

错误二：用 == 判断相遇

if slow.val == fast.val:  # ❌ 值相等不代表同一节点
if slow is fast:           # ✅ 同一对象引用

判定环要看「指针重新指向之前走过的节点」，即引用相同。

错误三：忘记 slow/fast 同时从头出发

slow, fast = head, head.next  # ❌ 起点不同，可能错过相遇
slow = fast = head             # ✅ 同起点

边界情况

输入说明
head = []fast = None 直接跳过循环，返回 False
head = [1] 无环fast.next = None，不进循环，返回 False
head = [1] 自环（pos=0）第 1 轮 slow=1、fast=1，slow is fast → 返回 True

9. 总结

环形链表 精髓：

  • 快慢双指针（龟兔赛跑）：slow 1 步、fast 2 步
  • 相对速度为 1，有环必相遇
  • 无环时 fast 先到 null，循环退出
  • 时间 O(n)，空间 O(1)
class Solution:
    def hasCycle(self, head):
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:
                return True
        return False

💡 口诀：快慢同起步，每轮差一步；相遇即有环，fast 空则无。
