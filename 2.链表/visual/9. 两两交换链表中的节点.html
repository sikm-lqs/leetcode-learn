9. 两两交换链表中的节点

给定链表，两两交换相邻节点，返回头节点。必须交换节点本身（不能只改值）。

📋 目录

1. 题目理解 2. 核心思路：迭代 + 哑节点 3. 交互可视化演示 4. 详细过程模拟 5. 代码逐段解释 6. 复杂度分析 7. 常见易错点 8. 总结

1. 题目理解

给定一个链表的头节点 head，两两交换其中相邻的节点，并返回交换后链表的头节点。必须真正交换节点本身（修改 next 指针），不能只是修改节点里的值。

关键：不能偷懒只交换 val——题目要求修改指针关系，锻炼链表操作能力。

示例

输入：head = [1, 2, 3, 4]
输出：[2, 1, 4, 3]
1 → 2 → 3 → 4 → null

交换后变为：2 → 1 → 4 → 3 → null

2. 核心思路：迭代 + 哑节点

📌 引入哑节点 dummy

dummy.next = head。让第一对节点的「前驱」也有一个前驱，统一奇偶长度的处理逻辑。

🔁 每轮做四件事

取 first / second / rest → 重排三条指针 → cur 前进到 first。

算法流程

  1. 初始化 dummy.next = head，cur = dummy
  2. 当 cur.next 与 cur.next.next 都不为空时，循环：
  3.   first = cur.next      // 待交换左节点
  4.   second = cur.next.next // 待交换右节点
  5.   rest = second.next        // 先保存，防断链
  6.   cur.next = second      // 前驱接 second
  7.   second.next = first      // second 接 first（完成两节点互换）
  8.   first.next = rest         // first 接后半段
  9.   cur = first                // cur 前进一对
  10. 循环结束返回 dummy.next
核心洞察：关键是「先保存 rest」——一旦修改 second.next，原 second 之后的链就会丢失。dummy 让第一对的前驱与后续完全一致，无需特判头节点。

4. 详细过程模拟

以 head = [1, 2, 3, 4] 为例，重点拆解三指针重排的过程。

初始：dummy → 1 → 2 → 3 → 4

取 cur = dummy，待交换第一对 (1, 2)。先保存 rest = second.next = 3。

curd → first1 → second2 → rest3 → 4

三步重排（核心动作）

第 1 步： cur.next = second —— 前驱绕过 first，直接接 second。

dummy.next = 2   // 原 dummy.next=1 被覆盖，需先存好 first

第 2 步： second.next = first —— second 反过来接 first，完成两节点互换。

2.next = 1   // 原 2.next=3 被覆盖，故必须先存好 rest

第 3 步： first.next = rest —— first 接回后半段，链不断裂。

1.next = 3   // 把保存的 rest 拼回去

交换后：dummy → 2 → 1 → 3 → 4

d → 2 → cur1 → 3 → 4

cur = first = 1，准备处理下一对 (3, 4)，逻辑完全相同。

关键：三条赋值顺序看似可调，但 rest 必须在任何修改之前保存好；否则 second.next 一旦改写，后半段就再也找不回来了。

结束：cur.next = null，返回 dummy.next

d → 2 → 1 → 4 → head3 → null
✅ 两对全部交换完成：2 → 1 → 4 → 3 → null

5. 代码逐段解释

完整代码

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def swapPairs(self, head: ListNode) -> ListNode:
        dummy = ListNode(0, head)
        cur = dummy
        while cur.next and cur.next.next:
            first = cur.next
            second = cur.next.next
            rest = second.next
            cur.next = second
            second.next = first
            first.next = rest
            cur = first
        return dummy.next

逐段说明

第 1 步：建立哑节点

dummy = ListNode(0, head)
cur = dummy

dummy.next = head，让第一对节点也有「前驱」；cur 从 dummy 出发，循环不变量：cur 始终是待交换一对的前驱节点。

第 2 步：循环条件——保证还有一对

while cur.next and cur.next.next:

只有当 cur 后面至少有两个节点时才交换。and 短路保证不会对 None.next 求值。

第 3 步：取三个引用，先存后改

first = cur.next
second = cur.next.next
rest = second.next   # 关键：保存后半段

first / second 是要交换的一对；rest 是这对之后的链头，必须在改写指针前先存好。

第 4 步：三步重排指针

cur.next = second    # 前驱接 second
second.next = first  # second 接 first
first.next = rest     # first 接后半段

三条赋值把 cur→first→second→rest 改写为 cur→second→first→rest，节点本身互换。

第 5 步：cur 前进，循环

cur = first

交换后 first 是这对中的第二个（即下一对的前驱位置），cur 跳过去继续处理。

返回 dummy.next 而非 head：交换后头节点已变为原第二个节点，dummy.next 始终指向真正的新头。

6. 复杂度分析

维度值说明
时间复杂度O(n)每对节点只访问一次，n 个节点共 ⌊n/2⌋ 轮。
空间复杂度O(1)只使用 dummy / cur / first / second / rest 几个指针变量，原地交换。

7. 常见易错点

错误一：忘记保存 rest，后半段丢失

# 错误：先改 second.next，原后半段就丢了
cur.next = second
second.next = first    # ❌ second.next 原指向 rest，现在被覆盖
first.next = second.next  # 拿到的不是 rest，而是 first 自己！死循环

必须在任何修改之前执行 rest = second.next。

错误二：忘记 cur 前进，死循环

cur.next = second
second.next = first
first.next = rest
# 漏掉 cur = first  → 下一轮 cur 不变，永远重复同一对

错误三：奇数长度漏判

# 循环条件必须同时判断两个 next
while cur.next and cur.next.next:

奇数长度时最后一个节点 cur.next.next = None，循环自动停止，不交换该孤尾节点。

边界情况

输入说明
head = []cur.next = None，直接跳过循环，返回 None
head = [1]cur.next.next = None，不交换，返回节点 1
head = [1,2]一轮后 cur = 2，cur.next = None，返回 2→1

8. 总结

两两交换链表节点 精髓：

  • 哑节点统一「第一对」与「后续对」的处理逻辑
  • 三指针 first / second / rest，先存后改
  • 口诀：取一对、存 rest、三条改、cur 走
  • 空间 O(1)，时间 O(n)
class Solution:
    def swapPairs(self, head):
        dummy = cur = ListNode(0, head)
        while cur.next and cur.next.next:
            first, second = cur.next, cur.next.next
            cur.next, second.next, first.next = second, first, second.next
            cur = first
        return dummy.next

💡 口诀：dummy 立前哨，first second 各取好；rest 先存防断链，三指一挥节换掉。
