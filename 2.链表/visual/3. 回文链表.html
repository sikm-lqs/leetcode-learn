3. 回文链表

给定单链表头节点 head，判断是否为回文链表。

1. 题目理解

给定一个单链表的head，判断该链表是否为回文（正读反读都一样）。

约束：要求时间 O(n)、空间 O(1)。回文即「前半段」与「反转后的后半段」完全相同。

示例

输入：head = [1, 2, 2, 1]
输出：true

输入：head = [1, 2, 3, 2, 1]
输出：true

输入：head = [1, 2, 3, 4]
输出：false
1 → 2 → 2 → 1 → null

从左读：1→2→2→1，从右读：1→2→2→1，相同 → 回文。

2. 核心思路：找中点 → 反转后半 → 对撞比较

🐢 快慢指针找中点

slow 走一步、fast 走两步。当 fast 到达末尾时，slow 正好停在中点。

🔁 原地反转后半段

从 slow 开始，用三指针法把后半段反转，得到右指针 right（原尾节点）。

⚖️ 左右对撞比较

left 从头出发向右，right 从尾出发向左，逐个比较 val，全部相等即回文。

💡 空间优化

不借助数组，所有操作在原链表上完成，空间 O(1)。

算法流程

  1. 初始化 slow = fast = head
  2. 当 fast 与 fast.next 都不为空时循环：slow = slow.next，fast = fast.next.next
  3. 循环结束时 slow 停在后半段起点
  4. 从 slow 开始反转后半段，得到新头 prev
  5. 令 left = head，right = prev，同时前进比较：left.val 与 right.val
  6. 若出现不等，返回 false；若 right 走到 null，返回 true
核心洞察：slow 走一步、fast 走两步定位中点；反转后半段后，right 从尾向中间走、left 从头向中间走，一次遍历完成比较。

4. 详细过程模拟

以 head = [1, 2, 2, 1] 为例，展示两个关键画面。

关键画面一：快慢指针定位中点

slow 每次走一步，fast 每次走两步。当 fast 无法再前进时，slow 恰好停在后半段的起点。

1 → 2 → slow2 → fast1

fast 走到末尾（下标 3），slow 停在中点（下标 2）。

关键画面二：反转后半段后左右对撞比较

把后半段 [2(下标2), 1] 反转为 1 → 2，right 指向新头（原尾节点 1）。然后 left 从左向右、right 从右向左，逐位比较。

left1 → 2 ← 2 ← right1

绿色 ← 表示后半段已反转。left=1, right=1，相等；继续推进。

比较过程中，left 与 right 在中间相遇，全部相等即回文。

5. 代码逐段解释

完整代码

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def isPalindrome(self, head: ListNode) -> bool:
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        prev = None
        cur = slow
        while cur:
            nxt = cur.next
            cur.next = prev
            prev = cur
            cur = nxt
        left, right = head, prev
        while right:
            if left.val != right.val:
                return False
            left = left.next
            right = right.next
        return True

逐段说明

第 1 步：快慢指针找中点

slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next

slow 走一步、fast 走两步。循环条件 fast and fast.next 保证 fast 不会越界。循环结束时 slow 恰好停在后半段起点。

第 2 步：原地反转后半段

prev = None
cur = slow
while cur:
    nxt = cur.next
    cur.next = prev
    prev = cur
    cur = nxt

从 slow 开始，用经典三指针法反转。prev 最终指向反转后的新头（原尾节点）。

第 3 步：左右对撞比较

left, right = head, prev
while right:
    if left.val != right.val:
        return False
    left = left.next
    right = right.next
return True

left 从原头出发向右，right 从反转后的头（原尾）出发向左（链表方向上即向中间走）。任一对不等立即返回 False；right 走到 null 说明全部匹配。

循环以 right 为准：后半段长度 ≤ 前半段，right 先到 null，正好覆盖所有需要比较的节点。

6. 复杂度分析

维度值说明
时间复杂度O(n)找中点 O(n) + 反转后半 O(n/2) + 比较 O(n/2)，整体 O(n)。
空间复杂度O(1)只用若干指针变量，原地完成。
相比「复制到数组再用双指针」的 O(n) 空间解法，本方案把空间压到 O(1)。

7. 常见易错点

错误一：快慢指针循环条件写错

while fast.next:        # ❌ 偶数长度时会越界
while fast:             # ❌ fast.next 可能是 None
while fast and fast.next:  # ✅ 同时判 fast 与 fast.next

错误二：反转后半段后比较循环条件错

while left:             # ❌ left 比 right 多一个，会读到后半段
while right:            # ✅ right 长度 ≤ left，先到 null

对照：数组法（空间 O(n)）

# 思路更直观，但空间 O(n)
vals = []
cur = head
while cur:
    vals.append(cur.val)
    cur = cur.next
return vals == vals[::-1]  # 判断正反是否相同

复制到数组后双指针对撞，思路简单但空间 O(n)，不满足进阶要求。

边界情况

输入说明
head = []空链表视为回文，返回 True
head = [1]单节点，fast 不动，后半段反转后即自身，返回 True
head = [1,2]slow 停在 2，反转后比较 1 与 2，不等返回 False
奇数长度 [1,2,3,2,1]slow 停在中间 3，反转 [3,2,1] 后 right 从 1 走到 null，正好忽略中间节点

8. 总结

回文链表 精髓：

  • 快慢指针 slow / fast 定位中点
  • 三指针法反转后半段，得到右指针
  • 左右对撞逐位比较 val
  • 时间 O(n)，空间 O(1)
class Solution:
    def isPalindrome(self, head):
        slow = fast = head
        while fast and fast.next:
            slow, fast = slow.next, fast.next.next
        prev, cur = None, slow
        while cur:
            cur.next, prev, cur = prev, cur, cur.next
        left, right = head, prev
        while right:
            if left.val != right.val:
                return False
            left, right = left.next, right.next
        return True

💡 口诀：快慢找中点，反转后半段，左右齐对撞，全等即回文。
