7. 两数相加

两个非空链表表示两个非负整数（逆序存储，每位一位数字），返回表示和的链表。

📋 目录

1. 题目理解 2. 核心思路：模拟加法 + 进位 3. 交互可视化演示 4. 详细过程模拟 5. 代码逐段解释 6. 复杂度分析 7. 常见易错点 8. 总结

1. 题目理解

给出两个非空链表，每个节点存一位数字，且数字按逆序存储（链表头是最低位）。将这两个数相加，返回一个同样逆序存储和的链表。

关键：逆序存储意味着链表头恰好是「个位」——加法从最低位开始，正好可以从两个链表头同时向前走。

示例

输入：l1 = [2,4,3], l2 = [5,6,4]   （即 342 + 465）
输出：[7,0,8]                        （即 807，342 + 465 = 807）
2 → 4 → 3 → null

l1 = [2,4,3]，逆序读即 342（个位→十位→百位）

5 → 6 → 4 → null

l2 = [5,6,4]，逆序读即 465

2. 核心思路：模拟加法 + 进位

📌 哑节点 + 游标

用 dummy 哨兵节点简化头部处理，cur 始终指向结果链表的尾。

🔢 逐位相加

每位 s = x + y + carry，写入 s % 10，新进位 s // 10。

算法流程

  1. 建立哑节点 dummy，cur = dummy，carry = 0
  2. 当 l1 or l2 or carry 不为空/零时循环：
  3.   x = l1.val if l1 else 0  // 缺位补 0
  4.   y = l2.val if l2 else 0
  5.   s = x + y + carry
  6.   carry = s // 10    // 进位
  7.   cur.next = ListNode(s % 10)  // 写入低位
  8.   cur = cur.next，l1、l2 各自前进一步（非空时）
  9. 循环结束，返回 dummy.next
核心洞察：逆序存储恰好对应从低位到高位的加法顺序——链表头就是个位，可以直接从头同步遍历。哑节点避免了「头节点是否进位」的特判，while 条件里带上 carry 保证结束后剩余进位也会被建出新节点。

5. 代码逐段解释

完整代码

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        dummy = cur = ListNode(0)
        carry = 0
        while l1 or l2 or carry:
            x = l1.val if l1 else 0
            y = l2.val if l2 else 0
            s = x + y + carry
            carry = s // 10
            cur.next = ListNode(s % 10)
            cur = cur.next
            if l1:
                l1 = l1.next
            if l2:
                l2 = l2.next
        return dummy.next

逐段说明

第 1 步：建立哑节点与游标

dummy = cur = ListNode(0)
carry = 0

dummy 是哨兵节点，避免单独处理头节点；cur 始终指向结果链表的尾，方便 O(1) 追加。最终返回 dummy.next 跳过哨兵。

第 2 步：循环条件带上 carry

while l1 or l2 or carry:

只要还有未处理的输入位 或 还有进位，就继续。这一句把「两链表遍历完但 carry=1」的边界情况自动纳入循环，避免遗漏最高位的进位节点。

第 3 步：取当前位（缺位补 0）

x = l1.val if l1 else 0
y = l2.val if l2 else 0

当某条链表已遍历完，把它当作 0 参与运算，逻辑统一、无需特判。

第 4 步：相加、写位、算进位

s = x + y + carry
carry = s // 10
cur.next = ListNode(s % 10)
cur = cur.next

总和 s 最多 9+9+1=19，所以 s % 10 是当前位、s // 10 是新进位（0 或 1）。把新节点接到 cur.next 后让 cur 前进。

第 5 步：两条输入链表各前进一步

if l1:
    l1 = l1.next
if l2:
    l2 = l2.next

非空时才前进，避免对 None 取 .next 报错。

最后 return dummy.next 跳过哨兵节点，返回真正的和链表头。

6. 复杂度分析

维度值说明
时间复杂度O(max(m, n))遍历较长的链表（含可能的最后一位进位），m、n 为两链表长度。
空间复杂度O(max(m, n))结果链表长度最多为 max(m, n) + 1（最后再进一位）。
结果链表本身不计入空间复杂度时为 O(1) 额外空间——只用了 dummy、cur、carry 等常数个变量。

7. 常见易错点

错误一：循环条件漏掉 carry

while l1 or l2:        # ❌ 漏掉 carry
    ...

当两条链表同时遍历完、但最高位产生了进位 carry=1 时，这个进位会被丢弃，导致结果少一位。

错误二：先算进位还是先取位？

carry = s // 10
cur.next = ListNode(s % 10)   # ✅ s 未被修改，正确
cur.next = ListNode(s % 10)
carry = s // 10                # ✅ 顺序无影响，因 s 未变

只要不动 s，两行顺序无关；但不要写成 s = s % 10 后再 carry = s // 10——那样进位恒为 0。

边界情况（重要）

输入说明
[0] + [0]一位即结束，返回 [0]，carry 始终为 0。
[9,9,9] + [1]999 + 1 = 1000 → [0,0,0,1]。两链表长度不等且结束后 carry 仍为 1，必须再建一个节点。
长度不等短链表遍历完后 x 或 y 自动补 0，if l1: l1=l1.next 防止对 None 取 next。
典型坑：[9,9,9] + [1]。前 3 位分别得 0、0、0（carry 全为 1），两链表都遍历完，但 carry=1，需要 while 条件里的 or carry 把最后这个 1 写成新节点 → 结果 [0,0,0,1]。

第二个示例：[9,9,9] + [1] = [0,0,0,1]

9 + 1 + 0 = 10 → 写 0，carry 1   （l1→第 2 位，l2 已 null）
9 + 0 + 1 = 10 → 写 0，carry 1   （l1→第 3 位）
9 + 0 + 1 = 10 → 写 0，carry 1   （l1 已 null）
0 + 0 + 1 =  1 → 写 1，carry 0   ← 关键！靠循环里的 or carry 触发
结果：[0,0,0,1]  即 1000  ✅ (999 + 1 = 1000)

8. 总结

两数相加 精髓：

  • 逆序存储 ↔ 从低位加起，链表头就是「个位」
  • dummy 哑节点简化头部处理，最后返回 dummy.next
  • 口诀：x + y + carry，写 %10，进 //10
  • 循环条件 while l1 or l2 or carry 一并处理剩余进位
  • 缺位补 0，if l1: l1=l1.next 防 None 报错
class Solution:
    def addTwoNumbers(self, l1, l2):
        dummy = cur = ListNode(0)
        carry = 0
        while l1 or l2 or carry:
            x = l1.val if l1 else 0
            y = l2.val if l2 else 0

            cur.next = ListNode(s % 10)
            cur = cur.next
            if l1: l1 = l1.next
            if l2: l2 = l2.next

💡 口诀：dummy 当头，cur 接尾；缺位补零，进位靠 or。
