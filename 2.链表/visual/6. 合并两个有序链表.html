6. 合并两个有序链表

将两个升序链表合并为一个新的升序链表并返回。

1. 题目理解

给定两个升序链表 list1 和 list2，将它们合并为一个新的升序链表并返回头节点。新链表由拼接原链表的节点组成（不新建节点）。

关键：两个输入都已排好序，只需每次挑两者头部中较小的接到结果末尾。

示例

输入：list1 = [1, 2, 4], list2 = [1, 3, 4]
输出：[1, 1, 2, 3, 4, 4]
1 → 2 → 4 → null

1 → 3 → 4 → null

2. 核心思路：迭代 + 哑节点

📌 关键变量

dummy（哑节点，结果头部哨兵）、cur（结果链表当前尾）、list1/list2（两个扫描指针）。

🔁 每轮做一件事

比较 list1.val 与 list2.val，较小者接到 cur.next，对应指针后移，cur 也后移。

算法流程

  1. 新建 dummy = ListNode(0)，令 cur = dummy
  2. 当 list1 与 list2 都不为空时，循环：
  3.   若 list1.val ≤ list2.val：cur.next = list1，list1 = list1.next
  4.   否则：cur.next = list2，list2 = list2.next
  5.   cur = cur.next   // 结果尾指针前进
  6. 循环结束后：cur.next = list1 if list1 else list2   // 接上剩余部分
  7. 返回 dummy.next（跳过哑节点）
核心洞察：哑节点 dummy 让「头节点」不再特殊——所有节点都通过 cur.next = ... 统一接入，循环里无需判断是否为结果头。遍历一次同时完成比较与接入。

4. 详细过程模拟

以 list1 = [1, 2, 4]、list2 = [1, 3, 4] 为例，重点展示「比较并接入」的典型两步。

初始：dummy 为头，cur 指向 dummy

curdummy

结果链表此时只有哨兵节点 dummy（val=0）。

第 1 步：比较 list1=1 与 list2=1

1 ≤ 1 成立，取 list1 的 1：cur.next = list1，list1 后移到 2。

dummy → cur1
list12 → 4 → null
list21 → 3 → 4 → null
相等时取 list1（条件写成 ≤），结果稳定。

第 2 步：比较 list1=2 与 list2=1

2 > 1，取 list2 的 1：cur.next = list2，list2 后移到 3。

dummy → 1 → cur1
list12 → 4 → null
list23 → 4 → null
以此类推，每次把两个头部中较小者摘下来接上，直到某条链表被取空。

结束：list1 先空，接上 list2 剩余节点

当某条链表为空时，另一条剩余部分整体拼到 cur.next。

dummy → 1 → 1 → 2 → 3 → 4 → head4 → null
✅ 合并完成：1 → 1 → 2 → 3 → 4 → 4 → null，返回 dummy.next。

5. 代码逐段解释

完整代码

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def mergeTwoLists(self, list1: ListNode, list2: ListNode) -> ListNode:
        dummy = ListNode(0)
        cur = dummy
        while list1 and list2:
            if list1.val <= list2.val:
                cur.next = list1
                list1 = list1.next
            else:
                cur.next = list2
                list2 = list2.next
            cur = cur.next
        cur.next = list1 if list1 else list2
        return dummy.next

逐段说明

第 1 步：建立哑节点

dummy = ListNode(0)
cur = dummy

dummy 是结果链表的哨兵，cur 始终指向结果链表的「当前最后一个节点」。这样头节点的接入和后续节点完全统一。

第 2 步：双指针比较循环

while list1 and list2:
    if list1.val <= list2.val:
        cur.next = list1
        list1 = list1.next
    else:
        cur.next = list2
        list2 = list2.next
    cur = cur.next

只要两条链表都还有节点，就比较它们当前头节点：较小者接到 cur.next，对应链表指针前进一步；最后 cur 也要前进一步，保持指向尾端。

第 3 步：接上剩余部分

cur.next = list1 if list1 else list2

循环结束时必有一条链表已空，另一条剩余的节点本身已是有序，直接整段接到 cur.next 即可。

第 4 步：返回真实头节点

return dummy.next
dummy 只是辅助节点，真正的头是 dummy.next。

6. 复杂度分析

维度值说明
时间复杂度O(m + n)每个节点至多被访问一次（m、n 为两链表长度）。
空间复杂度O(1)只新增 dummy 与 cur 两个指针变量，原地拼接节点。
若采用递归写法，空间为 O(m + n)（递归栈），故迭代法在空间上更优。

7. 常见易错点

错误一：忘记处理剩余链表

# 错误：循环结束后直接 return，剩余节点全丢
while list1 and list2:
    ...
    cur = cur.next
return dummy.next   # ❌ 某条链表可能还有节点未接上！

必须补一句 cur.next = list1 if list1 else list2，否则会丢失较长链表的尾部。

错误二：返回 dummy 而非 dummy.next

return dummy      # ❌ 把哨兵节点 val=0 也算进结果
return dummy.next  # ✅ 跳过哨兵，返回真正的头

错误三：循环里漏掉 cur = cur.next

while list1 and list2:
    if list1.val <= list2.val:
        cur.next = list1
        list1 = list1.next
    else:
        cur.next = list2
        list2 = list2.next
    # ❌ 忘记 cur = cur.next → 后续会覆盖 cur.next，链表只剩一个节点

边界情况

输入说明
[] 与 []循环跳过，cur.next = None，返回 None
[] 与 [0]循环跳过，cur.next = list2，返回 list2
两条等长链表循环结束两条同时为空，剩余语句接 None

8. 总结

合并两个有序链表 精髓：

  • 哑节点 dummy 统一了头节点的接入逻辑
  • 口诀：比两值 → 接较小 → 移双针
  • 循环结束后必须接上「未空的那条」剩余部分
  • 时间 O(m+n)，空间 O(1)
class Solution:
    def mergeTwoLists(self, list1, list2):
        dummy = cur = ListNode(0)
        while list1 and list2:
            if list1.val <= list2.val:
                cur.next, list1 = list1, list1.next
            else:
                cur.next, list2 = list2, list2.next
            cur = cur.next
        cur.next = list1 or list2
        return dummy.next

💡 口诀：哑节点先占位，两两比较接较小；任一为空补剩余，回头跳过 dummy。
