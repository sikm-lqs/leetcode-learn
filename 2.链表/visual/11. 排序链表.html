11. 排序链表

给定链表头节点 head，将其按升序排序并返回。

📋 目录

1. 题目理解 2. 核心思路：链表转数组 3. 交互可视化演示 4. 详细过程模拟 5. 代码逐段解释 6. 复杂度分析 7. 常见易错点 8. 总结

1. 题目理解

给定单链表的头节点 head，将其按升序排序，并返回排好序的链表头节点。

关键：返回一条由原节点值组成的、升序排列的新链表。本题采用「链表转数组」的简化解法。

示例

输入：head = [4, 2, 1, 3]
输出：[1, 2, 3, 4]
4 → 2 → 1 → 3 → null

排序后变为：1 → 2 → 3 → 4 → null

2. 核心思路：链表转数组

📌 三阶段

收集（链表 → 数组）→ 排序（数组排序）→ 重建（数组 → 新链表）。

🔧 关键工具

Python 的 list.sort() 采用 Timsort，时间 O(n log n)，稳定高效。

算法流程

  1. 创建空数组 nums = []，指针 cur = head
  2. 遍历链表，把每个 cur.val 加进 nums
  3. 调用 nums.sort() 升序排序
  4. 建立虚拟头 dummy = ListNode(0)，cur = dummy
  5. 遍历 nums，每读一个值就 cur.next = ListNode(num)，cur 后移
  6. 返回 dummy.next
核心洞察：把「链表排序」转化为「数组排序」。链表不擅长随机访问与排序，而数组排序有 Timsort 这样现成的高效实现，于是用空间换简洁。

4. 详细过程模拟

以 head = [4, 2, 1, 3] 为例，分三阶段展示。

阶段一：收集（链表 → 数组）

从 head 开始遍历，把每个节点的值 append 到 nums。

cur4 → 2 → 1 → 3 → null
4 2 1 3

遍历结束后：nums = [4, 2, 1, 3]

阶段二：排序（Timsort, O(n log n)）

调用 nums.sort()，对数组升序排序。

4 2 1 3 → sort → 1 2 3 4

排序后：nums = [1, 2, 3, 4]

阶段三：重建（数组 → 新链表）

用 dummy 虚拟头逐个新建节点并接入。

dummy0 → 1 → 2 → 3 → head4 → null
✅ 返回 dummy.next，结果链表：1 → 2 → 3 → 4 → null

5. 代码逐段解释

完整代码

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def sortList(self, head: ListNode) -> ListNode:
        nums = []
        cur = head
        while cur:
            nums.append(cur.val)
            cur = cur.next
        nums.sort()

        dummy = ListNode(0)
        cur = dummy
        for num in nums:
            cur.next = ListNode(num)
            cur = cur.next
        return dummy.next

逐段说明

第 1 步：遍历链表，收集值到数组

nums = []
cur = head
while cur:
    nums.append(cur.val)
    cur = cur.next

从 head 起逐个访问节点，把 val 追加进 nums，cur 后移直到 None。这一步把链表的值「拍平」成数组。

第 2 步：对数组排序

nums.sort()

调用 Python 列表的原地排序 sort()，底层是 Timsort（归并 + 插入的混合），平均/最坏均为 O(n log n)。

第 3 步：用 dummy 重建链表

dummy = ListNode(0)
cur = dummy
for num in nums:
    cur.next = ListNode(num)
    cur = cur.next
return dummy.next

建立虚拟头 dummy（简化首节点处理），遍历排序后的数组，每读一个值就新建节点接到 cur.next，然后 cur 后移。最后 dummy.next 即为新链表的头。

dummy 节点的经典用法：避免单独处理「链表为空时要不要建第一个节点」的边界，统一成「永远往 cur.next 接」。

6. 复杂度分析

维度值说明
时间复杂度O(n log n)遍历 O(n) + Timsort O(n log n) + 重建 O(n)，主导项为排序。
空间复杂度O(n)额外开辟长度 n 的 nums 数组，以及重建的 n 个新节点。
进阶提示：题目 follow-up 通常要求 O(n log n) 时间 + O(1) 空间。本页的数组法空间是 O(n)，适合入门理解。若面试要求 O(1) 额外空间，标准解法是 链表归并排序：自顶向下用快慢指针找中点后递归合并（递归栈 O(log n)）；或自底向上迭代归并（真正 O(1) 额外空间）。

7. 常见易错点

错误一：忘了 dummy，首节点处理出错

# 错误：直接用 head 接，但 head 可能被改变/丢失
cur = head
for num in nums:
    cur.next = ListNode(num)
    cur = cur.next   # ❌ head 原节点的值还在，结果链表会多出一个旧值
return head          # ❌ 多了原链表第一个节点

正确做法是用 dummy = ListNode(0) 作为新起点，最后返回 dummy.next。

错误二：重建时没让 cur 前进

for num in nums:
    cur.next = ListNode(num)
    # ❌ 忘了 cur = cur.next，所有节点叠在 cur.next 上

每次接入新节点后必须 cur = cur.next，把游标推进到新节点上。

错误三：返回错节点

return dummy    # ❌ dummy 是虚拟头，val=0，不是结果
return cur      # ❌ cur 停在最后一个节点，丢了前面
return dummy.next  # ✅ 真正的结果头

边界情况

输入说明
head = []循环不执行，nums = []，重建后 dummy.next = None
head = [1]遍历得 nums=[1]，排序不变，重建出单节点链表
含重复值数组法天然支持重复值，Timsort 是稳定排序

8. 总结

排序链表（数组法） 精髓：

  • 三阶段：收集 → 排序 → 重建
  • 用 dummy 简化链表构建的首节点处理
  • 把难题让给专业工具：Timsort 负责 O(n log n) 排序
  • 时间 O(n log n)、空间 O(n)，清晰易懂
class Solution:
    def sortList(self, head):
        nums, cur = [], head
        while cur:
            nums.append(cur.val)
            cur = cur.next
        nums.sort()
        dummy = cur = ListNode(0)
        for num in nums:
            cur.next = ListNode(num)
            cur = cur.next
        return dummy.next

💡 口诀：链表先拍平，Timsort 来帮忙；dummy 重建起，升序链表成。

面试进阶：要求 O(1) 额外空间时，改用自底向上归并排序（迭代，空间 O(1)）；或自顶向下归并（快慢指针找中点 + 递归合并，递归栈 O(log n)）。
