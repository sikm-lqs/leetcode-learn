2. 反转链表

给定单链表的头节点 head，反转链表并返回新的头节点。

1. 题目理解

给定单链表的头节点 head，将链表原地反转，并返回反转后链表的头节点（原链表的尾节点）。

关键：必须修改节点间的 next 指针关系，而不是仅仅交换节点里的值。

示例

输入：head = [1, 2, 3, 4, 5]
输出：[5, 4, 3, 2, 1]
1 → 2 → 3 → 4 → 5 → null

反转后变为：5 → 4 → 3 → 2 → 1 → null

2. 核心思路：三指针迭代

📌 三个变量

prev（已反转部分的头）、cur（当前处理节点）、nxt（暂存下一节点）。

🔁 每轮做四件事

存 nxt → 调 cur.next → 移 prev → 移 cur。

算法流程

  1. 初始化 prev = None，cur = head
  2. 当 cur 不为空时，循环：
  3.   nxt = cur.next   // 先保存，防止断链
  4.   cur.next = prev   // 反转指针
  5.   prev = cur      // prev 前进
  6.   cur = nxt      // cur 前进
  7. 循环结束时 cur = None，返回 prev
核心洞察：关键是「先存后改」——必须先用 nxt 保存 cur.next，再修改 cur.next，否则一旦改了指针就找不到后续节点了。

4. 详细过程模拟

以 head = [1, 2, 3, 4, 5] 为例，完整模拟。

初始：prev = null, cur = 1

cur1 → 2 → 3 → 4 → 5

第 1 轮：处理节点 1

nxt = 2 → 1.next = null（指向 prev）→ prev = 1 → cur = 2

prev1 → cur2 → 3 → 4 → 5

第 2 轮：处理节点 2

nxt = 3 → 2.next = 1 → prev = 2 → cur = 3

1 ← prev2 → cur3 → 4 → 5
以此类推，每轮把一个节点的 next 指向前一个节点。

结束：cur = null，返回 prev = 5

1 ← 2 ← 3 ← 4 ← head5
✅ 反转完成：5 → 4 → 3 → 2 → 1 → null

5. 代码逐段解释

完整代码

from typing import List

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reverseList(self, head: ListNode) -> ListNode:
        prev, cur = None, head
        while cur:
            nxt = cur.next
            cur.next = prev
            prev = cur
            cur = nxt
        return prev

逐段说明

第 1 步：初始化双指针

prev, cur = None, head

prev 指向「已反转部分」的头部，初始为 None；cur 指向当前待处理节点。

第 2 步：保存下一个节点

nxt = cur.next

因为下一步要修改 cur.next，必须先把原 cur.next 存起来，否则后续节点会「丢失」。

第 3 步：反转指针

cur.next = prev

把当前节点的 next 指向已反转部分的头，完成「掉头」。

第 4 步：两个指针前进

prev = cur
cur = nxt

prev 接上当前节点，cur 跳到之前保存的 nxt，准备处理下一个。

循环结束时 cur 为 None，prev 恰好停在原链表的尾节点（新的头）。

6. 复杂度分析

维度值说明
时间复杂度O(n)每个节点访问一次。
空间复杂度O(1)只用三个指针变量，原地反转。

7. 常见易错点

错误一：忘记先保存 next

# 错误：先改指针 → 后续节点丢失
cur.next = prev
nxt = cur.next   # ❌ 此时 cur.next 已经是 prev 了！

必须先 nxt = cur.next，再 cur.next = prev。

错误二：返回错指针

return head   # ❌ head 现在是尾节点，next 已是 None
return cur     # ❌ cur 已经是 None
return prev    # ✅ prev 停在新头部

边界情况

输入说明
head = []cur = None 直接跳过循环，返回 prev = None
head = [1]一轮后 1.next = None，返回节点 1

8. 总结

反转链表 精髓：

  • 三指针 prev / cur / nxt 协作
  • 口诀：存 → 改 → 移 → 移
  • 「先存后改」防止断链
  • 空间 O(1)，原地完成
class Solution:
    def reverseList(self, head):
        prev, cur = None, head
        while cur:
            nxt = cur.next
            cur.next = prev
            prev, cur = cur, nxt
        return prev

💡 口诀：存下一、指向前，prev cur 各向前；cur 空时 prev 头。
