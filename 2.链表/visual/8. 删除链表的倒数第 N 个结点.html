8. 删除链表的倒数第 N 个结点

给定链表头节点 head，删除倒数第 n 个结点并返回头节点。

1. 题目理解

给定单链表的头节点 head 和一个整数 n，删除链表的倒数第 n 个结点，并返回删除后的链表头节点。

关键：要求一趟扫描完成（经典约束）。难点不在「删除」本身，而在「只走一遍就找到那个节点的前驱」。

示例

输入：head = [1, 2, 3, 4, 5], n = 2
输出：[1, 2, 3, 5]   # 删除倒数第 2 个，即值 4
1 → 2 → 3 → 4 → 5 → null

绿色高亮节点即「被删除」的节点（倒数第 2 个）。

2. 核心思路：双指针 + 哑节点

🛡 哑节点 dummy

在 head 前加一个 dummy 节点。dummy.next = head。这样删除头节点时无需特判，最终统一返回 dummy.next。

🏃 双指针 fast / slow

都从 dummy 出发。fast 先走 n + 1 步，再两者同步前进。fast 到 null 时，slow 恰在被删节点的前驱。

算法流程

  1. 建立 dummy = ListNode(0, head)，slow = fast = dummy
  2. fast 先前进 n + 1 步
  3. 当 fast 不为 null 时，slow 与 fast 同步各前进一步
  4. 循环结束时，slow 位于被删节点的前驱
  5. 执行 slow.next = slow.next.next 跳过被删节点
  6. 返回 dummy.next
核心洞察：「fast 先走 n+1 步」是关键——这样 slow 与 fast 之间间隔 n+1 个位置，等 fast 走到链尾 null 时，slow 刚好停在倒数第 n 个节点的前一个，便于直接删除。

5. 详细过程模拟

以 head = [1, 2, 3, 4, 5]，n = 2 为例，复现三个关键画面。

画面一：fast 先走 n + 1 = 3 步

fast 从 dummy 出发前进 3 步，到达节点 3；slow 仍在 dummy。两者间隔 3 个位置。

slowdummy → 1 → 2 → fast3 → 4 → 5 → null

画面二：同步前进至 slow 在前驱位置

slow、fast 同步前进，直到 fast = null。此时 slow 恰好停在被删节点(4)的前一个节点(3)。

dummy → 1 → 2 → slow3 → 4 → 5 → fast=null

画面三：删除跳过节点 4

执行 slow.next = slow.next.next，把节点 4 从链表中断开。

dummy → 1 → 2 → slow3 → 4 ✗ 5 → null
✅ 返回 dummy.next = [1, 2, 3, 5]

6. 代码逐段解释

完整代码

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def removeNthFromEnd(self, head: ListNode, n: int) -> ListNode:
        dummy = ListNode(0, head)
        slow = fast = dummy
        for _ in range(n + 1):
            fast = fast.next
        while fast:
            slow = slow.next
            fast = fast.next
        slow.next = slow.next.next
        return dummy.next

逐段说明

第 1 步：建立哑节点

dummy = ListNode(0, head)
slow = fast = dummy

dummy 指向 head，slow、fast 都从 dummy 出发。哑节点保证删除头节点时也能走「找前驱 → 改 next」的统一流程。

第 2 步：fast 先走 n + 1 步

for _ in range(n + 1):
    fast = fast.next

让 fast 与 slow 拉开 n + 1 个位置的间隔。多走那 1 步是为了让 slow 最终停在被删节点的前驱，而不是被删节点本身。

第 3 步：同步前进

while fast:
    slow = slow.next
    fast = fast.next

两者同步前进，直到 fast 走到 null。此时 slow 恰好位于倒数第 n 个节点的前一个节点。

第 4 步：删除并返回

slow.next = slow.next.next
return dummy.next

让 slow.next 跳过被删节点，完成删除。最后返回 dummy.next（若删的是头节点，新头也正确）。

返回 dummy.next 而不是 head——当头节点本身被删除时，head 已不在链表中。

7. 复杂度分析

维度值说明
时间复杂度O(n)fast 先走 n+1 步、再与 slow 同步走到末尾，整体每个节点最多访问一次。
空间复杂度O(1)只用 dummy / slow / fast 三个指针，原地完成。

8. 常见易错点

错误一：忘记加哑节点

# 错误：直接 slow = fast = head
# 当要删的就是头节点（如 head=[1], n=1）时，
# slow 停在被删节点本身，没有前驱可改 next！

必须加 dummy，让 slow 永远能停在一个「前驱」位置上（哪怕前驱是 dummy）。

错误二：fast 先走的是 n 步而不是 n+1 步

for _ in range(n):      # ❌ 少走 1 步
    fast = fast.next
# 结果 slow 停在被删节点本身，无法执行 slow.next = slow.next.next

差 1 步：n+1 步让 slow 落在前驱；n 步会让 slow 落在被删节点。

错误三：返回 head 而非 dummy.next

return head         # ❌ 删头节点时 head 已不在链表中
return dummy.next   # ✅ 统一处理，删头也正确

边界情况

输入说明
head = [1], n = 1删唯一节点。dummy 救场：slow=dummy，slow.next=None，返回 None（即 []）。
head = [1,2], n = 2删头节点。fast 先走 3 步到 null，循环不执行，slow=dummy，slow.next=2，返回节点 2。

9. 总结

删除倒数第 N 个结点 精髓：

  • 双指针 + 哑节点，一趟扫描
  • 口诀：建哑点 → fast 先 n+1 → 同步走 → 改 next
  • 哑节点消除「删头」特例
  • fast 多走 1 步，让 slow 停在前驱
class Solution:
    def removeNthFromEnd(self, head, n):
        dummy = ListNode(0, head)
        slow = fast = dummy
        for _ in range(n + 1):
            fast = fast.next
        while fast:
            slow, fast = slow.next, fast.next
        slow.next = slow.next.next
        return dummy.next

💡 口诀：哑点统一删头事，快走 n+1 慢同步；快到 null 时慢在前，改 next 即得新链。
