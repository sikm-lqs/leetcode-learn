10. 随机链表的复制

链表每个节点除 next 外还有 random 指针（可指向任意节点或 null），构造该链表的深拷贝。

📋 目录

1. 题目理解 2. 核心思路：哈希表 + 两次遍历 3. 交互可视化演示 4. 详细过程模拟 5. 代码逐段解释 6. 复杂度分析 7. 常见易错点 8. 总结

1. 题目理解

给定一个长度为 n 的链表，每个节点除 val、next 外，还包含一个 random 指针，可以指向链表中的任意节点（包括自己）或 null。请构造该链表的深拷贝，返回新链表的头节点。

关键：深拷贝意味着要「全新创建」所有节点，新链表的 next 与 random 拓扑结构和原链表完全一致，但不能与原链表共享任何节点对象。

节点定义

class Node:
    def __init__(self, x: int, next: 'Node' = None, random: 'Node' = None):
        self.val = int(x)
        self.next = next
        self.random = random

示例（LeetCode 官方）

输入：head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
输出：[[7,null],[13,0],[11,4],[10,2],[1,0]]   # 结构完全一致的新链表

原链表 next 顺序与 random 关系如下：

idx 07 rand→null → idx 113 rand→7 → idx 211 rand→1 → idx 310 rand→11 → idx 41 rand→7 → null

下标 [i, j] 表示：val = i，random 指向下标 j 的节点（null 表示不指向）。

2. 核心思路：哈希表 + 两次遍历

🗺️ 一张哈希表

old_to_new：原节点 → 新节点。让任意原节点能在 O(1) 找到对应副本。

🔁 两遍遍历

第一遍只复制值建映射；第二遍只接指针（next / random）。职责分离。

算法流程

  1. 特判 head 为空，直接返回 None
  2. 第一遍：cur = head，沿 next 走，每访问一个原节点就 new Node(cur.val)，存入 old_to_new[cur]
  3. 第二遍：cur = head 再走一遍，对每个原节点查两次映射：
  4.   old_to_new[cur].next = old_to_new.get(cur.next)   // 新节点 next
  5.   old_to_new[cur].random = old_to_new.get(cur.random) // 新节点 random
  6. 返回 old_to_new[head]，即新链表头节点
核心洞察：哈希表让第二遍遍历能在 O(1) 内把 cur.random（一个原节点）「翻译」成对应的新节点；把「复制值」与「接指针」两件事分离到不同循环里，避免指针混乱。
old_to_new.get(cur.random)  ⇒  「原 random 节点」对应的「新 random 节点」

4. 详细过程模拟

以官方示例 [[7,null],[13,0],[11,4],[10,2],[1,0]] 为例，重点关注 random 是如何通过 map.get(cur.random) 间接获得的。

第一遍：复制所有节点，建立映射

沿 next 走一遍，每访问原节点就 new Node(cur.val)，此时新节点的 next / random 都还是 None。

原7 → 原13 → 原11 → 原10 → 原1
新7' × 新13' × 新11' × 新10' × 新1'
{ 7→7', 13→13', 11→11', 10→10', 1→1' }
× 表示新节点的 next / random 尚未连接。第一遍只负责「复制值 + 建映射」。

第二遍：按映射接 next（map.get(cur.next)）

新7' → 新13' → 新11' → 新10' → 新1'

第二遍：按映射接 random（map.get(cur.random)）

新7' rand→null → 新13' rand→7' → 新11' rand→1' → 新10' rand→11' → 新1' rand→7'
random 的关键：例如原节点 13.random 指向原节点 7，通过 old_to_new.get(原7) 得到 新节点 7'，赋给 13'.random。整条 random 拓扑与新链表自洽，不会「穿回」原链表。
✅ 完成：返回 old_to_new[head] = 7'，深拷贝成功。

5. 代码逐段解释

完整代码

class Node:
    def __init__(self, x: int, next: 'Node' = None, random: 'Node' = None):
        self.val = int(x)
        self.next = next
        self.random = random

class Solution:
    def copyRandomList(self, head: 'Node') -> 'Node':
        if not head:
            return None
        old_to_new = {}
        cur = head
        while cur:
            old_to_new[cur] = Node(cur.val)
            cur = cur.next
        cur = head
        while cur:
            old_to_new[cur].next = old_to_new.get(cur.next)
            old_to_new[cur].random = old_to_new.get(cur.random)
            cur = cur.next
        return old_to_new[head]

逐段说明

第 1 步：特判空链表

if not head:
    return None

空链表的深拷贝就是 None，直接返回，避免后续 old_to_new[head] 取不到值。

第 2 步：第一遍遍历 —— 复制值、建映射

old_to_new = {}
cur = head
while cur:
    old_to_new[cur] = Node(cur.val)   # 只复制 val，next/random 暂为 None
    cur = cur.next

这一遍不碰任何指针，只关心「值」和「映射」。结束后每个原节点都对应一个独立的新节点。

第 3 步：第二遍遍历 —— 接 next 与 random

cur = head
while cur:
    old_to_new[cur].next = old_to_new.get(cur.next)
    old_to_new[cur].random = old_to_new.get(cur.random)
    cur = cur.next

对每个原节点 cur，把它的「新副本」的 next/random 指向「cur.next/cur.random 的新副本」。用 .get(...) 是因为 cur.next、cur.random 可能为 None，get 安全地返回 None。

第 4 步：返回新链表头

return old_to_new[head]

头节点在第一遍就已存入映射，直接取出即可。

old_to_new.get(cur.random) 这一行是整道题的灵魂：它把「指向原节点的 random 指针」翻译成「指向新节点的 random 指针」，无需关心目标节点在链表中的位置。

6. 复杂度分析

维度值说明
时间复杂度O(n)两遍遍历，每遍各访问每个节点一次，共 2n 次。
空间复杂度O(n)哈希表存 n 个映射；新链表本身不计入辅助空间。
进阶：若要求 O(1) 空间，可采用「原地插入 + 拆分」法：把每个新节点插到原节点之后，利用位置关系推导 random，最后拆分两条链表。但可读性不如哈希表法。

7. 常见易错点

错误一：直接让新节点的 random 指向原节点

# 错误：new.random = cur.random 指向的是「原节点」而非副本！
old_to_new[cur].random = cur.random   # ❌ 穿回了原链表

# 正确：必须经过哈希表「翻译」一次
old_to_new[cur].random = old_to_new.get(cur.random)   # ✅

这是最隐蔽的 bug：表面上结构「连起来了」，但新链表的 random 指针全部指向原节点，破坏了深拷贝语义。

错误二：用 [] 取值导致 KeyError

old_to_new[cur].next = old_to_new[cur.next]     # ❌ cur.next 为 None 时 KeyError
old_to_new[cur].next = old_to_new.get(cur.next) # ✅ None 时安全返回 None

链表末尾的 next 必为 None，random 也常为 None，用 .get() 而非 []。

错误三：只遍历一遍就想同时建映射 + 接指针

# 错误：random 可能指向「还未创建」的节点
while cur:
    new = Node(cur.val)
    old_to_new[cur] = new
    new.next = old_to_new.get(cur.next)       # ❌ 下一节点此刻还没创建
    new.random = old_to_new.get(cur.random)   # ❌ 目标节点可能尚未创建
    cur = cur.next

random 可指向任意位置（前或后），单遍无法保证目标节点已存在。两遍遍历正是为了先把所有节点都创建出来。

边界情况

输入说明
head = []特判直接返回 None
head = [[1,null]]单节点，next/random 均为 None，get 返回 None
random 指向自身如 [[1,0]]：old_to_new.get(cur) = 自身副本，正确

8. 总结

随机链表的复制 精髓：

  • 哈希表 old_to_new 把「找新节点」降到 O(1)
  • 两遍遍历：第一遍复制值建映射，第二遍接 next / random
  • random 必须经过 map.get(cur.random) 翻译，绝不直接复用原指针
  • 用 .get() 兼容 None，避免 KeyError
class Solution:
    def copyRandomList(self, head: 'Node') -> 'Node':
        if not head: return None
        m = {}
        cur = head
        while cur: m[cur] = Node(cur.val); cur = cur.next
        cur = head
        while cur:
            m[cur].next = m.get(cur.next)
            m[cur].random = m.get(cur.random)
            cur = cur.next
        return m[head]

💡 口诀：一遍建表存副本，二遍照表接两针；next random 都走 get，头节点出表即收工。
