1. 相交链表

给定两个单链表的头节点 headA 和 headB，找出并返回两个单链表相交的起始节点；不相交返回 null。

1. 题目理解

两个单链表在某些节点可能开始共享同一段后缀。相交的定义是：从某个节点开始，两个链表共用同一组节点对象（不是值相同，而是同一引用）。

关键：相交指的是节点引用相同，而不仅仅是值相等。相交点之后两个链表完全重合（共享同一组节点）。

示例

listA = [4, 1, 8, 4, 5]
listB = [5, 6, 1, 8, 4, 5]
相交于值为 8 的节点（A 下标 2，B 下标 3，是同一个节点）
返回：节点 8

链表 A

4 → 1 → 相交8 → 4 → 5 → null

链表 B

5 → 6 → 1 → 相交8 → 4 → 5 → null

绿色节点（8→4→5）是两个链表共享的同一组节点。

2. 核心思路：双指针切换链表

📌 两个指针

pa 从链表 A 出发，pb 从链表 B 出发，各自同步前进。

🔁 走到末尾就切换

pa 走到 A 末尾（null）就转向 B 的头；pb 走到 B 末尾（null）就转向 A 的头。

算法流程

  1. 初始化 pa = headA，pb = headB
  2. 当 pa != pb 时，循环：
  3.   pa = pa.next if pa else headB   // pa 走到末尾就切换到 B
  4.   pb = pb.next if pb else headA   // pb 走到末尾就切换到 A
  5. 循环结束时返回 pa（可能是相交节点，也可能是 null）

为什么一定能相遇？

设 A 独有部分长 a，B 独有部分长 b，共享部分长 c
pa 走 a + c + b 步  |  pb 走 b + c + a 步  →  路径等长，必然同时到达交点
核心洞察：「切换链表」巧妙对齐了两条链表的起点差异——A 比 B 短，pa 就先走完；切换到 B 后，正好对齐了 B 多出来的部分。两个指针走过的总路程相同（a+c+b = b+c+a），所以一定在交点同时相遇，无需预先计算长度。

5. 详细过程模拟

以 listA = [4,1,8,4,5]、listB = [5,6,1,8,4,5] 为例，模拟关键几步。

初始：pa 在 A 头，pb 在 B 头

链表 A  （a = 2：4→1）

pa4 → 1 → 8 → 4 → 5 → null

链表 B  （b = 3：5→6→1）

pb5 → 6 → 1 → 8 → 4 → 5 → null
A 比 B 短 1 个节点（a=2 < b=3）。直接同步走，pa 会先到末尾，二者无法对齐。

关键：pa 切换到链表 B 的头部

链表 A

4 → 1 → 8 → 4 → 5 → null

链表 B（pa 已切换过来）

pa5 → 6 → 1 → pb8 → 4 → 5 → null
pa 走完 A（a+c 步）后切换到 B 头部。此时 pa 已走 5 步，pb 已走 5 步——两者在路径上开始对齐。

相遇：pa、pb 同时指向节点 8

链表 A（pb 已切换过来）

4 → 1 → 相遇8 → 4 → 5 → null

链表 B（pa 切换后到达此处）

5 → 6 → 1 → 相遇8 → 4 → 5 → null
pa 走 a + c + b = 2 + 3 + 3 = 8 步  |  pb 走 b + c + a = 3 + 3 + 2 = 8 步
路径等长 → 两指针同时到达节点 8
✅ pa == pb 成立，返回节点 8（相交起始节点）。

6. 代码逐段解释

完整代码

class ListNode:
    def __init__(self, x):
        self.val = x
        self.next = None

class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> ListNode:
        pa, pb = headA, headB
        while pa != pb:
            pa = pa.next if pa else headB
            pb = pb.next if pb else headA
        return pa

逐段说明

第 1 步：初始化双指针

pa, pb = headA, headB

pa 从链表 A 的头出发，pb 从链表 B 的头出发。

第 2 步：循环条件

while pa != pb:

只要两个指针还没指向同一节点，就继续前进。若两链表不相交，二者最终会同时为 null（None）退出。

第 3 步：前进 + 切换链表

pa = pa.next if pa else headB
pb = pb.next if pb else headA

pa 不为空就继续在当前链表上前进；一旦走到末尾（None），就切换到另一条链表的头部继续。pb 同理。

切换链表后，两个指针各自走过的总路程就相等了（a+c+b = b+c+a），保证它们要么在交点相遇，要么同时为 null。

7. 复杂度分析

维度值说明
时间复杂度O(a+b)两指针最多各走 a+c+b / b+c+a 步，即 O(a+b) 级别。
空间复杂度O(1)只用两个指针变量 pa、pb，无额外空间。

8. 常见易错点

错误一：先计算长度差

# 常见思路：先遍历计算两链表长度差 d，长的先走 d 步
# 可行，但需要两次完整遍历 + 额外逻辑，不如双指针切换优雅

双指针切换法无需预先计算长度，代码更简洁，本质等价。

错误二：忘记切换或切换错了链表

pa = pa.next if pa else headA   # ❌ pa 应该切换到 headB，否则走不出 A
pa = pa.next if pa else headB   # ✅ 正确

pa 走完 A 必须切换到 B 的头，pb 走完 B 必须切换到 A 的头，方向不能搞反。

错误三：循环条件写成 while pa and pb

while pa and pb:    # ❌ 这样一旦其中一个为 null 就退出，永远遇不到
while pa != pb:      # ✅ 让它们在 null 时也能继续切换

边界情况

输入说明
两链表不相交pa 走 a+b 步到达 null，pb 走 b+a 步到达 null，同时为 null，pa == pb 成立，返回 None
两链表完全相同头部即交点，pa == pb 直接成立，返回头节点
其中一个为空设 A 为空：pa = headB，与 pb 同走 B；若 B 也走完无交点，同时为 null 返回 None

9. 总结

相交链表 精髓：

  • 双指针 pa / pb 同步前进
  • 口诀：走完自己 → 切换对方
  • 「切换」自动对齐起点差异，无需计算长度
  • 路径等长（a+c+b = b+c+a）保证必然相遇
  • 时间 O(a+b)，空间 O(1)
class Solution:
    def getIntersectionNode(self, headA, headB):
        pa, pb = headA, headB
        while pa != pb:
            pa = pa.next if pa else headB
            pb = pb.next if pb else headA
        return pa

💡 口诀：两指针同出发，各走各的；到头切到对面去，路径相等必相遇。
