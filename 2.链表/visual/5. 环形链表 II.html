5. 环形链表 II

给定链表头节点 head，返回链表开始入环的第一个节点；无环返回 null。

📋 目录

1. 题目理解

给定单链表的头节点 head，返回链表开始入环的第一个节点。如果链表无环，则返回 null。

这里 pos 仅用于标识入环位置（尾节点 next 指向的下标），不作为参数传入，需通过指针本身判断。

关键：不仅要判断「是否有环」，还要找到入环点本身。进阶要求：空间复杂度 O(1)。

示例

输入：head = [3, 2, 0, -4]，pos = 1
输出：返回节点 2（下标为 1 的节点）
解释：尾节点 -4 的 next 指回节点 2，形成环。
3 → 入环点2 → 0 → -4

链表结构：3 → 2 → 0 → -4 ↘（指回 2）

2. 核心思路：两阶段快慢指针

⚡ 阶段一：找相遇点

fast 每次走 2 步，slow 每次走 1 步；若链表有环，二者必然在环内相遇。

🎯 阶段二：找入环点

把一个指针 p 放回 head，slow 留在相遇点，二者同速前进，再次相遇即入环点。

为什么 a = c？

设：头到入环距离 a，入环到相遇距离 b，相遇再回到入环距离 c。环长 = b + c。

fast 走的 = 2 × slow 走的
2(a + b) = a + b + k·(b + c)
推出：a + b = k·(b + c)  →  a = (k−1)(b + c) + c
k = 1 时：a = c ✅
核心洞察：用 a = c 把「找入环点」转化为「第二次相遇」——无需记录走过的节点，只要让两个指针一个从头、一个从相遇点同速走，第一次相遇处就是答案。

4. 详细过程模拟

以 head = [3, 2, 0, -4]，pos = 1 为例。

阶段一 · 第一次相遇：slow 与 fast 在节点 -4 相遇

3 → 入环点2 → 0 → slow/fast-4

fast 走过的距离是 slow 的两倍：fast = 3 → 0 → 2 → -4，slow = 3 → 2 → 0 → -4。

此时 a = 1（3→2），b = 3（2→0→-4→相遇前走过），环内关系满足
2(a + b) = a + b + (b + c)  →  a = c

阶段二 · 第二次相遇于入环点：p 从 head 出发，slow 留在相遇点

3 → p / slow2 → 0 → -4
✅ p 走 1 步到节点 2，slow 同时走 1 步也到节点 2（因为 a = c），第二次相遇处即入环点，返回节点 2（下标 1）。

5. 代码逐段解释

完整代码

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def detectCycle(self, head: ListNode) -> ListNode:
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:
                p = head
                while p is not slow:
                    p = p.next
                    slow = slow.next
                return p
        return None

逐段说明

第 1 步：初始化快慢指针

slow = fast = head

两者同时从头节点出发。fast 走两步、slow 走一步。

第 2 步：阶段一循环条件

while fast and fast.next:

只要 fast 和 fast.next 都不为空就继续。这是无环时的退出关键：若链表无环，fast 必然先到 None，循环自然结束。

第 3 步：阶段一移动与相遇判断

slow = slow.next
fast = fast.next.next
if slow is fast:   # 第一次相遇，进入阶段二

若两者指向同一节点，说明有环，相遇点已找到。

第 4 步：阶段二找入环点

p = head
while p is not slow:
    p = p.next
    slow = slow.next
return p

新指针 p 回到 head，与 slow 同速前进。由 a = c，二者必然在入环点相遇，返回该节点。

循环外层的 return None 处理无环情况——若 fast 走到 None，说明无环，直接返回 None。

6. 复杂度分析

维度值说明
时间复杂度O(n)阶段一最多走 O(n) 步相遇；阶段二 a + c ≤ n。总线性。
空间复杂度O(1)只用 slow、fast、p 三个指针，常数空间。

7. 常见易错点

错误一：无环时崩在 fast.next

# 错误：只判 fast，没判 fast.next
while fast:                # ❌ fast.next 可能是 None
    fast = fast.next.next  # ❌ 对 None 取 .next 报错

必须 while fast and fast.next，先判 fast 再判 fast.next，短路求值保证安全。

错误二：忘了阶段二

if slow is fast:
    return slow   # ❌ 这是相遇点，不是入环点！

阶段一只回答了「有没有环」，入环点必须靠阶段二的第二次相遇确定。

错误三：用 == 而非 is 比较节点

if slow == fast:        # ❌ 依赖 __eq__，可能比较值
if slow is fast:        # ✅ 比较对象身份，就是同一节点

边界情况

输入说明
head = []fast 为 None，循环不进入，返回 None
head = [1]，pos = -1fast.next 为 None，循环不进入，返回 None
head = [1, 2]，pos = 01→2→1，slow/fast 在 1 相遇；阶段二 p=head=1 直接等于 slow，返回 1

8. 总结

环形链表 II 精髓：

  • 两阶段快慢指针：相遇点 → 入环点
  • 核心等式：a = c，把找入环点转化为第二次相遇
  • 循环条件 fast and fast.next 同时处理无环返回
  • 空间 O(1)，无需哈希集合
class Solution:
    def detectCycle(self, head):
        slow = fast = head
        while fast and fast.next:
            slow, fast = slow.next, fast.next.next
            if slow is fast:
                p = head
                while p is not slow:
                    p, slow = p.next, slow.next
                return p
        return None

💡 口诀：快慢找相遇，回头再同走；a 等于 c 时，二次相遇即入环。
