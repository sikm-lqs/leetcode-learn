12. LRU 缓存

设计 LRU（最近最少使用）缓存。get(key) 存在则返回值并标记为最近使用，否则 -1；put(key,value) 不存在则插入，超过容量时淘汰最久未使用。

1. 题目理解

设计并实现一个 LRU（Least Recently Used）缓存 数据结构，需要支持两种操作：

  • get(key)：若关键字存在于缓存中，返回其对应的值，并把它标记为最近使用；否则返回 -1。
  • put(key, value)：若关键字已存在，则变更其值并标记为最近使用；若不存在，则插入该组关键字-值。当缓存容量达到上限时，淘汰最久未使用的关键字后再插入。
关键：两种操作都要求 O(1) 平均时间复杂度完成。

函数签名与示例

class LRUCache:
    def __init__(self, capacity: int): ...
    def get(self, key: int) -> int: ...
    def put(self, key: int, value: int) -> None: ...

# 输入
["LRUCache", "put", "put", "get", "put", "get", "get"]
[[2],        [1,1],  [2,2],  [1],    [3,3],  [2],    [1]]
# 输出
[null,        null,   null,   1,      null,   -1,     -1]

容量为 2：put(1,1) → put(2,2) → get(1)=1 → put(3,3) 淘汰 2 → get(2)=-1 → get(1)=1。

2. 核心思路：哈希表 + 双向链表

🗂️ 哈希表 map

key → 链表节点。O(1) 判断 key 是否存在并拿到节点指针。

🔗 双向链表

维护访问顺序。head 一端是「最近用」，tail 一端是「最久未用」。

两个 O(1) 链表操作

操作作用
_remove(node)把节点从链表中摘下（改两个方向的指针）
_add_to_head(node)把节点插到 head 之后，标记为最新使用

算法流程

  1. get(key)：map 中无 → 返回 -1；有 → _remove + _add_to_head，返回值。
  2. put(key, value)：
  3.   key 已存在 → 更新 value，_remove + _add_to_head。
  4.   key 不存在 → 新建节点，map[key]=node，_add_to_head。
  5.   若超容量 → old = tail.prev，_remove(old)，del map[old.key]。
核心洞察：哈希表 + 双向链表组合，_remove 与 _add_to_head 均 O(1)；访问与插入统一为「移到头部」，淘汰即「删尾」。双向链表能在 O(1) 内摘下任意节点（因为节点自带 prev 指针）。

为什么需要双向链表？

删除尾节点时要访问它的前驱。单链表找前驱需 O(n)，双向链表直接 node.prev 即 O(1)。同时引入 head / tail 两个哨兵节点，永远不为空，省去处理空链表与边界的大量判空逻辑。

head ⇄ 最近用k1=v1 ⇄ k2=v2 ⇄ 最久未用k3=v3 ⇄ tail

4. 详细过程模拟

以 capacity = 2 为例，重点看两个关键画面：get 命中移到头部 与 put 超容量淘汰尾部。

画面一：get(1) 命中 → 移到头部

操作前链表：head ⇄ [2=2] ⇄ [1=1] ⇄ tail（1 在尾部，最久未用）。get(1) 命中后：_remove(node1) 把 1 摘下，再 _add_to_head(node1) 把 1 插到 head 之后。

_remove(node1)：node1.prev.next = node1.next（[2].next → tail）；node1.next.prev = node1.prev（tail.prev → [2]）。

head ⇄ cur2=2 ⇄ 摘下1=1 ⇄ tail

_add_to_head(node1)：node1.next = head.next（→ [2]）；node1.prev = head；head.next.prev = node1（[2].prev → [1]）；head.next = node1。

head ⇄ 最新1=1 ⇄ 2=2 ⇄ tail
✅ get(1) 返回 1，链表变为 head ⇄ [1=1] ⇄ [2=2] ⇄ tail。

画面二：put(3,3) 容量满 → 淘汰尾部 + 插入头部

当前链表 head ⇄ [1=1] ⇄ [3=3] ⇄ tail (假设前一步是 put(3,3) 已淘汰 2)。这里演示更典型的「put(3,3) 触发淘汰 2」的瞬间：先 old = tail.prev（节点 [2=2]），_remove(old) 删尾，del map[2]，再 _add_to_head(node3)。

淘汰 old = [2=2]：old.prev.next = old.next（[1].next → tail）；old.next.prev = old.prev（tail.prev → [1]）。同步 del map[2]。

head ⇄ 1=1 ⇄ 淘汰2=2 ⇄ tail

插入 [3=3]：新建节点，map[3]=node3，_add_to_head 放到 head 之后。

head ⇄ 最新3=3 ⇄ 1=1 ⇄ tail
⚠️ 容量回到 2，节点 2 已从链表与 map 中彻底移除。

5. 代码逐段解释

完整代码

class Node:
    def __init__(self, key=0, value=0):
        self.key = key
        self.value = value
        self.prev = None
        self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.map = {}
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def get(self, key: int) -> int:
        if key not in self.map:
            return -1
        node = self.map[key]
        self._remove(node)
        self._add_to_head(node)
        return node.value

    def put(self, key: int, value: int) -> None:
        if key in self.map:
            node = self.map[key]
            node.value = value
            self._remove(node)
            self._add_to_head(node)
        else:
            node = Node(key, value)
            self.map[key] = node
            self._add_to_head(node)
            if len(self.map) > self.capacity:
                old = self.tail.prev
                self._remove(old)
                del self.map[old.key]

    def _remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _add_to_head(self, node):
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node

逐段说明

第 1 段：Node 节点定义

class Node:
    def __init__(self, key=0, value=0):
        self.key = key
        self.value = value
        self.prev = None
        self.next = None

每个节点保存 key、value 与前后指针。存 key 是为了淘汰时反向从 map 删除（del map[old.key]）。

第 2 段：初始化（哨兵）

self.head = Node()
self.tail = Node()
self.head.next = self.tail
self.tail.prev = self.head

head、tail 是空壳哨兵，互相首尾相连形成空链表。之后所有插入/删除都在 head 与 tail 之间进行，永远不必判空链表。

第 3 段：_remove（摘下节点）

node.prev.next = node.next   # 前驱的 next 跳过我
node.next.prev = node.prev   # 后继的 prev 跳过我

两条赋值即可把 node 从链表中移除，O(1)。注意：没有清 node 自身的 prev/next，因为它马上要被 _add_to_head 重新接线。

第 4 段：_add_to_head（插到头部）

node.next = self.head.next      # 新节点接原首节点
node.prev = self.head          # 新节点接 head
self.head.next.prev = node     # 原首节点回接新节点
self.head.next = node          # head 接新节点

四步把 node 插到 head 之后。顺序很关键：先改「新节点两侧」、再改「两侧回指」，避免引用丢失。

第 5 段：put 超容量淘汰

if len(self.map) > self.capacity:
    old = self.tail.prev
    self._remove(old)
    del self.map[old.key]

tail.prev 就是最久未用的节点。摘链后必须同步删 map，否则 map 残留指向已失效节点的引用。

get 与 put 命中/更新分支都走「_remove + _add_to_head」两步，逻辑统一。

6. 复杂度分析

维度值说明
get 时间O(1)哈希表查找 + 两次 O(1) 链表操作。
put 时间O(1)同上；淘汰分支也只删一个尾节点。
空间复杂度O(capacity)最多存 capacity 个节点（map + 链表同规模）。

7. 常见易错点

错误一：删尾节点后忘记同步删 map

if len(self.map) > self.capacity:
    old = self.tail.prev
    self._remove(old)
    # ❌ 缺 del self.map[old.key]

此时链表已无 old，但 map[old.key] 仍指向它。后续 get(old.key) 会命中 map 却拿到游离节点，逻辑彻底错乱。必须 del self.map[old.key]。

错误二：双向链表只改了一个方向

def _remove(self, node):
    node.prev.next = node.next   # ✅ 前驱跳过
    # ❌ 忘了 node.next.prev = node.prev

双向链表的精髓是两根指针都得改。漏掉 node.next.prev 会留下「回指已删节点」的野指针，遍历时进入死循环或报错。

错误三：不引入哨兵，边界判空爆炸

# ❌ 没有 head/tail 哨兵，每次都要判空
if self.first is None:
    self.first = self.last = node
elif node is self.last:
    ...   # 各种特殊分支

用 head / tail 哨兵节点，链表永远非空，_remove / _add_to_head 逻辑对所有情况一致，无需任何判空。

边界情况

输入说明
capacity = 0题目通常保证 ≥1；若需支持 0，应在 put 入口直接 return。
put 已存在的 key不新增节点，只更新 value 并移到头部，不触发容量检查。
get 未命中直接返回 -1，链表与 map 不动。

8. 总结

LRU 缓存 精髓：

  • 哈希表 O(1) 查找 + 双向链表 O(1) 调序
  • 访问/插入统一为「移到头部」，淘汰即「删尾」
  • head/tail 哨兵节点 消除空链表边界
  • 删链节点必须同步 del map
class LRUCache:
    def get(self, key):
        if key not in self.map: return -1
        node = self.map[key]
        self._remove(node); self._add_to_head(node)
        return node.value

    def put(self, key, value):
        if key in self.map:
            node = self.map[key]; node.value = value
            self._remove(node); self._add_to_head(node)
        else:
            self.map[key] = self._add_to_head(Node(key, value))
            if len(self.map) > self.capacity:
                self._remove(self.tail.prev)  # 实际实现中需 del map

💡 口诀：哈希查、链表调，命中都往头上挪；超容就把尾巴削，del map 别漏掉。
