很好。数组之后学习链表是非常自然的，因为链表是面试中非常常见的数据结构。

你现在可以先把链表理解成一句话：

> 链表不是通过下标访问元素，而是通过“节点之间的指向关系”把数据串起来。

在 Python 刷题里，链表通常不是直接用 `list`，而是题目会给你一个 `ListNode` 类。

---

# 一、什么是链表？

数组是这样的：

```python
nums = [10, 20, 30, 40]
```

它在逻辑上可以通过下标访问：

```python
nums[0]
nums[1]
nums[2]
```

但是链表不是这样。

链表更像这样：

```text
10 -> 20 -> 30 -> 40 -> None
```

每一个元素叫一个 **节点 Node**。

每个节点一般包含两部分：

```text
值 val
指向下一个节点的指针 next
```

也就是：

```text
节点 = 数据 + 下一个节点的位置
```

---

# 二、Python 中链表节点怎么表示？

LeetCode 中常见定义是：

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val      # 当前节点的值
        self.next = next    # 指向下一个节点
```

比如一个链表：

```text
1 -> 2 -> 3 -> None
```

可以手动写成：

```python
node1 = ListNode(1)
node2 = ListNode(2)
node3 = ListNode(3)

node1.next = node2
node2.next = node3
node3.next = None
```

其中：

```python
head = node1
```

`head` 表示链表的头节点。

---

# 三、链表和数组的区别

| 对比项       | 数组 list  | 链表 linked list  |
| --------- | -------- | --------------- |
| 存储方式      | 连续存储     | 节点分散存储          |
| 访问元素      | 可以用下标    | 只能从头开始找         |
| 访问第 i 个元素 | O(1)     | O(n)            |
| 插入/删除节点   | 中间操作较慢   | 改指针即可           |
| 是否有下标     | 有        | 没有              |
| 常见技巧      | 双指针、滑动窗口 | 虚拟头节点、快慢指针、反转指针 |

你需要特别记住：

> 链表不能像数组一样写 `head[0]`、`head[1]`。

链表只能通过：

```python
cur = head
cur = cur.next
```

一步一步往后走。

# 四、链表的基本遍历

## 1. 遍历整个链表

```python
cur = head

while cur:
    print(cur.val)
    cur = cur.next
```

这个模板非常重要。

意思是：

```text
cur 先指向头节点
只要 cur 不是 None，就访问当前节点
然后 cur 往后移动一步
```

例如：

```text
1 -> 2 -> 3 -> None
```

遍历过程是：

```text
cur = 1
cur = 2
cur = 3
cur = None，结束
```

---

## 2. 为什么判断条件是 `while cur`？

因为链表最后一个节点的 `next` 是 `None`：

```text
1 -> 2 -> 3 -> None
```

当 `cur` 变成 `None` 时，说明已经走到链表末尾了。

所以：

```python
while cur:
```

等价于：

```python
while cur is not None:
```

---

# 五、访问链表节点的值和下一个节点

假设：

```python
cur = head
```

那么：

```python
cur.val
```

表示当前节点的值。

```python
cur.next
```

表示当前节点的下一个节点。

例如：

```text
cur
 |
 v
1 -> 2 -> 3 -> None
```

那么：

```python
cur.val       # 1
cur.next.val  # 2
```

但是要注意：

如果 `cur.next` 是 `None`，那么不能写：

```python
cur.next.val
```

否则会报错。

所以写链表题时，经常要判断：

```python
if cur and cur.next:
```

或者：

```python
while cur and cur.next:
```

---

# 六、链表题最重要的思维：不要丢节点

链表题最容易犯的错误是：

> 改了 `next` 指针之后，把后面的节点弄丢了。

比如你有：

```text
1 -> 2 -> 3 -> None
```

如果你直接写：

```python
head.next = None
```

链表就变成：

```text
1 -> None
```

后面的 `2 -> 3` 就找不到了。

所以很多链表操作之前，要先保存下一个节点：

```python
nxt = cur.next
```

这个 `nxt` 很重要。

# 七、链表常见基础操作

---

## 1. 创建一个新节点

```python
node = ListNode(5)
```

表示创建一个值为 5 的节点。

---

## 2. 连接两个节点

```python
node1.next = node2
```

表示：

```text
node1 -> node2
```

---

## 3. 删除当前节点的下一个节点

假设链表是：

```text
1 -> 2 -> 3 -> None
```

`cur` 指向节点 `1`。

如果想删除节点 `2`，写：

```python
cur.next = cur.next.next
```

删除后：

```text
1 -> 3 -> None
```

这句非常常见：

```python
cur.next = cur.next.next
```

意思是：

> 让当前节点跳过下一个节点，直接指向下下个节点。

---

## 4. 插入一个新节点

假设：

```text
1 -> 3 -> None
```

想在 `1` 和 `3` 中间插入 `2`。

```python
node = ListNode(2)

node.next = cur.next
cur.next = node
```

顺序不能反。

正确顺序：

```python
node.next = cur.next
cur.next = node
```

插入后：

```text
1 -> 2 -> 3 -> None
```

如果你先写：

```python
cur.next = node
node.next = cur.next
```

就会出问题，因为 `cur.next` 已经变了。

---

# 八、链表题核心技巧一：虚拟头节点 dummy

链表题里最常见、最重要的技巧是：

> 使用 dummy 虚拟头节点。

---

## 1. 为什么需要 dummy？

比如删除链表中的某个节点。

如果删除的是中间节点，很简单：

```text
1 -> 2 -> 3
```

删除 `2`：

```python
cur.next = cur.next.next
```

但是如果要删除的是头节点：

```text
1 -> 2 -> 3
```

删除 `1` 就比较麻烦，因为 `head` 本身要改变。

所以我们加一个虚拟头节点：

```text
dummy -> 1 -> 2 -> 3 -> None
```

这样即使删除头节点，也可以统一处理。

---

## 2. dummy 模板

```python
dummy = ListNode(0)
dummy.next = head

cur = dummy

# 中间做操作

return dummy.next
```

你要记住：

> 最后通常返回 `dummy.next`，而不是 `head`。

因为 `head` 可能已经被删除或改变了。

---

# 九、链表题核心技巧二：快慢指针

快慢指针在链表中非常常见。

基本写法：

```python
slow = head
fast = head

while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
```

含义：

* `slow` 每次走一步
* `fast` 每次走两步

---

## 快慢指针常见用途

| 用途          | 思路                  |
| ----------- | ------------------- |
| 判断链表是否有环    | fast 如果追上 slow，说明有环 |
| 找链表中点       | fast 到结尾时，slow 在中间  |
| 删除倒数第 N 个节点 | fast 先走 N 步         |
| 判断回文链表      | 找中点 + 反转后半段         |

---

## 例子：找链表中点

```python
slow = head
fast = head

while fast and fast.next:
    slow = slow.next
    fast = fast.next.next

return slow
```

例如：

```text
1 -> 2 -> 3 -> 4 -> 5
```

最后 `slow` 指向 `3`。

如果是：

```text
1 -> 2 -> 3 -> 4
```

最后 `slow` 通常指向 `3`，也就是第二个中点。

---

# 十、链表题核心技巧三：反转链表

反转链表是链表题的核心基本功。

原链表：

```text
1 -> 2 -> 3 -> None
```

反转后：

```text
3 -> 2 -> 1 -> None
```

---

## 反转链表模板

```python
prev = None
cur = head

while cur:
    nxt = cur.next
    cur.next = prev
    prev = cur
    cur = nxt

return prev
```

这个模板必须背熟。

---

## 逐步解释

假设：

```text
1 -> 2 -> 3 -> None
```

初始：

```python
prev = None
cur = head
```

也就是：

```text
prev = None
cur = 1
```

每一轮做四件事：

```python
nxt = cur.next
```

先保存下一个节点。

```python
cur.next = prev
```

把当前节点反过来指向前一个节点。

```python
prev = cur
```

`prev` 往前走。

```python
cur = nxt
```

`cur` 往前走。

这四句顺序很重要：

```python
nxt = cur.next
cur.next = prev
prev = cur
cur = nxt
```

你可以把它理解成链表反转的“四步口诀”：

```text
先存后
再反指
前进 prev
前进 cur
```

---

# 十一、链表题核心技巧四：双指针找倒数第 N 个节点

比如题目：

> 删除链表倒数第 N 个节点。

常见做法：

```python
dummy = ListNode(0)
dummy.next = head

fast = dummy
slow = dummy

for _ in range(n):
    fast = fast.next

while fast.next:
    fast = fast.next
    slow = slow.next

slow.next = slow.next.next

return dummy.next
```

---

## 思路解释

假设链表：

```text
1 -> 2 -> 3 -> 4 -> 5
```

删除倒数第 2 个节点，也就是删除 `4`。

做法：

1. `fast` 先走 `n` 步；
2. 然后 `fast` 和 `slow` 一起走；
3. 当 `fast` 到最后一个节点时，`slow` 正好在要删除节点的前一个节点；
4. 执行：

```python
slow.next = slow.next.next
```

完成删除。

---

# 十二、链表题核心技巧五：合并两个有序链表

这是非常经典的链表题。

两个链表：

```text
1 -> 2 -> 4
1 -> 3 -> 4
```

合并后：

```text
1 -> 1 -> 2 -> 3 -> 4 -> 4
```

模板：

```python
dummy = ListNode(0)
cur = dummy

while list1 and list2:
    if list1.val <= list2.val:
        cur.next = list1
        list1 = list1.next
    else:
        cur.next = list2
        list2 = list2.next
    
    cur = cur.next

if list1:
    cur.next = list1
else:
    cur.next = list2

return dummy.next
```

这个题也体现了 dummy 的重要性。

# 十三、链表题常见模板总结

---

## 模板 1：遍历链表

```python
cur = head

while cur:
    # 处理 cur.val
    cur = cur.next
```

适合：

* 求链表长度
* 查找某个值
* 打印链表
* 统计节点

---

## 模板 2：dummy 虚拟头节点

```python
dummy = ListNode(0)

cur = dummy

# 修改链表结构

```

适合：

* 删除节点
* 合并链表
* 需要改变头节点的题

---

## 模板 3：反转链表

```python
prev = None
cur = head

while cur:
    nxt = cur.next
    cur.next = prev
    prev = cur
    cur = nxt

return prev
```

适合：

* 反转整个链表
* 反转部分链表
* 回文链表
* K 个一组翻转链表

---

## 模板 4：快慢指针

```python
slow = head
fast = head

while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
```

适合：

* 找中点
* 判断环
* 回文链表
* 链表重排

---

## 模板 5：删除节点

```python
cur.next = cur.next.next
```

适合：

* 删除当前节点后面的节点

注意：

```python
cur.next
```

必须存在，否则会报错。

---

## 模板 6：合并两个链表

```python
dummy = ListNode(0)
cur = dummy

while l1 and l2:
    if l1.val <= l2.val:
        cur.next = l1
        l1 = l1.next
    else:
        cur.next = l2
        l2 = l2.next
    cur = cur.next

cur.next = l1 if l1 else l2

return dummy.next
```

# 十五、链表题常见边界情况

链表题非常容易在边界情况出错。

写代码前一定要想这些情况。

---

## 1. 空链表

```text
None
```

对应代码：

```python
head = None
```

很多题开头要判断：

```python
if not head:
    return None
```

---

## 2. 只有一个节点

```text
1 -> None
```

比如反转链表时，返回它自己即可。

---

## 3. 两个节点

```text
1 -> 2 -> None
```

很多交换、删除、反转题容易在两个节点时出错。

---

## 4. 删除的是头节点

```text
1 -> 2 -> 3
```

删除 `1` 时，`head` 会变。

所以建议使用 dummy。

---

## 5. 删除的是尾节点

```text
1 -> 2 -> 3
```

删除 `3` 时，要确保：

```python
cur.next = None
```

---

## 6. 链表长度不够

比如删除倒数第 N 个节点时，如果 `n` 不合法，可能会报错。

LeetCode 通常保证输入合法，但自己写代码时要有这个意识。

# 十七、链表题最容易错的地方

---

## 1. 忘记保存下一个节点

错误示例：

```python
cur.next = prev
cur = cur.next
```

这里 `cur.next` 已经被改成 `prev` 了，所以 `cur` 会往回走，链表就乱了。

正确写法：

```python
nxt = cur.next
cur.next = prev
cur = nxt
```

---

## 2. 返回错了头节点

使用 dummy 时，最后应该返回：

```python
return dummy.next
```

不是：

```python
return head
```

因为 `head` 可能已经变了。

---

## 3. 没考虑空链表

错误示例：

```python
return head.val
```

如果 `head` 是 `None`，就会报错。

应该先判断：

```python
if not head:
    return None
```

---

## 4. 判断条件写错

比如：

```python
while fast.next:
```

如果 `fast` 本身是 `None`，就会报错。

更安全的写法是：

```python
while fast and fast.next:
```

---

## 5. 指针重连顺序错了

插入节点时，应该先让新节点指向后面：

```python
node.next = cur.next
cur.next = node
```

不要反过来。

# 十八、链表和数组做题思维的区别

数组题经常这样想：

```text
下标 i 在哪里？
nums[i] 是多少？
left/right 怎么移动？
```

链表题要这样想：

```text
当前节点是谁？
下一个节点是谁？
我要不要先保存 next？
改完指针后，链表还能不能继续往后走？
最后新的 head 是谁？
```

链表题不要只在脑子里想，最好在纸上画。

比如反转链表时画成：

```text
prev    cur    nxt
None    1  ->  2  ->  3
```

每改一次指针，就画一次。

# 二十二、链表题核心判断方法

看到题目时可以这样判断：

# 二十三、链表题的时间复杂度怎么分析？

大多数链表题时间复杂度都比较简单。

## 1. 遍历一次链表

```python
cur = head
while cur:
    cur = cur.next
```

如果链表有 `n` 个节点，那么时间复杂度是：

```text
O(n)
```

---

## 2. 反转链表

每个节点只处理一次，所以：

```text
时间复杂度：O(n)
空间复杂度：O(1)
```

---

## 3. 合并两个有序链表

如果两个链表长度分别是 `m` 和 `n`，每个节点最多处理一次：

```text
时间复杂度：O(m + n)
空间复杂度：O(1)
```

注意：这里没有新建所有节点，只是改变指针，所以额外空间是 `O(1)`。

---

## 4. 快慢指针

虽然有两个指针，但每个指针都是线性移动：

```text
时间复杂度：O(n)
空间复杂度：O(1)
```

不要看到两个指针就以为是 `O(n²)`。

# 二十四、链表题一定要多画图

链表题和数组题最大的不同是：

> 数组题可以靠下标想，链表题必须靠指针关系想。

你可以每道题都画这种图：

```text
dummy -> 1 -> 2 -> 3 -> None
cur
```

或者：

```text
prev    cur    nxt
None    1  ->  2  ->  3
```

然后问自己：

```text
1. 当前节点是谁？
2. 下一个节点是谁？
3. 我要不要先保存下一个节点？
4. 改完 next 之后，会不会丢掉后面的链表？
5. 最后返回谁？
```

这 5 个问题非常关键。

# 二十五、链表篇最重要的总结

你现在先不要贪多，只要记住下面这些。

## 链表基础

```text
节点 = val + next
head 是头节点
None 表示链表结束
链表不能随机访问，只能从头走
```

## 常用操作

```python
cur = cur.next              # 往后走
cur.next = cur.next.next    # 删除节点
node.next = cur.next        # 插入节点第一步
cur.next = node             # 插入节点第二步
```

## 三个核心技巧

```text
dummy 虚拟头节点
快慢指针
反转链表
```

## 最重要的模板

```python
prev = None
cur = head

while cur:
    nxt = cur.next
    cur.next = prev
    prev = cur
    cur = nxt

return prev
```

这个是链表入门必须掌握的模板。
