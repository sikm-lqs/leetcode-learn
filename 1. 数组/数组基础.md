# 一、Python 中数组是什么？

Python 没有像 C/C++ 那种原生数组，刷题时一般用：

```python
nums = [1, 2, 3, 4]
```

它叫 **列表 list**。

可以理解为：

> 一个可以存放多个元素的容器，并且元素有顺序、有下标、可以修改。

---

# 二、数组的基本访问

## 1. 通过下标访问元素

```python
nums = [10, 20, 30, 40]

print(nums[0])   # 10
print(nums[1])   # 20
print(nums[2])   # 30
```

注意：Python 下标从 **0** 开始。

|下标|元素|
|---|---|
|0|10|
|1|20|
|2|30|
|3|40|

---

## 2. 访问最后一个元素

```python
nums = [10, 20, 30, 40]

print(nums[-1])  # 40
print(nums[-2])  # 30
```

负数下标很常用：

|写法|含义|
|---|---|
|`nums[-1]`|最后一个元素|
|`nums[-2]`|倒数第二个元素|
|`nums[-3]`|倒数第三个元素|

---

## 3. 获取数组长度

```python
nums = [10, 20, 30, 40]

n = len(nums)
print(n)  # 4
```

刷题中经常写：

```python
n = len(nums)
```

这是非常常见的习惯。

---

# 三、数组的遍历方式

数组题最重要的基础就是遍历。

---

## 1. 只需要元素时

```python
nums = [10, 20, 30, 40]

for x in nums:
    print(x)
```

适合场景：

> 只关心元素值，不关心下标。

---

## 2. 需要下标时

```python
nums = [10, 20, 30, 40]

for i in range(len(nums)):
    print(i, nums[i])
```

输出：

```python
0 10
1 20
2 30
3 40
```

适合场景：

> 需要修改数组、比较相邻元素、使用双指针。

---

## 3. 同时需要下标和值时

```python
nums = [10, 20, 30, 40]

for i, x in enumerate(nums):
    print(i, x)
```

这是 Python 很常用的写法。

等价于：

```python
for i in range(len(nums)):
    x = nums[i]
```

刷题中推荐你多用：

```python
for i, x in enumerate(nums):
```

# 四、数组的常用操作

## 1. 添加元素

```python
nums = [1, 2, 3]

nums.append(4)

print(nums)  # [1, 2, 3, 4]
```

`append()` 是在末尾添加元素。

---

## 2. 删除最后一个元素

```python
nums = [1, 2, 3]

x = nums.pop()

print(x)     # 3
print(nums)  # [1, 2]
```

`pop()` 默认删除最后一个元素，并返回它。

这个在 **栈** 里面非常常用。

---

## 3. 删除指定位置元素

```python
nums = [1, 2, 3, 4]

nums.pop(1)

print(nums)  # [1, 3, 4]
```

`pop(1)` 删除下标为 1 的元素，也就是 `2`。

但注意：

> 在数组中间删除元素，通常比较慢，因为后面的元素都要往前移动。

---

## 4. 修改元素

```python
nums = [1, 2, 3]

nums[0] = 100

print(nums)  # [100, 2, 3]
```

---

## 5. 判断元素是否存在

```python
nums = [1, 2, 3, 4]

if 3 in nums:
    print("存在")
```

但是要注意：

```python
x in nums
```

对列表来说，时间复杂度是 **O(n)**。

因为它要一个一个找。

如果你要经常判断某个元素是否存在，通常用集合：

```python
s = set(nums)

if 3 in s:
    print("存在")
```

集合查找通常是 **O(1)**。

---

# 五、数组切片

切片是 Python 刷题里很常见的操作。

```python
nums = [0, 1, 2, 3, 4, 5]
```

## 1. 取一段

```python
print(nums[1:4])  # [1, 2, 3]
```

注意：

```python
nums[1:4]
```

表示从下标 `1` 开始，到下标 `4` 之前结束。

也就是：

> 左闭右开 `[1, 4)`

---

## 2. 从开头取到某个位置

```python
print(nums[:3])  # [0, 1, 2]
```

---

## 3. 从某个位置取到结尾

```python
print(nums[3:])  # [3, 4, 5]
```

---

## 4. 反转数组

```python
print(nums[::-1])  # [5, 4, 3, 2, 1, 0]
```

---

## 5. 注意切片会创建新数组

比如：

```python
a = nums[1:4]
```

这里的 `a` 是一个新的列表。

所以切片虽然方便，但会消耗额外空间。

在面试中，如果要求 **原地修改**，就不要随便用切片。

# 六、排序相关操作

## 1. 原地排序

```python
nums = [3, 1, 4, 2]

nums.sort()

print(nums)  # [1, 2, 3, 4]
```

`sort()` 会直接修改原数组。

---

## 2. 得到一个新的排序数组

```python
nums = [3, 1, 4, 2]

arr = sorted(nums)

print(arr)   # [1, 2, 3, 4]
print(nums)  # [3, 1, 4, 2]
```

区别：

|写法|是否修改原数组|
|---|---|
|`nums.sort()`|修改原数组|
|`sorted(nums)`|不修改原数组，返回新数组|

---

## 3. 降序排序

```python
nums = [3, 1, 4, 2]

nums.sort(reverse=True)

print(nums)  # [4, 3, 2, 1]
```

---

## 4. 按规则排序

例如二维数组：

```python
pairs = [[1, 3], [2, 2], [3, 1]]

pairs.sort(key=lambda x: x[1])

print(pairs)  # [[3, 1], [2, 2], [1, 3]]
```

意思是：

> 按每个小数组的第二个元素排序。

# 七、数组题中最常见的几个技巧

下面是你刷数组题最应该掌握的部分。

---

# 技巧一：哈希表

适合解决：

- 查找是否存在
    
- 统计出现次数
    
- 两数之和
    
- 去重
    
- 判断重复
    

---

## 例子：统计每个数字出现次数

```python
nums = [1, 2, 2, 3, 3, 3]

cnt = {}

for x in nums:
    cnt[x] = cnt.get(x, 0) + 1

print(cnt)
```

输出：

```python
{1: 1, 2: 2, 3: 3}
```

这句非常重要：

```python
cnt[x] = cnt.get(x, 0) + 1
```

意思是：

> 如果 `x` 已经在字典里，就在原来的次数上加 1；如果不在，就从 0 开始加 1。
> dict.get() 是 Python 字典的一个方法，用来获取某个 key 对应的 value，并且可以设置默认值。

---

## 例子：判断是否有重复元素

```python
nums = [1, 2, 3, 1]

seen = set()

for x in nums:
    if x in seen:
        print("有重复")
        break
    seen.add(x)
```

核心思想：

> 一边遍历，一边记录已经见过的元素。

---

# 技巧二：双指针

双指针是数组题超级高频技巧。

常见形式有两种。

---

## 1. 左右指针

适合：

- 有序数组
    
- 回文判断
    
- 两数之和变形
    
- 反转数组
    

```python
nums = [1, 2, 3, 4, 5]

left = 0
right = len(nums) - 1

while left < right:
    nums[left], nums[right] = nums[right], nums[left]
    left += 1
    right -= 1

print(nums)  # [5, 4, 3, 2, 1]
```

这句是 Python 交换两个元素的写法：

```python
nums[left], nums[right] = nums[right], nums[left]
```

非常常用。

---

## 2. 快慢指针

适合：

- 原地删除
    
- 去重
    
- 移动零
    
- 链表题
    

例如删除有序数组中的重复项：

```python
nums = [1, 1, 2, 2, 3]

slow = 0

for fast in range(1, len(nums)):
    if nums[fast] != nums[slow]:
        slow += 1
        nums[slow] = nums[fast]

print(slow + 1)       # 新长度
print(nums[:slow+1])  # [1, 2, 3]
```

理解：

- `fast` 负责往前扫描
    
- `slow` 负责记录新数组的末尾位置
    

---

# 技巧三：滑动窗口

滑动窗口本质上是双指针的一种。

适合：

- 连续子数组
    
- 连续子串
    
- 最长
    
- 最短
    
- 满足某个条件的区间
    

模板：

```python
left = 0

for right in range(len(nums)):
    # 把 nums[right] 加入窗口

    while 窗口不满足条件:
        # 移除 nums[left]
        left += 1

    # 更新答案
```

---

## 例子：长度最小的子数组

问题：

> 给一个正整数数组 nums 和 target，找出和至少为 target 的最短连续子数组长度。

```python
nums = [2, 3, 1, 2, 4, 3]
target = 7

left = 0
window_sum = 0
ans = float("inf")

for right in range(len(nums)):
    window_sum += nums[right]

    while window_sum >= target:
        ans = min(ans, right - left + 1)
        window_sum -= nums[left]
        left += 1

print(ans)  # 2，因为 [4, 3]
```

核心思想：

> 右指针扩大窗口，左指针缩小窗口。

---

# 技巧四：前缀和

前缀和适合解决：

- 子数组和
    
- 区间和
    
- 连续区间问题
    

---

## 例子：快速求区间和

```python
nums = [1, 2, 3, 4]

prefix = [0]

for x in nums:
    prefix.append(prefix[-1] + x)

print(prefix)  # [0, 1, 3, 6, 10]
```
prefix[i] = prefix[i-1] + nums[i-1]
`prefix[i]` 表示：

> 前 i 个元素的和。

如果要求 `nums[l]` 到 `nums[r]` 的和：

```python
range_sum = prefix[r + 1] - prefix[l]
```

例如：

```python
nums = [1, 2, 3, 4]
prefix = [0, 1, 3, 6, 10]

# 求 nums[1] 到 nums[3] 的和：2 + 3 + 4
print(prefix[4] - prefix[1])  # 9
```

---

# 技巧五：原地修改

很多数组题要求：

> 不使用额外数组，原地修改 nums。

常见题：

- 删除排序数组中的重复项
    
- 移动零
    
- 移除元素
    
- 合并两个有序数组
    

这种题常用：

```python
slow = 0

for fast in range(len(nums)):
    if 条件成立:
        nums[slow] = nums[fast]
        slow += 1
```

例如移动零：

```python
nums = [0, 1, 0, 3, 12]

slow = 0

for fast in range(len(nums)):
    if nums[fast] != 0:
        nums[slow] = nums[fast]
        slow += 1

while slow < len(nums):
    nums[slow] = 0
    slow += 1

print(nums)  # [1, 3, 12, 0, 0]
```

理解：

第一步：把所有非零数往前放。

第二步：剩下的位置全部填 0。

# 九、数组题常见边界情况

初学者最容易错在边界情况。

你写代码前要想这些：

## 1. 空数组

```python
nums = []
```

有些题要先判断：

```python
if not nums:
    return 0
```

---

## 2. 只有一个元素

```python
nums = [1]
```

很多双指针、滑动窗口题要注意。

---

## 3. 全部元素相同

```python
nums = [2, 2, 2, 2]
```

---

## 4. 有负数

```python
nums = [-1, -2, 3]
```

比如滑动窗口很多时候只适用于 **正数数组**。如果有负数，就可能不能直接用滑动窗口。

---

## 5. 已经有序 / 完全逆序

```python
nums = [1, 2, 3, 4]
nums = [4, 3, 2, 1]
```

排序、双指针题经常要考虑。

# 十一、你最应该先掌握的数组模板

## 模板 1：一次遍历

```python
ans = 0

for x in nums:
    # 根据 x 更新 ans
    pass

return ans
```

适合：

- 求最大值
    
- 求和
    
- 统计数量
    
- 找目标元素
    

---

## 模板 2：下标遍历

```python
for i in range(len(nums)):
    # 使用 nums[i]
    pass
```

适合：

- 需要下标
    
- 修改数组
    
- 比较相邻元素
    

---

## 模板 3：哈希表

```python
cnt = {}

for x in nums:
    cnt[x] = cnt.get(x, 0) + 1
```

适合：

- 统计频率
    
- 判断重复
    
- 查找匹配元素
    

---

## 模板 4：双指针

```python
left = 0
right = len(nums) - 1

while left < right:
    # 根据条件移动 left 或 right
    left += 1
    right -= 1
```

适合：

- 有序数组
    
- 回文
    
- 两数和
    
- 反转数组
    

---

## 模板 5：快慢指针

```python
slow = 0

for fast in range(len(nums)):
    if 条件成立:
        nums[slow] = nums[fast]
        slow += 1
```

适合：

- 原地删除
    
- 去重
    
- 移动零
    

---

## 模板 6：滑动窗口

```python
left = 0
window = 0

for right in range(len(nums)):
    window += nums[right]

    while 窗口不满足条件:
        window -= nums[left]
        left += 1

    # 更新答案
```

适合：

- 连续子数组
    
- 最长/最短区间
    

---

## 模板 7：前缀和

```python
prefix = [0]

for x in nums:
    prefix.append(prefix[-1] + x)

# nums[l:r+1] 的和
range_sum = prefix[r + 1] - prefix[l]
```

适合：

- 多次查询区间和
    
- 子数组和问题
