4. 三数之和

排序 + 双指针：从 O(n³) 暴力降到 O(n²)。

1. 题目理解

给定一个包含 n 个整数的数组 nums，判断是否存在三个元素 a, b, c，使得 a + b + c = 0。请找出所有不重复的三元组。

示例

输入：nums = [-1, 0, 1, 2, -1, -4]
输出：[[-1, -1, 2], [-1, 0, 1]]

输入：nums = [0, 1, 1]
输出：[]

输入：nums = [0, 0, 0]
输出：[[0, 0, 0]]
答案中不能包含重复的三元组——这是本题最容易漏掉的要求。

2. 核心思路：排序 + 双指针

  1. 排序：数组有序后，重复元素相邻，方便去重
  2. 固定一个数 nums[i]：问题降维成「在剩余区间找两数之和 = -nums[i]」
  3. 双指针收缩：left 指向 i+1，right 指向末尾；和小于目标则 left++，大于目标则 right--，等于则记录并双向收缩
  4. 三处去重：i 去重（相邻相同跳过）、left 去重、right 去重
为什么双指针可行？排序后区间单调，指针向内移动时「和」单调变化，可以在 O(n) 内扫完一个固定 i 的所有两数和。

5. 详细过程模拟

以 i = 0（nums[0] = -4）为例，双指针在 [-1, -1, 0, 1, 2] 中找两数和 = 4：

ileftright三数和操作
0 (-4)1 (-1)5 (2)-3total < 0，left++
0 (-4)2 (-1)5 (2)-3total < 0，left++
0 (-4)3 (0)5 (2)-2total < 0，left++
0 (-4)4 (1)5 (2)-1total < 0，left++ → left > right 结束

接下来 i = 1（nums[1] = -1）时，双指针会命中 [-1, -1, 2] 和 [-1, 0, 1] 两组答案。

注意 i = 2 时 nums[2] == nums[1] == -1，直接跳过——否则会与 i = 1 的结果重复。

6. 代码逐段解释

class Solution:
    def threeSum(self, nums):
        nums.sort()                       # 排序：去重与双指针的前提
        res = []
        n = len(nums)
        for i in range(n):
            if i > 0 and nums[i] == nums[i - 1]:
                continue                 # 去重①：固定数相同则跳过
            left, right = i + 1, n - 1
            while left < right:
                total = nums[i] + nums[left] + nums[right]
                if total == 0:
                    res.append([nums[i], nums[left], nums[right]])
                    while left < right and nums[left] == nums[left + 1]:
                        left += 1        # 去重②：跳过重复 left
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1       # 去重③：跳过重复 right
                    left += 1; right -= 1
                elif total < 0:
                    left += 1              # 和太小，右移左指针
                else:
                    right -= 1             # 和太大，左移右指针
        return res

逐段说明

  • i 去重：固定数相同只会产生重复组合，直接跳过
  • 命中后去重：找到一组后先把相邻重复值跳过，再收缩指针，避免同一组合出现多次
  • 双指针移动：total 是单调的——排序保证 left 右移和变大、right 左移和变小

7. 复杂度分析

复杂度说明
时间O(n²)排序 O(n log n) + 固定 i 的 O(n) 次双指针扫描 O(n)，总 O(n²)
空间O(1)除答案外只用了常数空间（排序可原地）

8. 常见易错点

忘记去重：三处去重缺一处都会产生重复三元组，尤其是「命中后」必须先跳过重复值再收缩指针。
先排序再讨论：未排序就做双指针会得到错误结果；双指针的正确性完全依赖单调性。
i 去重边界：判断用 i > 0 and nums[i] == nums[i-1]，与 nums[i] == nums[i+1] 不同（后者会漏掉 [-1, -1, 2] 这类答案）。
跳过重复值导致漏解：命中后先「去重到最后一个重复值」，再 left++, right--，顺序不能反。

9. 总结

  • 降维：三数和 → 排序后固定一个数 → 两数之和（双指针 O(n)）
  • 去重三件套：i 去重、命中后 left/right 去重
  • 复杂度：O(n²) 时间、O(1) 空间，是「排序 + 双指针」的代表题
口诀：排序固定第一个，双指针找剩下俩；三处去重不能少，O(n²) 就搞定。
