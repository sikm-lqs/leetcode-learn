4. 三数之和

返回数组中和为 0 的不重复三元组。

📋 目录

1. 题目理解 2. 核心思路：排序 + 双指针 3. 详细过程模拟 4. 代码逐段解释 5. 复杂度分析 6. 常见易错点 7. 总结

1. 题目理解

给定数组 nums，找出所有和为 0 且不重复的三元组 [nums[i], nums[j], nums[k]]。

注意：答案中不能包含重复的三元组。i、j、k 互不相同。

示例

输入：nums = [-1, 0, 1, 2, -1, -4]
输出：[[-1, -1, 2], [-1, 0, 1]]
-1 0 1 2 -1 -4

不重复的三元组：[-1, -1, 2] 和 [-1, 0, 1]。

2. 核心思路：排序 + 双指针

将 O(n³) 暴力枚举优化到 O(n²)：

  1. 排序数组 —— 让双指针可以工作
  2. 固定第一个数 nums[i]
  3. 在 [i+1, n-1] 区间用双指针找两数之和为 -nums[i]
  4. 去重：跳过重复的 nums[i] 和重复的左右指针值
核心洞察：排序后，两数和问题可以用双指针在 O(n) 时间解决，使整体从 O(n³) 降到 O(n²)。再加上去重逻辑，确保结果不重复。

最终结果：[[-1, -1, 2], [-1, 0, 1]] ✅

4. 代码逐段解释

class Solution:
    def threeSum(self, nums):
        nums.sort()
        res = []
        n = len(nums)
        for i in range(n):
            if i > 0 and nums[i] == nums[i-1]:
                continue  # 跳过重复的 i
            l, r = i + 1, n - 1
            while l < r:
                s = nums[i] + nums[l] + nums[r]
                if s == 0:
                    res.append([nums[i], nums[l], nums[r]])
                    while l < r and nums[l] == nums[l+1]: l += 1
                    while l < r and nums[r] == nums[r-1]: r -= 1
                    l += 1; r -= 1
                elif s < 0: l += 1
                else: r -= 1
        return res

去重逻辑共三处：

  1. if i > 0 and nums[i] == nums[i-1]: continue — 防止第一个数重复
  2. while l < r and nums[l] == nums[l+1]: l += 1 — 防止左指针值重复
  3. while l < r and nums[r] == nums[r-1]: r -= 1 — 防止右指针值重复
先移动指针去重，再收缩一次，确保跳过所有重复值。

5. 复杂度分析

维度值说明
时间复杂度O(n²)排序 O(n log n) + 外层循环 n × 内层双指针 O(n)
空间复杂度O(1)除结果数组外，只用了常数空间

6. 常见易错点

错误：忘记去重导致重复三元组

三个地方的去重缺一不可，否则会出现 [-1, -1, 2] 重复出现。

错误：去重顺序搞错

先移动指针去重，后再收缩一次。正确顺序：

while l < r and nums[l] == nums[l+1]: l += 1
while l < r and nums[r] == nums[r-1]: r -= 1
l += 1; r -= 1  # 别忘了再缩一次

7. 总结

三数之和 解法精髓：

  • 排序 + 固定一个数
  • 剩余区间 双指针 找两数和
  • 三处去重 保证结果不重复

💡 口诀：排序固定第一个，双指针找剩下俩。三处去重不能少，O(n²) 就搞定。
