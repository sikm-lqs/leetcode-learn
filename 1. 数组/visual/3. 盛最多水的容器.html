3. 盛最多水的容器

给定高度数组，找出两条线使它们与 x 轴构成的容器能容纳最多的水。

1. 题目理解

给定 n 个非负整数 height，每个数代表坐标 (i, height[i]) 的一条垂直线。找出两条线，使得它们与 x 轴构成的容器能容纳最多水。

面积公式：min(height[left], height[right]) × (right - left)

示例

输入：height = [1, 8, 6, 2, 5, 4, 8, 3, 7]
输出：49

最大面积来自 height[1] = 8 和 height[8] = 7，宽度为 7，高度取小值 7，面积 = 7 × 7 = 49。

2. 核心思路：双指针

用左右两个指针从两端向中间收缩：

  • 每次计算当前面积 min(h[l], h[r]) × (r - l)
  • 更新最大面积
  • 移动较短的边——因为移动长边不会让面积变大
核心洞察：面积由较短的边决定。移动长边，高度不可能变大（受限于短边），宽度却在缩小，面积只减不增。所以唯一正确策略是移动短边。

5. 代码逐段解释

class Solution:
    def maxArea(self, height: List[int]) -> int:
        l, r = 0, len(height) - 1
        max_area = 0
        while l < r:
            cur = (r - l) * min(height[l], height[r])
            max_area = max(max_area, cur)
            if height[l] < height[r]:
                l += 1
            else:
                r -= 1
        return max_area

l, r = 0, len(height) - 1：双指针初始化在两端。

cur = (r - l) * min(height[l], height[r])：计算当前面积。

if height[l] < height[r]: l += 1 else: r -= 1：总是移动较短的那条边。

为什么移动短边？因为面积受限于短边，固定短边移动长边面积只会更小。移动短边才有可能找到更高的边。

6. 复杂度分析

维度值说明
时间复杂度O(n)双指针一次遍历，每步移动一个指针。
空间复杂度O(1)只用两个指针和常数变量。

7. 常见易错点

错误：移动较长的边

直觉上可能想"把高的柱子留着"——但面积受限于短边，留长边没意义。

边界：只有两根柱子

直接计算一次面积即可返回。

8. 总结

盛最多水的容器 解法精髓：

  • 双指针从两端向中间收缩
  • 每步计算面积并更新最大值
  • 总是移动较短的边
class Solution:
    def maxArea(self, h):
        l, r, ans = 0, len(h)-1, 0
        while l < r:
            ans = max(ans, (r-l) * min(h[l], h[r]))
            if h[l] < h[r]: l += 1
            else: r -= 1
        return ans

💡 口诀：左右双指针，面积看短板。短边往内移，最大自然来。
