2. 移动零

将数组中所有 0 移动到末尾，同时保持非零元素的相对顺序。原地操作。

1. 题目理解

给定一个数组 nums，将所有的 0 移动到数组的末尾，同时保持非零元素的相对顺序不变。要求原地修改，不能使用额外数组。

示例

输入：nums = [0, 1, 0, 3, 12]
输出：[1, 3, 12, 0, 0]
0 1 0 3 12

→ 移动后

1 3 12 0 0
非零元素 1, 3, 12 的相对顺序保持不变，所有 0 移到了末尾。

2. 核心思路：快慢指针

用两个指针，一趟遍历完成：

  • 快指针 fast：负责扫描数组，寻找非零元素
  • 慢指针 slow：指向下一个非零元素应放入的位置

遇到非零元素时，与 nums[slow] 交换，然后 slow++。这样所有零会被自然地交换到数组末尾。

核心洞察：交换操作同时完成了两件事——将非零数往前移、将零往后移。一趟遍历，无需额外数组。

6. 代码逐段解释

class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1

slow = 0：指向下一个非零元素该放的位置。

for fast in range(len(nums))：快指针扫描每个元素。

if nums[fast] != 0：发现非零元素，与 slow 位置的元素交换。

slow += 1：慢指针移动到下一个位置。

因为非零元素总是向前"挤"，交换后原来的位置自然被 0 填充，所以不用手动清零。

7. 复杂度分析

维度值说明
时间复杂度O(n)快指针遍历一次数组。
空间复杂度O(1)只用了两个额外指针。

8. 常见易错点

错误一：把交换写成覆盖

nums[slow] = nums[fast]  # ❌ 会丢失非零数据！

必须用交换，否则会覆盖掉 slow 位置原来的值。

错误二：忘记交换后 slow++

if nums[fast] != 0:
    nums[slow], nums[fast] = nums[fast], nums[slow]
    # 忘记 slow += 1 → 后续交换位置会错乱
每交换一次都要移动 slow，否则非零元素放的位置不对。

9. 总结

移动零 解法精髓：

  • 快慢指针，一趟遍历
  • 非零元素与 slow 位置交换
  • 零自然"浮"到末尾
class Solution:
    def moveZeroes(self, nums):
        s = 0
        for f in range(len(nums)):
            if nums[f] != 0:
                nums[s], nums[f] = nums[f], nums[s]
                s += 1

💡 口诀：快慢双指针，非零就交换。零自往后移，顺序不乱掉。
