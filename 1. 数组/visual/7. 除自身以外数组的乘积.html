7. 除自身以外数组的乘积

返回数组 answer，其中 answer[i] 等于 nums 中除 nums[i] 之外其余各元素的乘积。不使用除法，O(n)。

1. 题目理解

给定数组 nums，返回 answer，其中 answer[i] 是 nums 中除 nums[i] 外所有元素的乘积。

限制：不能使用除法，时间 O(n)。

示例

输入：nums = [1, 2, 3, 4]
输出：[24, 12, 8, 6]
位置排除剩余乘积结果
012 × 3 × 424
121 × 3 × 412
231 × 2 × 48
341 × 2 × 36

2. 核心思路：前缀积 × 后缀积

不使用除法、O(n) 的关键：

  • answer[i] = 左侧所有数的乘积 × 右侧所有数的乘积
  • 先在 answer 中存储前缀积（从左到右扫描）
  • 再用一个变量存储后缀积，从右到左乘到 answer 上
answer[i] = (nums[0] × ... × nums[i-1]) × (nums[i+1] × ... × nums[n-1])
核心洞察：两次遍历，分别算「我左边所有数的积」和「我右边所有数的积」，乘在一起就是除我之外的积。用输出数组暂存中间结果，无需额外空间。

5. 代码逐段解释

class Solution:
    def productExceptSelf(self, nums):
        n = len(nums)
        answer = [1] * n

        # 第一遍：左侧乘积
        left = 1
        for i in range(n):
            answer[i] = left
            left *= nums[i]

        # 第二遍：右侧乘积
        right = 1
        for i in range(n - 1, -1, -1):
            answer[i] *= right
            right *= nums[i]

        return answer

第一遍：answer[i] 存储「nums[i] 左边所有数的乘积」。每次更新后 left 乘上当前数。

第二遍：用 right 记录右侧乘积，乘到 answer[i] 上。从右向左遍历。

注意 answer 数组在第一次遍历中存储中间结果，这是"在输出数组上暂存"的技巧，不算额外空间。

7. 常见易错点

错误：忘记初始化 answer 为 1

乘法初始值应为 1，不是 0。

错误：第一遍遍历时 left 的更新顺序

answer[i] = left  # 先赋值
left *= nums[i]   # 再乘当前值

顺序反过来会导致包含自身。

边界：数组中有 0

如果用除法，0 会导致除零错。这种前缀积 × 后缀积的做法天然处理了 0 的情况。

8. 总结

除自身以外数组的乘积 解法精髓：

  • 第一次遍历：计算前缀积，存入 answer
  • 第二次遍历：乘上后缀积，得到最终结果
  • O(n) 时间，O(1) 额外空间，不使用除法
class Solution:
    def productExceptSelf(self, nums):
        ans = [1] * len(nums)
        for i, v in enumerate(nums):
            ans[i] = l; l *= v
        r = 1
        for i in range(len(nums)-1, -1, -1):
            ans[i] *= r; r *= nums[i]
        return ans

💡 口诀：先算左边积，再乘右边积。两趟 O(n)，除法不需要。
