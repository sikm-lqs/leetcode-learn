5. 合并区间

排序 + 一次遍历：重叠判断只需比较右端点。

1. 题目理解

以数组 intervals 表示若干个区间的集合，其中单个区间为 intervals[i] = [start_i, end_i]。请合并所有重叠的区间，并返回一个不重叠的区间数组。

示例

输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释：[1,3] 与 [2,6] 重叠，合并成 [1,6]。

输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
解释：[1,4] 与 [4,5] 端点相接也算重叠。
注意第二个示例：[1,4] 与 [4,5] 端点重合（start ≤ 上一个 end）也要合并。

2. 核心思路：排序 + 一次遍历

  1. 按起点排序：排序后，能合并的区间必然相邻
  2. 遍历：维护结果数组 res，判断当前区间 cur 是否与 res 最后一个区间重叠
  3. 重叠判断：cur[0] > res[-1][1] 表示不重叠（当前起点大于上一个终点）→ 直接加入；否则重叠 → 更新最后一个区间的终点为两者较大值
排序是核心洞察：未排序时区间交错，合并需要复杂的交叉判断；排序后每个区间只需与「结果中最后一个」比较一次。

5. 详细过程模拟

步骤当前区间res 最后一个判断操作
1[1,3]—（空）res 为空直接加入 → res = [[1,3]]
2[2,6][1,3]2 ≤ 3 → 重叠更新终点：max(3,6)=6 → res = [[1,6]]
3[8,10][1,6]8 > 6 → 不重叠直接加入 → res = [[1,6],[8,10]]
4[15,18][8,10]15 > 10 → 不重叠直接加入 → res = [[1,6],[8,10],[15,18]]
「排序」把复杂问题变简单：只要当前起点大于结果末区间终点，就不可能与任何更早的区间重叠（它们终点都更小）。

6. 代码逐段解释

from typing import List

class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort()                      # 按起点排序（列表默认按第一元素）
        res = []
        for cur in intervals:
            if not res or cur[0] > res[-1][1]:
                res.append(cur)               # 不重叠：直接加入
            else:
                res[-1][1] = max(res[-1][1], cur[1])  # 重叠：终点取较大值
        return res

逐段说明

  • 排序：Python 列表排序默认按第一个元素升序，起点相同再按终点，恰好符合需求
  • 重叠判断：cur[0] > res[-1][1] —— 当前起点大于结果末区间终点才不重叠
  • 原地修改：直接更新 res[-1][1]，因为已排序保证新终点不会影响与后续区间的判断

7. 复杂度分析

复杂度说明
时间O(n log n)排序 O(n log n)，遍历合并 O(n)
空间O(n)结果数组 res 最坏存 n 个区间；排序 O(log n) 栈空间（可忽略）

8. 常见易错点

忘记排序：不排序时区间可能交错（如 [[2,6],[1,3]]），与结果末区间比较会得出错误结论。
端点相接的区间：cur[0] == res[-1][1] 也应合并（条件用 > 而非 >=）。
只更新终点、不动起点：合并结果起点用上一个区间的起点，因为已排序保证它是最小的。
直接引用 vs 拷贝：res.append(cur) 存的是引用，若后续修改 cur 会污染结果（本题原地改 res[-1] 不涉及，但要意识到）。

9. 总结

  • 排序 + 一次遍历：重叠判断简化为「当前起点 vs 结果末终点」一行比较
  • 两种动作：不重叠就加入，重叠就吞并（终点取 max）
  • 复杂度：O(n log n) 时间、O(n) 空间，区间类问题的最优范式
口诀：排序一遍过，不重叠直接加，重叠取大终点。
