5. 合并区间

给定若干区间，合并所有重叠的区间。

📋 目录

1. 题目理解 2. 核心思路：排序 + 合并 3. 详细过程模拟 4. 代码逐段解释 5. 复杂度分析 6. 常见易错点 7. 总结

1. 题目理解

给定一组区间 intervals = [[start, end]]，合并所有重叠的区间，返回恰好覆盖输入中所有区间的不重叠区间数组。

示例

输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
[1, 3] [2, 6] → [1, 6]
[8, 10] → [8, 10]
[15, 18] → [15, 18]
[1,3] 和 [2,6] 有重叠（3 ≥ 2），合并为 [1,6]。[8,10] 与 [15,18] 无重叠，保持不变。

2. 核心思路：排序 + 合并

  1. 按区间起点排序
  2. 遍历区间，维护结果数组 res
  3. 如果当前区间起点 > res 最后区间的终点 → 无重叠，直接加入
  4. 否则 → 有重叠，更新最后区间的终点为两者较大值
重叠判断：cur[0] > last[1] → 不重叠，否则重叠
核心洞察：排序后只需 O(n) 一次遍历。重叠的判断只需比较当前区间的左端点和已合并区间的右端点，无需复杂数据结构。

4. 代码逐段解释

class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort()                     # 按起点排序
        res = []
        for cur in intervals:
            if not res or cur[0] > res[-1][1]:
                res.append(cur)                # 无重叠，直接加入
            else:
                res[-1][1] = max(res[-1][1], cur[1])  # 合并终点
        return res

intervals.sort()：按起点升序排序。Python 默认对列表按第一个元素排序。

if not res or cur[0] > res[-1][1]：如果结果为空，或者当前区间起点超过已合并区间的终点 → 无重叠。

res[-1][1] = max(res[-1][1], cur[1])：有重叠，取较大的终点作为合并后的终点。

按起点排序后，重叠的判断变得异常简单：只关心已合并区间的终点。

5. 复杂度分析

维度值说明
时间复杂度O(n log n)排序 O(n log n)，合并遍历 O(n)
空间复杂度O(1)除结果数组外，只用常数空间

6. 常见易错点

错误：忘记排序

如果不排序，无法保证当前区间之前的区间已被处理完，合并逻辑会错乱。

错误：合并时取小值

res[-1][1] = cur[1]  # ❌ 应该取较大值
res[-1][1] = max(res[-1][1], cur[1])  # ✅

边界：单区间、空数组

空数组返回 []，单个区间返回自身。

7. 总结

合并区间 解法精髓：

  • 按起点排序
  • 一次遍历，比较当前起点与已合并终点
  • 重叠则取较大终点，不重叠则直接加入
class Solution:
    def merge(self, intervals):
        intervals.sort()
        res = []
        for cur in intervals:
            if not res or cur[0] > res[-1][1]:
                res.append(cur)
            else:
                res[-1][1] = max(res[-1][1], cur[1])
        return res

💡 口诀：排序一遍过，不重叠直接加，重叠取大终点。
