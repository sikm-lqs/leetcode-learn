1. 两数之和

给定整数数组 nums 和目标值 target，找出和为目标值的两个整数，返回它们的下标。

1. 题目理解

给定一个整数数组 nums 和一个整数 target，在数组中找出和等于 target 的两个数，返回它们的下标。

注意：每种输入只会对应一个答案，且同一个元素不能使用两次。返回的下标顺序不限。

示例

输入：nums = [2, 7, 11, 15], target = 9
输出：[0, 1]
解释：nums[0] + nums[1] = 2 + 7 = 9
2 7 11 15
0 1 2 3

2 + 7 = 9，所以返回 [0, 1]（或 [1, 0]）。

2. 核心思路：哈希表

❌ 暴力法 O(n²)

两层循环枚举所有数对，检查是否等于 target。简单但低效。

✅ 哈希表 O(n)

遍历一次，用哈希表记录已见过的数。对每个数检查 target - num 是否在表中。

算法流程

  1. 创建一个空的哈希表 num_map（值 → 下标）
  2. 遍历数组，对每个 num：
  3.   计算 complement = target - num
  4.   如果 complement 在哈希表中 → 返回 [num_map[complement], idx]
  5.   否则将 num 存入哈希表
核心洞察：用空间换时间。哈希表让我们能在 O(1) 时间内判断 complement 是否已出现，而不是再扫一遍数组。

5. 代码逐段解释

完整代码

from typing import List

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        num_map = {}
        for idx, num in enumerate(nums):
            complement = target - num
            if complement in num_map:
                return [num_map[complement], idx]
            num_map[num] = idx

逐段说明

第 1 步：初始化哈希表

num_map = {}

键是数字，值是该数字的下标。

第 2 步：遍历数组

for idx, num in enumerate(nums):
    complement = target - num

enumerate 同时拿到下标和值。complement 是当前数需要配对的数字。

第 3 步：检查 complement 是否出现过

if complement in num_map:
    return [num_map[complement], idx]

如果 complement 已经在哈希表中，说明之前遍历到过，直接返回两个下标。

第 4 步：存入当前数

num_map[num] = idx

还没找到答案，把当前数加入哈希表供后续使用。

题目保证有且仅有一个解，所以不需要处理找不到的情况。

6. 复杂度分析

维度值说明
时间复杂度O(n)只需一次遍历，哈希表查找和插入均为 O(1)。
空间复杂度O(n)哈希表最多存储 n 个键值对。

7. 常见易错点

错误一：同一个元素用两次

# 错误：先存再查 → 可能用同一个元素
num_map[num] = idx
if complement in num_map: ...

必须先查再存，否则可能 nums[i] 和自己的 complement 相同。

错误二：返回下标顺序搞反

return [idx, num_map[complement]]  # ❌
return [num_map[complement], idx]  # ✅
注意：complement 是之前遇到的数，它的下标在前；当前数的下标在后。

边界情况

输入说明
nums=[3, 2, 4], target=6返回 [1, 2]，3+3 不允许，是 2+4
nums=[3, 3], target=6返回 [0, 1]

8. 总结

两数之和 解法精髓：

  • 用 哈希表 记录已遍历的元素
  • 对每个数计算 target - num
  • 检查 complement 是否在表中
  • 先查后存，避免重复使用同一元素
class Solution:
    def twoSum(self, nums, target):
        m = {}
        for i, v in enumerate(nums):
            if target - v in m:
                return [m[target - v], i]
            m[v] = i

💡 口诀：遍历查补数，先查再存入。哈希记位置，一次就找到。
