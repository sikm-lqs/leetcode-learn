8. 和为 K 的子数组

统计并返回数组中和为 k 的连续子数组的个数。

📋 目录

1. 题目理解 2. 核心思路：前缀和 + 哈希表 3. 详细过程模拟 4. 代码逐段解释 5. 复杂度分析 6. 常见易错点 7. 总结

1. 题目理解

给定数组 nums 和整数 k，统计连续子数组中和为 k 的个数。

示例

输入：nums = [1, 1, 1], k = 2
输出：2
解释：[1, 1]（索引 0-1）和 [1, 1]（索引 1-2）
1 1 1

和为 2 ✓

1 1 1

和为 2 ✓

2. 核心思路：前缀和 + 哈希表

定义 pre[i] = nums[0] + ... + nums[i]，则子数组 nums[l→r] 的和 = pre[r] - pre[l-1]。

要求和为 k，即 pre[r] - pre[l-1] = k → pre[l-1] = pre[r] - k。

所以遍历时：

  • 维护当前前缀和 s
  • 在哈希表中查找 s - k 的出现次数
  • 将当前前缀和存入哈希表
当前前缀和 s → 查找 count[s - k] → 累加答案
核心洞察：将子数组求和转化为"两个前缀和的差"，用哈希表存前缀和频率，将 O(n²) 暴力降至 O(n)。初始化 count[0] = 1 是为了处理从索引 0 开始的子数组。

4. 代码逐段解释

class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        count = {0: 1}  # 前缀和为 0 出现 1 次
        s = 0; ans = 0
        for num in nums:
            s += num
            ans += count.get(s - k, 0)
            count[s] = count.get(s, 0) + 1
        return ans

count = {0: 1}：初始化前缀和为 0 出现 1 次。这一步很关键，处理从索引 0 开始的子数组。

ans += count.get(s - k, 0)：查找有多少个前缀和等于 s - k，这些位置到当前位置的子数组和都为 k。

count[s] = count.get(s, 0) + 1：记录当前前缀和的出现次数。

因为 nums 可能有负数，相同的前缀和可能出现多次，所以用频率计数而不是布尔值。

5. 复杂度分析

维度值说明
时间复杂度O(n)单次遍历，哈希表操作 O(1)
空间复杂度O(n)哈希表最多存储 n 个不同前缀和

6. 常见易错点

错误：忘记初始化 count[0] = 1

如果不初始化，从索引 0 开始的子数组会被漏掉。

错误：先记录再查找

count[s] = 1  # ❌ 先存
ans += count.get(s - k, 0)  # 如果 k=0，自己会被算进去

必须先查再存，防止 k=0 时把当前子数组也算上。

边界：负数

前缀和可能变小，哈希表能正确处理。

7. 总结

和为 K 的子数组 解法精髓：

  • 前缀和将子数组和转化为差值
  • 哈希表记录前缀和频率
  • 初始化 count[0]=1 处理从头开始的子数组
class Solution:
    def subarraySum(self, nums, k):
        m = {0:1}; s = 0; ans = 0
        for v in nums:
            s += v; ans += m.get(s - k, 0); m[s] = m.get(s, 0) + 1
        return ans

💡 口诀：前缀和加哈希表，s-k 频率累加。初始化 0:1，从头开始不漏掉。
