8. 和为 K 的子数组

前缀和 + 哈希表：把 O(n²) 暴力降到 O(n)。

1. 题目理解

给你一个整数数组 nums 和一个整数 k，请你统计并返回该数组中和为 k 的连续子数组的个数。子数组是数组中元素的连续非空序列。

示例

输入：nums = [1, 1, 1], k = 2
输出：2
解释：[1,1]（索引 0-1）和 [1,1]（索引 1-2）

输入：nums = [1, 2, 3], k = 3
输出：2
解释：[1,2] 和 [3]
注意：题目要求的是「连续」子数组，且数组可能含负数——所以不能对前缀和数组排序或使用滑动窗口。

2. 核心思路：前缀和 + 哈希表

  1. 定义前缀和 pre[i] = nums[0] + ... + nums[i]
  2. 子数组 nums[l→r] 的和 = pre[r] - pre[l-1]，问题转化为找 pre[r] - pre[l-1] = k，即 pre[l-1] = pre[r] - k
  3. 遍历时用哈希表记录每个前缀和出现的次数；每步先查 count[s - k] 累加到答案，再登记当前前缀和
  4. 初始化 count[0] = 1：表示「空前缀」，用于处理从索引 0 开始的子数组
pre[r] − pre[l−1] = k  ⟺  pre[l−1] = pre[r] − k
经典「一边遍历一边查表」：查表时表里存的是「之前所有前缀和的频率」，恰好覆盖所有可能的 l-1。

6. 代码逐段解释

from typing import List

class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        count = {0: 1}          # 前缀和 → 出现次数，空前缀 = 1
        s = 0                     # 当前前缀和
        ans = 0
        for num in nums:
            s += num
            ans += count.get(s - k, 0)   # 有 count[s-k] 个前缀，与当前下标构成和为 k 的子数组
            count[s] = count.get(s, 0) + 1  # 登记当前前缀和
        return ans

逐段说明

  • 初始化 count[0] = 1：前缀和为 0 出现 1 次，等价于「下标 -1 的前缀和 = 0」，覆盖 nums[0:r] 整体等于 k 的情况
  • 查表在登记前：先查 s - k 再登记 s，保证「自己减自己」不被计入（子数组至少一个元素）
  • 负数也可用：只依赖前缀和差值，与元素正负无关（这是比滑动窗口强的原因）

7. 复杂度分析

复杂度说明
时间O(n)一趟遍历，哈希表查询/插入均为 O(1)
空间O(n)哈希表最多存 n 个不同的前缀和

8. 常见易错点

忘记初始化 count[0] = 1：nums = [1,1,1], k = 3 时，漏掉初始化会少算从索引 0 开始的子数组。
查表与登记顺序颠倒：先登记再查表会把「当前前缀和自身」算进去，产生错误的子数组（长度为 0）。
用滑动窗口替代：数组含负数时窗口收缩条件不单调，滑动窗口失效，必须用前缀和。
与「两数之和」混淆：本题查的是 s - k 的出现次数（累加），不是是否存在（返回下标）。

9. 总结

  • 转化：子数组和 → 前缀和差值，问题变成「统计差值为 k 的前缀和配对」
  • 哈希表：用频率表把「枚举所有左端点」压缩成 O(1) 查表
  • 复杂度：O(n) 时间、O(n) 空间，处理含负数的数组依然成立
口诀：前缀和加哈希表，s-k 频率累加；初始化 0:1，从头开始不漏掉。
