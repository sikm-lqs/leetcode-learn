10. 等差数列划分

返回数组 nums 中所有等差子数组（长度 ≥ 3）的个数。

1. 题目理解

如果一个数列至少有三个元素，且任意两个相邻元素之差相同，则称该数列为等差数列。

给定数组 nums，返回所有为等差数组的子数组个数（子数组即连续子序列）。

示例

输入：nums = [1, 2, 3, 4]
输出：3
解释：[1,2,3], [2,3,4], [1,2,3,4] 三个等差子数组
1234 → [1,2,3] ✓
1234 → [2,3,4] ✓
1234 → [1,2,3,4] ✓

2. 核心思路：增量法

遍历数组，检查每三个相邻元素是否等差。但难点在于：等差数列可能很长，如何统计所有子数组？

增量法：

  • 用 cur 记录「以当前位置结尾的新增等差子数组个数」
  • 如果 nums[i] - nums[i-1] == nums[i-1] - nums[i-2]，则 cur += 1，否则 cur = 0
  • 累加 cur 到答案
等差连续 → cur += 1; ans += cur
等差中断 → cur = 0
核心洞察：每增加一个等差元素，新增的子数组数 = 之前连续等差长度 - 1。例如 [1,2,3] 新增 1 个，[1,2,3,4] 新增 2 个（[2,3,4] 和 [1,2,3,4]）。增量法无需统计段长再算组合数。

6. 代码逐段解释

class Solution:
    def numberOfArithmeticSlices(self, nums):
        ans = 0; cur = 0
        for i in range(2, len(nums)):
            if nums[i] - nums[i-1] == nums[i-1] - nums[i-2]:
                cur += 1
                ans += cur
            else:
                cur = 0
        return ans

for i in range(2, len(nums))：从索引 2 开始检查，因为需要至少 3 个元素才能构成等差。

nums[i] - nums[i-1] == nums[i-1] - nums[i-2]：检查三个相邻元素是否等差。

cur += 1; ans += cur：核心增量逻辑。每多一个等差元素，新增的子数组个数恰好等于连续等差段落的「增量」。

为什么 cur 递增？[1,2,3] 长度为 3，cur=1；[1,2,3,4] 长度为 4，cur=2。cur 实际上等于「以当前结尾的等差段长度 - 2」。

8. 常见易错点

错误：从索引 0 或 1 开始遍历

必须从 i=2 开始，因为需要比较 nums[i]、nums[i-1]、nums[i-2] 三个元素。

错误：忘记重置 cur

等差中断后 cur 要归零，否则后续会错误累加。

边界：数组长度 < 3

直接返回 0。

9. 总结

等差数列划分 解法精髓：

  • 遍历检查三个相邻元素是否等差
  • 增量法：cur 记录新增子数组数
  • 累加 cur 到答案，等差中断则重置
class Solution:
    def numberOfArithmeticSlices(self, nums):
        cur = ans = 0
        for i in range(2, len(nums)):
            if nums[i] - nums[i-1] == nums[i-1] - nums[i-2]:
                cur += 1; ans += cur
            else: cur = 0
        return ans

💡 口诀：三数等差就递增，cur 累加到 ans。等差中断 cur 归零，O(n) 一次过。
