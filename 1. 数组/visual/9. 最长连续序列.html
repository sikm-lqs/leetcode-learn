9. 最长连续序列

给定一个未排序的整数数组，找出数字连续的最长序列的长度。要求时间复杂度 O(n)。

1. 题目理解

给你一个未排序的整数数组 nums，找出数字连续的最长序列的长度。

注意：连续序列指 x, x+1, x+2, ... 这样的等差为 1 的序列，不要求序列元素在原数组中连续（只看值，不看位置）。要求时间复杂度 O(n)。

示例 1

输入：nums = [100, 4, 200, 1, 3, 2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]，长度为 4
100 4 200 1 3 2
0 1 2 3 4 5

别看数组长这样，从值的角度看，1 → 2 → 3 → 4 构成了长度为 4 的连续序列。100 和 200 是孤立的。

示例 2

输入：nums = [0, 3, 7, 2, 5, 8, 4, 6, 0, 1]
输出：9

包含 0 到 8 的所有数（9 除外），最长连续序列是 [0, 1, 2, 3, 4, 5, 6, 7, 8]，长度 9。

2. 核心思路：用集合找起点

拿到题目第一反应通常是排序后扫一遍：排序 O(n log n)，再线性找最长连续段。这个想法完全正确、也很好写（见第 7 章「解法二」），但题目要求 O(n)，排序成了瓶颈——于是需要换思路。

❌ 暴力思路

遍历每个数，不断 +1 查是否存在。每个数查 k 次，最坏 O(n²)。

✅ 优化思路

用 集合 实现 O(1) 查找。并且只从序列起点开始查找，避免重复。

判断起点的关键

如果 num - 1 不在 集合中 → num 是一个连续序列的起点

举例说明：

  • 1：1-1=0 不在集合中 → 起点 → 向后找 2、3、4 → 长度 4
  • 2：2-1=1 在集合中 → 不是起点 → 跳过（因为从 1 出发时已经算过它了）
  • 100：100-1=99 不在集合中 → 起点 → 向后找 101 不存在 → 长度 1
核心洞察：每个连续序列只从它的最小值开始遍历一次。这样每个元素最多被访问两次（一次在起点检查，一次在序列延伸），总复杂度 O(n)。

算法流程

  1. 将 nums 转为集合 num_set（去重 + O(1) 查找）
  2. 遍历集合中的每个数 num
  3. 如果 num - 1 不在集合中，说明是起点：
  4.   从 num 开始，不断 +1 查找连续的数，统计长度
  5.   更新 max_len
  6. 返回 max_len

5. 详细过程模拟

以 nums = [100, 4, 200, 1, 3, 2] 为例，完整模拟算法执行过程。

预备：构建集合

num_set = {1, 2, 3, 4, 100, 200}

集合去除了重复元素，并提供 O(1) 的查找速度。

第 1 轮：处理数字 1

100 4 200 1 3 2

检查：1 - 1 = 0 在集合中吗？不在 → 1 是序列起点！

从 1 开始向后查找：1 → 2 → 3 → 4 都在集合中，长度 = 4。5 不在集合中，停止。max_len = 4。

第 2～4 轮：处理数字 2、3、4

100 4 200 1 3 2

检查 2-1=1 在集合中 → 不是起点，跳过。
检查 3-1=2 在集合中 → 不是起点，跳过。
检查 4-1=3 在集合中 → 不是起点，跳过。

这些数已经在第 1 轮被 [1,2,3,4] 序列覆盖了，不需要重复查找。这就是"起点判断"的威力。

第 5 轮：处理数字 100

100 4 200 1 3 2

检查：100 - 1 = 99 不在集合中 → 起点。向后查 101 不存在 → 长度 = 1。max_len 保持 4。

第 6 轮：处理数字 200

100 4 200 1 3 2

检查：200 - 1 = 199 不在集合中 → 起点。向后查 201 不存在 → 长度 = 1。max_len 保持 4。

6. 代码逐段解释

完整代码

from typing import List

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        # 利用集合快速查找某数是否在 nums 中
        num_set = set(nums)
        max_len = 0

        for num in num_set:
            # 只有连续序列的起点才会往后找
            if num - 1 not in num_set:
                cur = num
                cur_len = 1

                # 向后查找连续的数
                while cur + 1 in num_set:
                    cur += 1
                    cur_len += 1

                max_len = max(max_len, cur_len)

        return max_len

逐段说明

第 1 步：建立集合

num_set = set(nums)

将数组转为哈希集合。好处：去重 + O(1) 查找。

第 2 步：判断起点（灵魂所在）

if num - 1 not in num_set:

这是整个算法最精巧的地方。只有 num - 1 不存在时，num 才是一个连续序列的起点。

为什么这样可以避免重复？如果 num - 1 存在，说明 num 已经被包含在某个从更小数开始的序列中了，不需要再计算一次。

第 3 步：向后延伸

cur = num
cur_len = 1
while cur + 1 in num_set:
    cur += 1
    cur_len += 1

不断 +1 查找下一个数是否存在，同时累计长度。

第 4 步：更新最大值

max_len = max(max_len, cur_len)

每处理完一个序列，更新全局最大值。

7. 解法二：排序 + 一次扫描

这是拿到题目最容易第一时间想到的解法：先排序，让相等的数聚在一起、连续的数变相邻，再一次线性扫描统计最长连续段。思路直白、代码好写，代价是排序引入 O(n log n)，不满足题目 O(n) 的要求。

扫描时的三个判断

  • 重复：nums[right] == nums[right-1] → 跳过（continue），既不累加也不重置
  • 连续：nums[right] == nums[right-1] + 1 → cur += 1
  • 断开：其他情况 → cur = 1，从当前数重新计数

伪代码骨架

if 数组为空: return 0       # if not nums
排序                        # nums.sort()

ans = 1
cur = 1

for right in 1 .. n-1:
    if 与前一数相等:           # nums[right] == nums[right-1]
        跳过重复
    elif 与前一数差一:         # nums[right] == nums[right-1] + 1
        连续长度加一            # cur += 1
    else:
        重置连续长度            # cur = 1
    更新最大长度                # ans = max(ans, cur)

return ans
关键字 变量 中文操作 注释公式
重复数字必须单独处理：既不能算进长度，也不能触发重置，直接 continue 跳过。

完整代码

class Solution2:
    # 解法二：先排序再一次扫描，O(n log n)
    def longestConsecutive(self, nums: List[int]) -> int:
        if not nums:
            return 0

        nums.sort()
        ans = 1
        cur = 1

        for right in range(1, len(nums)):
            # 重复数字跳过
            if nums[right] == nums[right - 1]:
                continue

            if nums[right] == nums[right - 1] + 1:
                # 连续
                cur += 1
            else:
                # 断开，重置
                cur = 1

            ans = max(ans, cur)

        return ans

复杂度：时间 O(n log n)（排序主导，扫描只占 O(n)）；空间 O(1)（原地排序）。面试可以先快速写出这个解法证明思路正确，再优化到解法一的 O(n)。

8. 复杂度分析

维度值说明
时间复杂度 O(n) 每个元素最多被访问两次：一次在 for 循环中检查起点，一次在 while 循环中延伸序列。
空间复杂度 O(n) 需要额外存储集合 num_set。

为什么是 O(n) 而不是 O(n²)？

关键就在 if num - 1 not in num_set 这个判断：

  • 只有序列的起点才会进入 while 循环
  • 每个序列的每个元素在 while 中只被遍历一次
  • 非起点的元素在 for 循环中直接被跳过，O(1) 判断
n 个元素，每个元素最多被检查 2 次 → 总操作 ≈ 2n → O(n)

两种解法对比

解法时间空间关键点
解法一 · 哈希集合 O(n) O(n) 起点判断 num - 1 not in set，每个序列只遍历一次
解法二 · 排序 + 扫描 O(n log n) O(1) 排序让连续数相邻，跳过重复、断开重置

解法二不满足题目 O(n) 要求，但胜在直观易写；解法一满足要求，是本题的标准答案。

9. 常见易错点

错误一：在原始数组上遍历而非集合

# 错误：遍历原始数组
for num in nums:   # 有重复数时会重复计算相同序列

应该遍历集合，避免重复元素导致的重复计算。

错误二：忘记起点判断导致 O(n²)

# 错误：没有起点判断，对每个数都向后找
for num in num_set:
    while cur + 1 in num_set: ...  # 每个序列被重复计算多次

错误三：混淆"连续"的含义

注意：题目说的"连续"指数值上的连续（x, x+1, x+2, ...），不是指在原数组中相邻的位置。这是最容易误解的地方。

边界情况

输入预期说明
[]0空数组
[1]1单个元素
[1, 2, 0, 1]3有重复，序列为 [0,1,2]

10. 总结

最长连续序列 解法精髓：

  • 用 集合 实现 O(1) 查找
  • 用 num - 1 in set 判断序列起点
  • 只从起点开始 向后延伸
  • 每个元素最多被访问 两次 → O(n)

最简洁记忆版

class Solution:
    def longestConsecutive(self, nums):
        s = set(nums)
        best = 0
        for x in s:
            if x - 1 not in s:
                y = x + 1
                while y in s:
                    y += 1
                best = max(best, y - x)
        return best

💡 口诀：去重建集合，起点才查找。往右一直数，更新最大长。
