6. 轮转数组

给定整数数组 nums，将其元素向右轮转 k 个位置。原地修改。

1. 题目理解

将数组元素向右轮转 k 个位置。轮转意味着末尾元素移到开头，依次类推。

示例

输入：nums = [1, 2, 3, 4, 5, 6, 7], k = 3
输出：[5, 6, 7, 1, 2, 3, 4]
1234567

→ 右移 3 位 →

5671234

2. 核心思路：三次反转

取余：k = k % len(nums)，因为轮转 n 次等于没转。

三步反转：

  1. 反转整个数组
  2. 反转前 k 个元素
  3. 反转后 n-k 个元素
核心洞察：反转操作具有叠加性。整体反转将尾部元素移到前面，再分别反转两段恢复顺序，间接实现轮转效果。
k = k % n → 反转全部 → 反转前 k 个 → 反转后 n-k 个

6. 代码逐段解释

class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        k = k % len(nums)
        nums.reverse()                        # 第一步：整体反转
        self._reverse(0, k - 1, nums)      # 第二步：反转前 k 个
        self._reverse(k, len(nums) - 1, nums)  # 第三步：反转后 n-k 个

    def _reverse(self, start, end, num):
        while start < end:
            num[start], num[end] = num[end], num[start]
            start += 1; end -= 1

k = k % len(nums)：处理 k > n 的情况，轮转 n 次等于没转。

nums.reverse()：Python 内置反转，整个数组原地反转。

_reverse(0, k-1, nums)：反转前 k 个元素，把它们恢复为正确顺序。

_reverse(k, len(nums)-1, nums)：反转剩余元素，恢复顺序。

三次反转完美利用了「反转的叠加性」——整体反转把尾部移动到前面，分段反转恢复各自内部的顺序。

6. 复杂度分析

维度值说明
时间复杂度O(n)三次反转各遍历一部分，总共 n 次操作
空间复杂度O(1)原地修改，仅用常数空间

7. 常见易错点

错误：忘记取余

如果 k > n，不取余会导致反转索引越界或结果错误。

错误：反转顺序搞反

必须是「整体→前 k 个→后 n-k 个」的顺序。先分段再整体结果不同。

边界：k=0 或 k=n

取余后 k=0，三次反转都不需要做。

8. 总结

轮转数组 解法精髓：

  • 取余处理 k > n
  • 三次反转：整体 → 前 k → 后 n-k
  • 原地 O(1) 空间，巧妙利用反转叠加性

💡 口诀：整体反转把尾移前，分段反转恢复顺序。
