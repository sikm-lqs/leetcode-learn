11. 接雨水

给定柱子高度图，计算能接多少雨水。

1. 题目理解

给定 n 个非负整数，表示每个宽度为 1 的柱子的高度。计算下雨之后，这组柱子能接多少雨水。

示例

输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6

输入：height = [4,2,0,3,2,5]
输出：9
单点接水公式：每个位置 i 能接的水 = min(leftMax, rightMax) − height[i]。其中 leftMax 是 i 左侧（含自身）最高柱、rightMax 是右侧（含自身）最高柱。水位由较矮的一侧决定。

2. 核心思路：双指针

朴素做法是对每个 i 扫两边求 leftMax、rightMax，O(n²)；或用两个数组预存左右最大值，O(n) 时间但 O(n) 空间。双指针能把空间压到 O(1)。

左右指针 left、right 从两端向中间收敛，维护 left_max（左半已见最高）和 right_max（右半已见最高）。每次移动较矮的一端处理：

  • 若 height[left] < height[right]：处理 left。若 height[left] ≥ left_max 更新 left_max，否则接水 left_max − height[left]，left++。
  • 否则：处理 right（对称），right--。
water(i) = min(leftMax, rightMax) − height[i]
双指针：移动矮端 → 该端水量只取决于同侧 max
核心洞察（为什么移动矮端）：水量由较矮侧决定。若 height[left] < height[right]，则右半必然存在一根 ≥ height[right] 的柱子，于是对 left 而言 rightMax ≥ height[right] > height[left] ≥ leftMax 可能性下，min(leftMax, rightMax) = leftMax——left 的水量只由 left_max 决定，无需知道确切的 rightMax。所以矮端可立即结算，高侧留着不动。

3. 伪代码骨架

控制流和变量用代码表达，操作用中文短句概括，精确公式放在 # 注释里——介于「思路文字」与「真实代码」之间的一层抽象，先看骨架再看细节。

left, right = 0, n - 1
leftMax = rightMax = ans = 0

while left < right:
    if 左边低:                    # h[left] < h[right]
        更新左最大值               # leftMax = h[left]
        计算左边贡献               # ans += leftMax - h[left]
        left += 1
    else:                         # 右边低
        更新右最大值               # rightMax = h[right]
        计算右边贡献               # ans += rightMax - h[right]
        right -= 1
return ans
关键字 变量 中文操作 注释公式
「更新最大值」与「计算贡献」二选一：该端比本侧最高还高时刷新最高（接不住水）；否则把差额累加进 ans。左右两支完全对称。

6. 代码逐段解释

class Solution:
    def trap(self, height: List[int]) -> int:
        # water[i] = min(leftMax, rightMax) - height[i]
        # 双指针，移动低的
        left, right = 0, len(height) - 1
        left_max = right_max = 0
        ans = 0

        while left < right:
            # 移动较矮的一端
            if height[left] < height[right]:
                if height[left] >= left_max:
                    left_max = height[left]     # 出现新高，更新左侧最高
                else:
                    ans += left_max - height[left]  # 可接水
                left += 1
            else:
                if height[right] >= right_max:
                    right_max = height[right]
                else:
                    ans += right_max - height[right]
                right -= 1
        return ans

while left < right：两端向中间收敛，相遇即止。每个位置恰好被处理一次。

if height[left] < height[right]：选较矮端处理。这是算法的关键——矮端的水量已可由同侧 max 结算。

if height[left] >= left_max：遇到新高柱，无法接水（水会从这根柱子两侧流走），只更新 max。否则该位置低于左侧最高，可接 left_max − height[left] 的水。

else 分支：处理右端，逻辑完全对称。

用 >= 更新 max：相等高度也算「新高」，不接水（差为 0，加不加都一样，但走更新分支更直观）。

7. 复杂度分析

维度值说明
时间复杂度O(n)left 与 right 合计最多各移动 n 次，整体一次遍历
空间复杂度O(1)只用 left、right、left_max、right_max、ans 五个变量
对比：动态规划法需两个长度 n 的 leftMax/rightMax 数组（O(n) 空间）；单调栈法也可解但更难理解。双指针是空间最优。

8. 常见易错点

错误：移动较高的一端

必须移动较矮端。若移动高侧，矮侧的 max 无法确定，会漏算或多算水。记住「矮端可立即结算」。

错误：用 > 而非 >= 判断更新 max

用 height[left] >= left_max。若用 >，相等高度会走接水分支（差 0，结果不影响），但语义上相等高度应视为新的左边界，用 >= 更清晰。

错误：ans 用 += 还是 =

是 ans += left_max - height[left]，累加每个位置的接水量。单点水层 = max − height，不是覆盖。

边界：单调递增/递减

如 [1,2,3,4]（递增），永远处理 left（始终更矮），left_max 一路更新，不接水，ans=0。正确。

9. 总结

接雨水 双指针解法精髓：

  • 公式：water(i) = min(leftMax, rightMax) − height[i]
  • 双指针：两端向中间，每次移动较矮的一端
  • 矮端结算：矮端水量只取决于同侧 max，遇新高则更新，否则接水
  • 时间 O(n)，空间 O(1)

💡 口诀：水位取左右最小，双指移动矮的一端；遇新高就记 max，低于 max 把水攒。
