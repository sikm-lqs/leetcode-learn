2. 统计角矩形数量

给定只含 0/1 的矩阵，统计四个顶点都为 1 的轴对齐矩形个数。

1. 题目理解

给定一个 m × n 的 0/1 矩阵 grid，要求统计其中四个顶点都为 1 的轴对齐子矩形的个数。即找出所有满足 grid[r1][c1] == grid[r1][c2] == grid[r2][c1] == grid[r2][c2] == 1（其中 r1 < r2, c1 < c2）的四元组个数。

关键观察：一个矩形由两条不同行和两条不同列唯一确定。如果某两行在若干列上「同为 1」，那么任选其中两列就构成一个合法矩形。

2. 核心思路：行对 + 组合计数

📦 朴素法 O(行对 × 列对 × 4)

枚举任意两行两列（C(m,2)×C(n,2) 个组合），检查四个顶点是否都为 1。直观但大量重复扫描。

✅ 行对计数法 O(m²·n)

枚举每对行 (r1,r2)，一次扫描统计两行同为 1 的列数 count，贡献 C(count,2)。把「四顶点判定」压成「两行按位与」。

算法流程

  1. 枚举行对 (r1, r2)，其中 r1 < r2（组合，非排列）
  2. 对每个行对，遍历所有列 c，统计 grid[r1][c] == 1 且 grid[r2][c] == 1 的列数 count
  3. 从这 count 列中任选两列即得到一个矩形，贡献 C(count,2) = count*(count-1)/2
  4. 累加到 ans
ans += count × (count − 1) ÷ 2
核心洞察：把矩形计数转化为组合问题——每对行共同为 1 的列中任选两列即一个矩形。一次列扫描即可得出该行对贡献的全部矩形数，无需逐个四元组判定。

6. 代码逐段解释

完整代码

from typing import List

class Solution:
    def countCornerRectangles(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        ans = 0
        for r1 in range(m):
            for r2 in range(r1 + 1, m):
                count = 0
                for c in range(n):
                    if grid[r1][c] == 1 and grid[r2][c] == 1:
                        count += 1
                ans += count * (count - 1) // 2
        return ans

逐段说明

第 1 段（初始化）：m, n 分别为行数和列数；ans 累计矩形总数。

第 2 段（双重循环枚举行对）：r2 从 r1+1 开始，保证 r1 < r2——这是组合而非排列，避免重复计数和自配对。

第 3 段（统计共同为 1 的列）：对当前行对遍历所有列，条件 grid[r1][c]==1 and grid[r2][c]==1 即「按列与运算」，累加 count。

第 4 段（组合贡献）：count*(count-1)//2 就是 C(count,2)——从 count 列中选 2 列的方案数。整除 // 保证结果是整数。count<2 时该式自然为 0，无需特判。

7. 复杂度分析

维度值说明
时间复杂度O(m²·n)枚举 C(m,2) 个行对，每对扫描 n 列。
空间复杂度O(1)只用常数个变量 ans、count。
对比：朴素四重循环 O(m²·n²) 需对每个四元组判 4 个顶点；行对计数法把内部两重列循环压成一次列扫描 + 一次组合运算，常数和渐进都更优。

8. 常见易错点

错误一：notebook 标注的「9」实为全 1 矩阵的答案

典型混淆：notebook 对 [[1,0,1],[1,0,1],[1,0,1]] 标注输出 9，但运行代码实际只得 3。

原因：列 1 三行全为 0，不参与任何矩形。3 个行对在列 0、列 2 同为 1（count=2），各贡献 C(2,2)=1，合计 3。

9 实际是全 1 矩阵 [[1,1,1],[1,1,1],[1,1,1]] 的答案：每个行对 count=3，C(3,2)=3，3 个行对 × 3 = 9。两者 grid 不同，结果不能套用。

# 验证（可在 notebook 中运行）
print(Solution().countCornerRectangles([[1,0,1],[1,0,1],[1,0,1]]))  # → 3
print(Solution().countCornerRectangles([[1,1,1],[1,1,1],[1,1,1]]))  # → 9

错误二：count < 2 时未正确处理

C(count,2) = count*(count-1)/2 在 count=0 或 1 时结果为 0，天然不贡献，无需 if 特判。但若误写成 count*(count-1) 漏除 2，或把 // 写成 /（返回 float），都会出错。

错误三：行对枚举当成排列

# 错误：r2 从 0 开始会重复计算 (1,0)(2,0)(2,1) 等已统计的行对
for r2 in range(m):        # ❌ 与 r1 不区分大小
    if r2 != r1:
        ...

正确写法是 r2 ∈ range(r1+1, m)，保证 r1 < r2，每个无序行对只算一次。

错误四：忘记整除

count*(count-1) 必为偶数，但 Python 中 / 返回 float，建议用 // 保持 int 类型，避免类型问题。

9. 总结

统计角矩形数量 精髓：

  • 矩形 = 两行 + 两列，四顶点同为 1
  • 枚举行对，统计共同为 1 的列数 count
  • 组合贡献 C(count,2) = count*(count-1)/2
  • 时间 O(m²n)，空间 O(1)
class Solution:
    def countCornerRectangles(self, grid):
        m, n = len(grid), len(grid[0])
        ans = 0
        for r1 in range(m):
            for r2 in range(r1+1, m):
                count = sum(1 for c in range(n) if grid[r1][c]==grid[r2][c]==1)
                ans += count*(count-1)//2
        return ans

💡 口诀：行对扫列数 count，组合 C 值即矩形数。
