4. 螺旋矩阵

按顺时针螺旋顺序，返回矩阵中所有元素。

1. 题目理解

给定一个 m × n 矩阵 matrix，以顺时针螺旋顺序（从左上角出发：右 → 下 → 左 → 上 → 右 → …）依次访问每个元素，返回访问到的元素列表。

关键：不是原地修改，而是把所有元素按螺旋顺序「读出来」放进一个一维列表。每个元素恰好被访问一次。

示例

输入：[[1,2,3],
      [4,5,6],
      [7,8,9]]
输出：[1,2,3,6,9,8,7,4,5]
解释：1→2→3 → 6→9 → 8→7 → 4 → 5（顺时针螺旋一圈再进入中心）

2. 核心思路：边界收缩法

📦 模拟方向法

用 (方向, 坐标) + 已访问集合，每次尝试前进，撞墙就右转。直观但需额外 visited 集合，空间 O(m×n)。

✅ 四边界收缩法

用 top/bottom/left/right 四个变量圈定「未遍历区域」，按 上→右→下→左 顺时针遍历一圈后向内收缩，空间 O(1)。

算法流程

  1. 初始化 top=0, bottom=m-1, left=0, right=n-1，结果数组 res=[]
  2. 当 top ≤ bottom 且 left ≤ right 时循环：
    • 走上边：从 (top,left) 到 (top,right) 向右走，收集；之后 top += 1
    • 走右边：从 (top,right) 到 (bottom,right) 向下走，收集；之后 right -= 1
    • 走下边（先判 if top ≤ bottom）：从 (bottom,right) 到 (bottom,left) 向左走，收集；之后 bottom -= 1
    • 走左边（先判 if left ≤ right）：从 (bottom,left) 到 (top,left) 向上走，收集；之后 left += 1
  3. 循环结束（边界相交），返回 res
核心洞察：用四个变量把「还剩哪些格子没走」框成一个矩形区域。每走完一条边就把那条边「剥掉」（向内收缩一格），问题就规约成更小的同构子问题。
亮点：四变量控制范围，每条边后收缩边界；注意只剩一行/一列时不要重复遍历——走下边/左边前必须用 if top≤bottom / if left≤right 判断，否则单行/单列会被重复收集。

3. 伪代码骨架

控制流和变量用代码表达，操作用中文短句概括，精确公式放在 # 注释里——介于「思路文字」与「真实代码」之间的一层抽象，先看骨架再看细节。

top, bottom = 0, m - 1
left, right = 0, n - 1
res = []

while top <= bottom and left <= right:
    走上边从左到右          # j: left → right, 收集 matrix[top][j]
    top += 1

    走右边从上到下          # i: top → bottom, 收集 matrix[i][right]
    right -= 1

    if top <= bottom:
        走下边从右到左      # j: right → left, 收集 matrix[bottom][j]
    bottom -= 1

    if left <= right:
        走左边从下到上      # i: bottom → top, 收集 matrix[i][left]
    left += 1

return res

四条边按顺时针顺序收缩：上→右→下→左。每次走完一条边就收缩对应边界，未遍历区域不断向内缩小。注意下边/左边前的 if 判断防止单行/单列重复遍历。

蓝色 = 当前未遍历区域。top=最上一行，bottom=最下一行，left=最左一列，right=最右一列。

第 1 圈·上边 → 收缩 top

沿 top=0 这一行从左到右：(0,0)=1 → (0,1)=2 → (0,2)=3，收集 [1,2,3]。走完后 top → 1，上边「剥掉」。

第 1 圈·右边 → 收缩 right

沿 right=2 这一列从上到下：(1,2)=6 → (2,2)=9，收集 [6,9]。走完后 right → 1，右边「剥掉」。

第 1 圈·下边（从右到左）→ 收缩 bottom

先判 top(1) ≤ bottom(2) ✓。沿 bottom=2 这一行从右到左：(2,1)=8 → (2,0)=7，收集 [8,7]。走完后 bottom → 1。

第 1 圈·左边（从下到上）→ 收缩 left

先判 left(0) ≤ right(1) ✓。沿 left=0 这一列从下到上：(1,0)=4，收集 [4]。走完后 left → 1。此时未遍历区域只剩中心一格。

第 2 圈·内层上边 → 收缩 top，循环结束

top=1, bottom=1, left=1, right=1，top ≤ bottom 且 left ≤ right 仍成立。走上边 (1,1)=5，收集 [5]，top → 2。此时 top(2) > bottom(1)，循环结束。

✅ 结果：res = [1,2,3,6,9,8,7,4,5]，每个元素恰好访问一次，空间 O(1)。

6. 代码逐段解释

完整代码

from typing import List

class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        if not matrix or not matrix[0]:
            return []
        res = []
        top, bottom = 0, len(matrix) - 1
        left, right = 0, len(matrix[0]) - 1

        while top <= bottom and left <= right:
            # 1. 上边：从左到右
            for j in range(left, right + 1):
                res.append(matrix[top][j])
            top += 1

            # 2. 右边：从上到下
            for i in range(top, bottom + 1):
                res.append(matrix[i][right])
            right -= 1

            # 3. 下边：从右到左（先判 top <= bottom）
            if top <= bottom:
                for j in range(right, left - 1, -1):
                    res.append(matrix[bottom][j])
            bottom -= 1

            # 4. 左边：从下到上（先判 left <= right）
            if left <= right:
                for i in range(bottom, top - 1, -1):
                    res.append(matrix[i][left])
            left += 1

        return res

逐段说明

第 0 段（空矩阵）：if not matrix or not matrix[0] 同时挡住 [] 和 [[]]，避免 len(matrix[0]) 越界。

第 1 段（上边）：j 从 left 到 right 闭区间，沿 top 行向右收集；之后 top += 1 把上边「剥掉」。

第 2 段（右边）：从新的 top 到 bottom，沿 right 列向下收集；之后 right -= 1 剥掉右边。注意起始用新的 top，避免重复收集上边右端点。

第 3 段（下边）：先判 if top ≤ bottom——单行时上边走完 top 已超过 bottom，此时不能再反向走下边。j 从 right 到 left 倒序。无论是否走，bottom -= 1 照常执行。

第 4 段（左边）：先判 if left ≤ right——单列时右边走完 right 已小于 left，不能再反向走左边。i 从 bottom 到 top 倒序。left += 1 照常执行。

循环条件：top ≤ bottom and left ≤ right 保证只要还有未遍历区域就继续；内层只剩一行/一列时也能正确处理。

7. 复杂度分析

维度值说明
时间复杂度O(m×n)每个元素恰好被访问一次，总访问量 = 元素总数。
空间复杂度O(1)除返回的 res 外，只用 top/bottom/left/right 四个变量。
注：若不计返回值本身的空间，算法只消耗常数额外空间——这是四边界法相比「方向+visited 集合」模拟法的核心优势。

8. 常见易错点

错误一：下边/左边不加判断 → 单行单列重复收集

# 错误：省略 if 判断
for j in range(right, left - 1, -1):     # ❌ 单行 [[1,2,3]] 上边走完后 top>bottom
    res.append(matrix[bottom][j])         #    此处会反向再走一遍 → [1,2,3,2,1]
bottom -= 1

必须先判 if top <= bottom（下边）和 if left <= right（左边），挡住退化情形。

错误二：右边起始用旧的 top

上边走完后 top 已 +1。若右边循环写成 for i in range(top_old, bottom+1)，会重复收集 (top_old, right)（上边右端点已被上边收集过）。右边必须用收缩后的新 top 起步。

错误三：忘记空矩阵判断

输入 [] 时 matrix[0] 越界；输入 [[]]（一行零列）时 len(matrix[0])=0，matrix[0][0] 越界。if not matrix or not matrix[0] 一起挡住。

错误四：循环条件写成 OR

while top <= bottom or left <= right 是错的——只要一个方向没走完就会继续，可能越界访问。必须用 and，表示「还有矩形区域」。

9. 总结

螺旋矩阵 精髓：

  • 用 top/bottom/left/right 四变量圈定未遍历矩形区域
  • 顺时针走 上 → 右 → 下 → 左 四条边，每条边后向内收缩一格
  • 走下边/左边前判 if top≤bottom / if left≤right，防单行/单列重复
  • 时间 O(m×n)，空间 O(1)
class Solution:
    def spiralOrder(self, matrix):
        if not matrix or not matrix[0]: return []
        res, t, b, l, r = [], 0, len(matrix)-1, 0, len(matrix[0])-1
        while t <= b and l <= r:
            for j in range(l, r+1): res += matrix[t][j],
            t += 1
            for i in range(t, b+1): res += matrix[i][r],
            r -= 1
            if t <= b:
                for j in range(r, l-1, -1): res += matrix[b][j],
            b -= 1
            if l <= r:
                for i in range(b, t-1, -1): res += matrix[i][l],
            l += 1
        return res

💡 口诀：四边围一圈，顺时针走完；走一条缩一格，单行单列先判断。
