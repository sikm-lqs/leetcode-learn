将 n×n 矩阵原地顺时针旋转 90 度。

1. 题目理解

给定一个 n × n 的二维矩阵 matrix，将其原地顺时针旋转 90 度。即不能开辟新矩阵，必须直接在原矩阵上修改。

关键：「原地」意味着空间 O(1)。直接模拟四个位置的循环旋转虽然可行，但坐标推导容易出错；下面用一个更优雅的「两步分解法」。

示例

输入：[[1,2,3],
      [4,5,6],
      [7,8,9]]
输出：[[7,4,1],
      [8,5,2],
      [9,6,3]]
解释：整个矩阵顺时针转 90°，行变成列

2. 核心思路：上下反转 + 主对角线转置

🔄 朴素法 O(n²) 空间

开一个 n×n 辅助矩阵，按 new[j][n-1-i] = old[i][j] 逐格填入。逻辑直观但多用了一整块内存。

✅ 分解法 O(1) 空间

把「旋转 90°」拆成两个简单操作的复合：上下反转 + 沿主对角线转置，全部原地完成。

两步操作

  1. 上下反转：把第 i 行与第 n-1-i 行整体交换，i 取 0 ~ n//2-1。
  2. 主对角线转置：只处理右上三角（j > i），交换 matrix[i][j] 与 matrix[j][i]。
顺时针 90° = reverse(上下) ◦ transpose(主对角线)
核心洞察：把旋转拆成两个简单操作，避免复杂的四角坐标推导。改变两步的顺序还能得到逆时针：先转置后左右翻转 = 逆时针 90°。

✅ 最终结果：[[7,4,1],[8,5,2],[9,6,3]]，整个矩阵顺时针旋转 90°。
顺时针 90° = reverse(上下) + transpose
逆时针 90° = transpose + reverse(左右)
记忆口诀：顺时针——「上下翻 + 转置」；逆时针——「转置 + 左右翻」。先转后翻 = 逆，先翻后转 = 顺，两步顺序不可随意调换。

5. 代码逐段解释

完整代码

from typing import List

class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        n = len(matrix)

        # 1. 上下反转：第 i 行与第 n-1-i 行交换
        for i in range(n // 2):
            matrix[i], matrix[n - 1 - i] = matrix[n - 1 - i], matrix[i]

        # 2. 主对角线转置：交换右上三角 (j > i)
        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

逐段说明

第 1 段（上下反转）：循环变量 i 只走前一半 0 ~ n//2-1，让第 i 行与倒数第 i 行（n-1-i）整体对调。Python 的 a, b = b, a 可直接交换两行引用，无需临时变量。

第 2 段（转置）：外层 i 走全部行，内层 j 从 i+1 开始——即只遍历右上三角。对每个 (i, j) 与关于主对角线的对称点 (j, i) 交换，等价于矩阵转置。

两步合起来：上下反转把行的方向倒过来，转置再把行列互换，整体就是顺时针 90°。每一步都在原矩阵上完成，无需额外空间。

6. 复杂度分析

维度值说明
时间复杂度O(n²)上下反转 O(n·n)（行交换）+ 转置遍历右上三角约 n²/2，合计 O(n²)。
空间复杂度O(1)仅用常数个下标变量，全部在原矩阵上修改。

7. 常见易错点

错误一：转置遍历整个矩阵

# 错误：i, j 都从 0 到 n，会把每对交换两次 → 还原成原样
for i in range(n):
    for j in range(n):          # ❌ j 应该从 i+1 开始
        matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

必须只处理右上三角（j > i），否则一对元素会被交换两次又变回去。

错误二：上下反转循环越界

# 错误：i 走到 n，会把每行交换两次还原
for i in range(n):              # ❌ 应该是 range(n // 2)
    matrix[i], matrix[n-1-i] = matrix[n-1-i], matrix[i]

循环上限必须是 n // 2，让前一半行与后一半行各交换一次即可。

错误三：返回新矩阵

题目要求原地修改 matrix，不能 return 一个新构造的二维列表。两步操作都直接作用于入参本身。

错误四：搞混两种旋转的顺序

顺时针是「先上下反转后转置」；若写成「先转置后左右翻转」得到的则是逆时针 90°，方向相反，不能混用。

8. 总结

旋转图像 精髓：

  • 把旋转 90° 拆成两个简单操作：上下反转 + 主对角线转置
  • 反转循环 i < n // 2；转置只遍历右上三角 j > i
  • 全程原地修改，时间 O(n²)，空间 O(1)
  • 换序可得逆时针：转置 + 左右翻转
class Solution:
    def rotate(self, matrix):
        n = len(matrix)
        for i in range(n//2):
            matrix[i], matrix[n-1-i] = matrix[n-1-i], matrix[i]
        for i in range(n):
            for j in range(i+1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

💡 口诀：上下翻一次，右上三角转一次，顺时针九十度。
