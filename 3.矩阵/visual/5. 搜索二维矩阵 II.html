5. 搜索二维矩阵 II

在行列均有序的矩阵中高效搜索目标值

1. 题目理解

给定一个 m x n 矩阵，其中每行从左到右升序排列，每列从上到下升序排列。编写高效算法搜索目标值 target。

关键特性：矩阵不仅行有序，列也有序。这意味着可以利用行列的单调性进行搜索。

示例

输入：matrix = [
  [1,   4,  7, 11, 15],
  [2,   5,  8, 12, 19],
  [3,   6,  9, 16, 22],
  [10, 13, 14, 17, 24],
  [18, 21, 23, 26, 30]
], target = 5
输出：true

输入：同上矩阵, target = 20
输出：false
观察：从右上角看，向左数值递减，向下数值递增。这个特性让搜索变得高效。

2. 核心思路：右上角搜索

❌ 暴力法 O(m×n)

遍历整个矩阵，逐个比较。简单但低效，没有利用矩阵的有序性。

✅ 右上角搜索 O(m+n)

从右上角开始，根据比较结果每次排除一行或一列。高效且空间 O(1)。

算法流程

  1. 从矩阵右上角开始（row=0, col=n-1）
  2. 比较当前元素 matrix[row][col] 与 target：
    • 相等 → 找到目标，返回 true
    • 当前值 > target → 当前列下面的元素都更大，向左移动（col--）
    • 当前值 < target → 当前行左边的元素都更小，向下移动（row++）
  3. 越界仍未找到 → 返回 false
核心洞察：每次比较都能排除一行或一列，最多移动 m+n 次，时间复杂度 O(m+n)。相比暴力 O(m×n) 有显著提升。

为什么选择右上角？

从右上角看，向左是递减，向下是递增，形成了一个完美的决策树：

  • 若当前值过大 → 排除当前列（向左）
  • 若当前值过小 → 排除当前行（向下）
其他起点：也可以从左下角开始（向右递增，向上递减），逻辑相同。但不能从左上角或右下角开始，因为无法有效排除。

3. 伪代码骨架

row = 0, col = n - 1  # 从右上角开始

while row < m and col >= 0:
    if 当前元素等于目标:         # matrix[row][col] == target
        return True
    elif 当前元素大于目标:       # matrix[row][col] > target
        col -= 1              向左移动，排除当前列
    else:                      # matrix[row][col] < target
        row += 1              向下移动，排除当前行

return False

6. 代码逐段解释

完整代码

class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        if not matrix or not matrix[0]:
            return False

        m, n = len(matrix), len(matrix[0])
        row, col = 0, n - 1  # 从右上角开始

        while row < m and col >= 0:
            if matrix[row][col] == target:
                return True
            elif matrix[row][col] > target:
                col -= 1  # 向左移动
            else:
                row += 1  # 向下移动

        return False

第 1 步：边界检查

    return False

处理空矩阵情况。

第 2 步：初始化位置

row, col = 0, n - 1  # 右上角

从第一行最后一列开始。

第 3 步：搜索循环

    if matrix[row][col] == target:
        return True
    elif matrix[row][col] > target:
        col -= 1  # 向左
    else:
        row += 1  # 向下

根据比较结果移动，每次排除一行或一列。

关键：while 条件是 row < m and col >= 0，确保不越界。

7. 复杂度分析

维度值说明
时间复杂度O(m + n) 最多移动 m 次向下 + n 次向左 = m + n 次
空间复杂度O(1) 只用了常数个变量，无额外空间
对比：暴力法 O(m×n)，右上角搜索 O(m+n)。当 m=n=1000 时，暴力需 10^6 次比较，右上角搜索仅需 2000 次。

8. 变体与扩展

变体1：严格递增矩阵搜索

若矩阵全局有序（每行末尾 < 下一行开头），可用二分搜索：

  • 先对行做二分，确定目标在哪一行
  • 再对该行做二分
  • 时间 O(log m + log n)

变体2：左下角搜索

从左下角 (m-1, 0) 开始，逻辑类似：

  • 若当前值 > target → 向上移动
  • 若当前值 < target → 向右移动

注意：不能从左上角或右下角开始，因为这两个方向都是单调递增或递减，无法有效排除。

9. 总结

搜索二维矩阵 II 解法精髓：

  • 从右上角（或左下角）开始搜索
  • 利用行列单调性，每次比较排除一行或一列
  • 当前值 > target → 向左（排除列）
  • 当前值 < target → 向下（排除行）
  • 时间 O(m+n)，空间 O(1)
class Solution:
    def searchMatrix(self, matrix, target):
        if not matrix or not matrix[0]:
            return False
        row, col = 0, len(matrix[0]) - 1
        while row < len(matrix) and col >= 0:
            cur = matrix[row][col]
            if cur == target: return True
            elif cur > target: col -= 1
            else: row += 1
        return False

💡 口诀：右上起步，比大左移，比小下移，行列同减，高效搜索。
