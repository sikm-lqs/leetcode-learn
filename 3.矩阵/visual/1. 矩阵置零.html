1. 矩阵置零

给定 m×n 矩阵，若某元素为 0，则将其所在行与列全部置 0。要求原地算法。

1. 题目理解

给定一个 m × n 的矩阵 matrix，如果 matrix[i][j] == 0，就把第 i 行和第 j 列的所有元素都变成 0。要求原地修改。

陷阱：不能遇到 0 就立即把整行整列清零——这会把原本非 0 的位置也变成 0，从而产生「传染式」的连锁清零。必须先标记，最后统一清零。

示例

输入：[[1,1,1],
      [1,0,1],
      [1,1,1]]
输出：[[1,0,1],
      [0,0,0],
      [1,0,1]]
解释：只有 (1,1) 是 0，于是第 1 行与第 1 列全部置 0

2. 核心思路：用首行首列做标记

📦 朴素法 O(m+n) 空间

用两个集合记录哪些行、哪些列需要清零，再统一清。简单但多用空间。

✅ 标记法 O(1) 空间

借用矩阵的第一行和第一列当标记数组，把空间降到常数。

算法流程

  1. 先用两个布尔变量记录第一行、第一列本身是否含有 0
  2. 遍历其余格子（i≥1, j≥1），遇 0 则把 matrix[i][0] 和 matrix[0][j] 置 0（打标记）
  3. 再遍历其余格子，若其行首或列首为 0，则把它置 0（按标记清零）
  4. 最后根据两个布尔变量处理第一行、第一列本身
核心洞察：第一行/列既「参与标记」又「本身可能被清零」，存在职责冲突。解决办法是先记录它们自身的状态，把它们的清零推迟到最后单独处理。

5. 代码逐段解释

完整代码

from typing import List

class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        m, n = len(matrix), len(matrix[0])

        # 1. 记录首行、首列自身是否有 0
        first_row_zero = any(matrix[0][j] == 0 for j in range(n))
        first_col_zero = any(matrix[i][0] == 0 for i in range(m))

        # 2. 打标记：用首行首列记录内部 0 的位置
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0
                    matrix[0][j] = 0

        # 3. 按标记清零（跳过首行首列）
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0

        # 4. 最后处理首行、首列
        if first_row_zero:
            for j in range(n):
                matrix[0][j] = 0
        if first_col_zero:
            for i in range(m):
                matrix[i][0] = 0

逐段说明

第 1 段（记录）：用 any() 扫描第一行/列，把它们自身是否含 0 存进两个布尔变量。这一步必须在打标记之前做，否则首行/列会被标记污染。

第 2 段（打标记）：只遍历内部 (i≥1, j≥1)，遇到 0 就在对应的首行/首列位置写 0。

第 3 段（清零）：再次遍历内部，根据首行/首列的标记决定是否清零。

第 4 段（收尾）：用最初记录的布尔值处理第一行/列本身。

6. 复杂度分析

维度值说明
时间复杂度O(m×n)遍历矩阵常数次。
空间复杂度O(1)只用两个布尔变量，标记复用首行首列。

7. 常见易错点

错误一：边找边清零

# 错误：遇到 0 立刻清整行整列 → 新生成的 0 会继续「传染」
for i in range(m):
    for j in range(n):
        if matrix[i][j] == 0:
            set_row_zero(i)   # ❌ 会把原本非 0 的位置也变 0
            set_col_zero(j)

必须先标记后清零，分两趟遍历。

错误二：忘记先记录首行/首列自身

如果先打标记再判断首行首列，标记已经把首行/首列改了，判断结果会失真。

错误三：清零时连首行首列一起清

第 3 段清零循环必须从 i=1, j=1 开始，否则会读到自己刚被改的首行/首列。

8. 总结

矩阵置零 精髓：

  • 先记录 → 再标记 → 后清零 → 最后处理首行首列
  • 用首行首列当标记数组，空间 O(1)
  • 首行首列的自身状态用两个布尔变量单独保存
class Solution:
    def setZeroes(self, matrix):
        m, n = len(matrix), len(matrix[0])
        fr = any(matrix[0][j]==0 for j in range(n))
        fc = any(matrix[i][0]==0 for i in range(m))
        for i in range(1,m):
            for j in range(1,n):
                if matrix[i][j]==0: matrix[i][0]=matrix[0][j]=0
        for i in range(1,m):
            for j in range(1,n):
                if matrix[i][0]==0 or matrix[0][j]==0: matrix[i][j]=0
        if fr: matrix[0]=[0]*n
        if fc:
            for i in range(m): matrix[i][0]=0

💡 口诀：先记首行首列，内部打标记；按标清内部，最后清首端。
